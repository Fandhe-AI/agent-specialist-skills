# 例: 自治体向けの Web レポートの地図（件数を率に替えるコロプレス）

「市区町村別の件数を色分け地図にして」という依頼を、人口あたりの率の色分けと、件数・人口の表に組み替える例。地図の色分け（コロプレス）で件数を扱うときや、面積の広い小さな地域が目立ちすぎるときに開く。題材は架空の県と市町村で、実在の地名・統計・製品は模倣しない。階級区分の方法と小地域のばらつきの扱いは、出典を取得していない。

## 依頼

- 組織: 架空の「あおば県」の交通安全担当。媒体は自治体向けの Web レポート（県内 6 市町村の担当者が読む）
- 依頼文: 「市区町村別の自転車事故（人身）の年間件数を、色分け地図にして」
- 読み手: 県と 6 市町村の担当者。注意喚起の資料を、どの市町村に先に届けるかを決める
- 現状: 件数の多さで 5 階級に色分け。凡例の色の照合が必要で、数値は地図上に無い
- データ（架空。年間）:

| 市町村 | 人口 | 件数 | 面積（km²） | 1 万人あたり |
|---|---|---|---|---|
| A 市 | 240,000 | 192 | 120 | 8.0 |
| B 市 | 150,000 | 195 | 90 | 13.0 |
| C 町 | 60,000 | 36 | 60 | 6.0 |
| D 町 | 40,000 | 28 | 100 | 7.0 |
| E 村 | 2,500 | 5 | 200 | 20.0 |
| F 町 | 80,000 | 80 | 190 | 10.0 |
| 合計 | 572,500 | 536 | 760 | 9.4（総件数 ÷ 総人口） |

### 根拠の範囲（先に読む）

- コロプレスは相対値（率・割合）に向く。人数そのものを地図にしても、人口を知らないと比べられない（S80）。コロプレスは、どれだけの地理的な面積が影響を受けているかを示す（S81）
- 階級区分の方法（等間隔・分位・自然分類）と、小さな地域のばらつきの扱いは、出典を取得していない（`../references/sources.md` の「調査の限界」）。本例の階級の境界（8.0 と 12.0）と、小地域への注記は、本 skill の目安・整理である
- 「面積と人口のずれ」の数値は、本例の架空のデータからの計算で、一般の傾向を示すものではない

## 目的の一文

県と市町村の担当者が、人口あたりの事故の多さで注意を向ける市町村を選び、注意喚起の資料を届ける順番を決める。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 件数そのものの色分け | 件数は人口が多い地域で大きくなりやすい（本 skill の整理）。人口を知らないと件数は比べられない（S80）。件数は表に回す（S12 は、地図上の円などで示す代わりに表を試す姿勢を示す） |
| 5 階級 | 6 市町村に対して階級が多く、凡例の色の照合を読み手に課す。3 階級にする（本 skill の整理） |
| 凡例の色の照合だけに頼る読み方 | 各市町村に率の値を直接書く（S60。色は階級の補助） |
| 実際の地形の描き込み | 本例の目的は率の比較で、形は要らない。面積に比例した簡略図にする（本 skill の整理） |

件数の順位と、率の順位は入れ替わる（本例のデータ）:

| 順位 | 件数 | 1 万人あたり |
|---|---|---|
| 1 | B 市 195 | E 村 20.0 |
| 2 | A 市 192 | B 市 13.0 |
| 3 | F 町 80 | F 町 10.0 |
| 4 | C 町 36 | A 市 8.0 |
| 5 | D 町 28 | D 町 7.0 |
| 6 | E 村 5 | C 町 6.0 |

## 構成

```text
+------------------------------------------------------------+
| 1 万人あたりの事故は、B 市 13.0 に対し E 村は 20.0。         |  見出し = メッセージ（S68）
| ただし E 村は 5 件で、1 件の増減で 4.0 動く                  |
| +-------------------+-------+-----+                          |
| |      E村 20.0     | A市8.0|C町  |   面積に比例した簡略図     |
| |    5 件（※）      |192 件 |6.0  |   各市町村に名前・率・件数    |
| +-----+-----+-------------------+                            |
| |B市  |D町  |       F町 10.0    |                            |
| |13.0 |7.0  |        80 件      |                            |
| +-----+-----+-------------------+                            |
| 凡例: 8.0 未満 / 8.0 以上 12.0 未満 / 12.0 以上（1 万人あたり、件）    |
| ※ E 村は件数が少ない。単位・期間・出典の 1 行                 |
+------------------------------------------------------------+
| 市町村ごとの人口・件数・率の表（上の「依頼」の表）              |
+------------------------------------------------------------+
```

- 地図は、各市町村の面積に比例した簡略図（実際の形ではない）。色は 1 万人あたりの件数の階級で、各市町村に名前・率・件数を直接書く。人数（件数）は表と文字で示し、色には使わない（S80）
- 階級は 3 つ（8.0 未満・8.0 以上 12.0 未満・12.0 以上）で、色は 1 色の明度の順（sequential）にする（S53）。明度の変化は、データの変化として読まれやすい（S49）。発散型にするなら、中心の値を明示する（S88。本例は使わない）
- 件数が少ない市町村（E 村。5 件）は、件数の文字と「※」で示し、点線の枠を補助に使う（濃い塗りの上では、点線は外側の白に接する半分だけが見える）。1 件の増減で率が動く幅は、人口の逆数で決まる（10,000 ÷ 2,500 = 4.00。A 市は 10,000 ÷ 240,000 = 0.04）。図から偶然のパターンを読んでしまう偏りがある（S13）。これが小さな数で強まるという当てはめは本 skill の整理で、小地域の扱いの出典は取得していない
- 地図の色は面積の広がりを強調する（S81）。本例で、階級ごとの面積・人口・件数の割合を計算した（面積・人口と件数のずれは本 skill の整理）:

| 階級（市町村） | 面積 | 人口 | 件数 |
|---|---|---|---|
| 8.0 未満（C 町・D 町） | 160 km²（21.1 %） | 100,000（17.5 %） | 64（11.9 %） |
| 8.0 以上 12.0 未満（A 市・F 町） | 310 km²（40.8 %） | 320,000（55.9 %） | 272（50.7 %） |
| 12.0 以上（B 市・E 村） | 290 km²（38.2 %） | 152,500（26.6 %） | 200（37.3 %） |

E 村は面積の 26.3 %（200 ÷ 760）を占めるが、人口の 0.44 %、件数の 0.93 % である。最も濃い色が広く塗られるが、件数が最多（195 件）の B 市は、面積では 90 km²（11.8 %）にとどまる。これを注記し、件数は表で補う。

## 仕様

出典あり（S 番号を付けたもの）:

| 発散型の場合 | 中心の値を明示する（本例は使わない） | S88 |
| 色だけに頼らない | 名前・率・件数を直接書く。「※」と点線を併用 | S60 |
| 文字のコントラスト | 4.5:1 以上 | S63 |
| 図の必要な部分のコントラスト | 隣接色に対して 3:1 以上 | S61、S62 |
| 注記 | データの出どころと分析の過程の文書化を添える（期間・単位は本 skill の整理） | S14 |
| 文字 | 水平 | S71 |

本 skill の目安（出典なし）: 階級の境界 8.0 と 12.0、階級数 3、面積 1 km² = 1.5 px の簡略図、市町村の高さ 140 px、市町村の間の隙間 4 px、率の文字 22 px・名前 13 px・件数 12 px。図の幅は 520〜582 px（582 px は描画の幅で、それより広い画面でも文字を拡大しない。名前 13 px・率 22 px・件数 12 px のまま）。520 px の下限では名前が 11.6 px、件数が 10.7 px になり、それより狭ければ横スクロールにする（`overflow-x: auto` の包み）。横スクロールの初期表示は左端なので、見出しの主役の E 村と B 市を各行の左端に置く（並びは本 skill の整理）。390 px の画面（図の表示幅 294 px）の初期表示に、E 村・B 市・D 町の名前・率・件数が入ることを、Chrome headless で確かめた（A 市・C 町・F 町は横スクロールの先で、率と件数は表にもある）。件数が 10 件未満を「少ない」とみなす基準。いずれも規格ではない。

色の計算（WCAG の相対輝度式。色値は本 skill の目安で、ColorBrewer などの配色の値ではない）:

| 組み合わせ | 比 | 判定 |
|---|---|---|
| 低 `#e9f0f8` / 文字 `#1c1f2a` | 14.30 | 4.5:1 を満たす |
| 中 `#6491ca` / 文字 `#1c1f2a` | 5.04 | 4.5:1 を満たす |
| 高 `#0f3a78` / 文字 `#ffffff` | 11.07 | 4.5:1 を満たす |
| 低 / 白 `#ffffff` | 1.15 | 3:1 を満たさない。枠線 `#4a4a55`（白に対し 8.74、低に対し 7.61）で境界を示す（本 skill の判断） |
| 中 / 白 | 3.26 | 3:1 を満たす |
| 高 / 白 | 11.07 | 3:1 を満たす |
| 低 / 中（隣り合う階級） | 2.84 | 3:1 を満たさない。値の直接ラベルで補う（本 skill の判断） |
| 中 / 高（隣り合う階級） | 3.40 | 3:1 を満たす |
| 枠線 / 中 | 2.68 | 枠線は中の塗りの上では目立たない。境界は、白に対する塗りの比 3.26 が担う |
| 枠線 / 高 | 1.27 | 高の塗りの上では枠線は見えない。境界は、白に対する塗りの比 11.07 が担う |

## コード断片

外部のライブラリ・スクリプト・フォント・計測は使わない。率・階級・総計を標準ライブラリで計算し、SVG の部品を出力する。

```python
from html import escape

# (名前, 人口, 件数, 面積 km², 行, 左端 px)。幅 = 面積 × 1.5 px、高さは 140 px で共通
towns = [
    ("E村", 2500, 5, 200, 0, 0), ("A市", 240000, 192, 120, 0, 304), ("C町", 60000, 36, 60, 0, 488),
    ("B市", 150000, 195, 90, 1, 0), ("D町", 40000, 28, 100, 1, 139), ("F町", 80000, 80, 190, 1, 293),
]
FILL = {0: "#e9f0f8", 1: "#6491ca", 2: "#0f3a78"}   # 低・中・高（明度が下がる順）
TEXT = {0: "#1c1f2a", 1: "#1c1f2a", 2: "#ffffff"}

def rate(count, pop):                  # 1 万人あたりの件数
    return count * 10000 / pop

def klass(r):                          # 階級の境界 8.0・12.0 は本 skill の目安
    return 0 if r < 8.0 else (1 if r < 12.0 else 2)

pop_all = sum(t[1] for t in towns)
cnt_all = sum(t[2] for t in towns)
area_all = sum(t[3] for t in towns)
print("全体の率", round(rate(cnt_all, pop_all), 1), "= 総件数 / 総人口（率の平均ではない）")
print("率の単純平均", round(sum(rate(t[2], t[1]) for t in towns) / len(towns), 2))
for name, pop, cnt, area, row, x in towns:
    print(name, f"率 {rate(cnt, pop):.1f}", f"1 件の増減 {10000 / pop:.2f}",
          f"面積 {area / area_all:.1%} 人口 {pop / pop_all:.2%} 件数 {cnt / cnt_all:.2%}")
for k, label in enumerate(("低", "中", "高")):
    m = [t for t in towns if klass(rate(t[2], t[1])) == k]
    print(label, [t[0] for t in m], f"面積 {sum(t[3] for t in m)}（{sum(t[3] for t in m) / area_all:.1%}）",
          f"人口 {sum(t[1] for t in m)}（{sum(t[1] for t in m) / pop_all:.1%}）",
          f"件数 {sum(t[2] for t in m)}（{sum(t[2] for t in m) / cnt_all:.1%}）")

for name, pop, cnt, area, row, x in towns:
    r = rate(cnt, pop)
    k = klass(r)
    w, y = area * 1.5, row * 144
    dash = ' stroke-dasharray="5 3"' if cnt < 10 else ""      # 件数が少ない地域は点線 + 注記
    print(f'<rect x="{x}" y="{y}" width="{w:g}" height="140" fill="{FILL[k]}" stroke="#4a4a55"{dash}/>')
    cx, cy = x + w / 2, y + 70
    print(f'<g fill="{TEXT[k]}" text-anchor="middle"><text x="{cx:g}" y="{cy - 14:g}">{escape(name)}</text>'
          f'<text x="{cx:g}" y="{cy + 8:g}" font-size="22" font-weight="700">{r:.1f}</text>'
          f'<text x="{cx:g}" y="{cy + 28:g}" font-size="12">{cnt} 件{"（※）" if cnt < 10 else ""}</text></g>')
```

## 点検

- 率: 色分けは率で、人数は表と文字で示した（S80）。全体の率は総件数 ÷ 総人口で、率の平均ではない（検算済み）
- 面積: 面積の広がりが強調されることを注記した（S81）。面積と人口・件数のずれは、階級別の割合の表で確かめた
- 小地域: E 村の 5 件は 1 件で率が 4.0 動く。注記と点線で示したが、小地域の扱いの出典は取得していない。必要なら、統計の専門家に確認する（範囲外）
- 色: 上の計算のとおり、低と中の隣接（2.84）は 3:1 に届かない。補っているのは値の直接ラベルだけで、枠線は補いにならない（枠線と中の塗りの比は 2.68）。この扱いは本 skill の判断で、WCAG の隣接色の扱いは Understanding の本文を未照合。色覚の違いは実機で確かめる（本例は 1 色の明度の順で、赤と緑を使わない）
- 階級: 境界 8.0・12.0 は本例の目安で、等間隔・分位・自然分類との比較はしていない（出典未取得）。市町村が増えた場合は、階級数と境界を見直す
- 推測の明示: 「率の高い市町村に注意喚起を優先する」という判断は、事故の原因・道路の状況などの個別のデータが要る。この図は優先順位の根拠の一部にすぎない
