# 例: 店舗別の売上を、数値の隣の sparkline で一覧にする（週次の営業ページ）

5 店の折れ線を 1 つのグラフに重ねた図を、「数値の隣に小さな推移の線を置く表」へ組み替える例。題材は架空の食品小売で、実在の製品・企業の画面は模倣しない。図の選び方と正確さ（尺度・数値・出典）に絞る。カードの数や更新の動きなど画面体験は扱わない（designer-apple が導入されていれば、その担当）。KPI の一覧に推移を添えるときに開く。

## 依頼

- 媒体: 架空の食品小売「みなと堂」の、週次の営業ページ（社内 Web ページ内の表）
- 依頼文（架空）: 「店舗ごとの売上の推移を、小さく一覧で見たい。今は 5 店の折れ線を 1 つのグラフに重ねていて、どれがどの店か分からない。ダッシュボードのグラフを直して」
- 見る人: 営業マネージャー。毎週月曜に 5 店を見て、今週、話を聞きに行く店を決める
- 現状: 5 本の折れ線を 1 つのグラフに重ね、凡例の色で店を照合させている。最大の店（480 万円）と最小の店（152 万円）が同じ軸にあり、小さい店の動きが平らに見える
- データ（架空）: 12 週分、単位は万円。期間は 8 月 25 日の週〜11 月 10 日の週

```text
駅前店    410 425 418 432 440 436 451 460 455 468 472 480
港店      300 310 295 305 290 285 298 280 275 268 272 260
丘の上店  150 148 152 149 151 150 153 150 152 151 150 152
南口店    220 235 228 241 160 232 238 245 240 250 244 255
西口店    180 176 182 170 165 172 160 168 175 182 190 198
```

### 根拠の範囲（先に読む）

- 出典のある事実: sparkline の定義（S01）、データだけから成ること（S05）、量は近くの数値で示すこと（S08）、見た目を減らしてもデータは減らさないこと（S04）。英語の原文（S01）: "A sparkline is a small intense, simple, word-sized graphic with typographic resolution." 日本語は要旨で、本人の発言ではない
- 本 skill の目安（出典なし）: 描画域の寸法（96 × 24）、点の数（12）、尺度の最小幅（平均の絶対値の 10 %。正の値の系列を想定）、行の高さ、行の数（5）、並び順。行の数や KPI の個数の出典は取得していない
- 範囲外: 港店が下がった原因、その下がりが偶然の範囲かどうか（統計の判断は扱わない）

## 目的の一文

営業マネージャーが毎週月曜に、5 店の最新の売上と 12 週の動きを一度に見て、話を聞きに行く店を決める。

図のメッセージ（S68）: (1) 最新週の売上は駅前店が最大の 480 万円。(2) 最初の週と最新週を比べて下がったのは港店だけ（300 → 260 万円）。(3) 南口店は 5 週目に 160 万円まで落ち込み、戻っている。原因はこの表から分からない。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 5 本を 1 つのグラフに重ねた折れ線 | 凡例の色で店を照合させる作りは避ける指針がある（S67）。店ごとに行を分ける |
| 各 sparkline の枠・目盛り・格子線 | sparkline はデータだけから成り、非データを持たない（S05）。枠・目盛りを置かないのは、その適用（本 skill の整理）。量は近くの数値で示す（S08） |
| 全点のマーカー | 不要なデータの印は避ける（S70）。残すのは終点 1 つで、隣の「最新週」の数字と線を結ぶため（本 skill の整理） |
| 赤・緑で示す増減 | 色だけで意味を伝えない（S60）。符号と数値で示す |
| ゲージ・信号の飾り | bullet graph は、メーター・ゲージの置き換えとして設計された（S40）。目標との比較に使うのは本 skill の整理で、今回は目標が無いので入れない |

削らないもの: 期間（12 週）・点の数・単位（万円）・最新値・範囲・出典。見た目の最小化であって、データの最小化ではない（S04。出典・期間・単位の明記は S14 と本 skill の整理）。

```text
店舗別の週次売上（万円）
最初の週と最新週を比べて下がったのは港店だけ（300 → 260）。ほかの 4 店は横ばいか上向き

店舗     最新週  前週比          12 週の範囲  12 週の推移（行ごとの尺度）
-------  ------  --------------  -----------  ---------------------------
駅前店      480  +8（+1.7 %）    410〜480     右上がりの線 ●
港店        260  −12（−4.4 %）   260〜310     右下がりの線 ●
南口店      255  +11（+4.5 %）   160〜255     5 週目に谷のある線 ●
西口店      198  +8（+4.2 %）    160〜198     谷から上向きの線 ●
丘の上店    152  +2（+1.3 %）    148〜153     平らな線 ●
```

- 並びは最新週の大きい順（本 skill の整理）
- 数値は HTML の文字で置く。線は補助で、数値を読めば同じ判断ができる

### 尺度の選び方（本 skill の整理）

| 尺度 | 起きること | 判断 |
|---|---|---|
| 全行で共通（0〜480） | 12 週の範囲が、描画域 18 px のうち 0.19〜3.56 px にしかならず、形が読めない（計算） | 採らない |
| 行ごと（最小〜最大） | 形は読める。高さは店どうしで比べられない | 採る。列見出しと注記に「行ごとの尺度」と書き、範囲を数で隣に置く |
| 行ごと + 最小幅 | 横ばいの行の小さな揺れを、大きな上下に見せない | 採る。最小幅は平均の絶対値の 10 %（目安。正の値の系列を想定する。平均が 0 に近い系列では最小幅も 0 に近づくので、固定の最小幅が要る） |

## 仕様

| 項目 | 値 | 根拠 |
|---|---|---|
| sparkline の性格 | 小さく単純で、文字と同じ解像度の図 | S01 |
| 描画域 | 96 × 24 px、余白 3 px | 本 skill の目安（出典なし） |
| 行の高さ | 36 px 以上（図 24 px + 上下 6 px。図を `display: block` にして隙間を作らない。区切り線 1 px を含めた実測は 37 px）。文字は 16 px | 本 skill の目安（出典なし） |

| 線 | 実線 1.5 px・1 色。終点だけに r = 2.5 の印 | 本 skill の目安。印は S70 を踏まえた整理 |
| 数値 | 最新週・前週比・範囲を、図の隣に文字で置く | S08 |
| 増減の表示 | 符号つきの数値と率。色で分けない | S60 |
| 出典・期間・単位 | 表の下に 1 行で書く | S14（期間・単位は本 skill の整理） |
| 区切り線 | 薄い灰色、行の下に 5 本 | S122 は図の格子線の上限（最大 10 本）。表の区切りは目安 |

座標の式（n は点の数、`v` は値）:

```text
x_i   = pad + i × (w − 2 × pad) / (n − 1)
span  = max(最大 − 最小, 0.10 × |平均|)
y_min = (最大 + 最小) / 2 − span / 2
y_i   = pad + (h − 2 × pad) × (1 − (v_i − y_min) / span)
```

検算（w = 96、h = 24、pad = 3。下のコードと、別に書いた Python の計算で一致を確認した）:

| 行 | 条件 | 結果 |
|---|---|---|
| 駅前店 | 範囲 70 > 平均の絶対値の 10 %（44.6）。span = 70 | 410 → (3.0, 21.0)、480 → (93.0, 3.0) |
| 港店 | 範囲 50。span = 50 | 最大 310（2 週目）→ y = 3.0、最新 260 → (93.0, 21.0) |
| 丘の上店 | 範囲 5 < 平均の絶対値の 10 %（15.07）。span = 15.07、y_min = 142.97 | 点の y は 9.0〜15.0（最小幅が無ければ 3〜21 に広がる）。最新 152 → y = 10.2 |
| 全点が同じ値 | 例 [5, 5, 5]。span = 0.5 | y = 12.0（中央）。0 除算にならない |

コントラスト比（WCAG の相対輝度式で計算。背景は #ffffff）:

| 要素 | 色 | 比 | 基準 |
|---|---|---|---|
| 文字 | #1d1d22 | 16.79 | 4.5:1（S63） |
| 補助の文字（列見出しの注記） | #4a4a55 | 8.74 | 4.5:1（S63） |
| 線・終点の印 | #1f5f8b | 6.84 | 図の必要な部分は 3:1（S61、S62） |
| 区切り線 | #d0d0d8 | 1.53 | 内容の理解に必要な部分ではないとして 3:1 を求めない（本 skill の判断） |

## コード断片

外部のライブラリ・スクリプト・フォント・計測は使わない。値は属性に設定し、HTML 文字列を組み立てない。

```js
// values: 有限の数値の配列（2 件以上）。label: 読み上げ用の説明。戻り値: SVG 要素。条件を満たさなければ null
function sparkline(values, label, w = 96, h = 24, pad = 3, minSpanRatio = 0.1) {
  if (!Array.isArray(values) || values.length < 2 || !values.every(Number.isFinite)) return null;
  const lo = values.reduce((a, b) => Math.min(a, b));
  const hi = values.reduce((a, b) => Math.max(a, b));
  const mean = values.reduce((a, b) => a + b, 0) / values.length;
  const span = Math.max(hi - lo, minSpanRatio * Math.abs(mean)) || 1; // 全点が同じ値でも 0 除算にしない
  const yMin = (hi + lo) / 2 - span / 2;
  const pts = values.map((v, i) => [
    (pad + (i * (w - 2 * pad)) / (values.length - 1)).toFixed(1),
    (pad + (h - 2 * pad) * (1 - (v - yMin) / span)).toFixed(1),
  ]);
  const NS = "http://www.w3.org/2000/svg";
  const svg = document.createElementNS(NS, "svg");
  svg.setAttribute("viewBox", `0 0 ${w} ${h}`);
  svg.setAttribute("width", w);
  svg.setAttribute("height", h);
  svg.setAttribute("class", "spark");
  svg.setAttribute("role", "img");
  svg.setAttribute("aria-label", label); // 属性への設定。HTML 文字列を組み立てない
  const line = document.createElementNS(NS, "polyline");
  line.setAttribute("points", pts.map((p) => p.join(",")).join(" "));
  // 見た目は属性で直接指定する（CSS が無くても、塗りつぶしでなく線として描ける）。値は下の CSS と同じ
  line.setAttribute("fill", "none");
  line.setAttribute("stroke", "#1f5f8b");
  line.setAttribute("stroke-width", "1.5");
  line.setAttribute("stroke-linejoin", "round");
  const last = pts[pts.length - 1];
  const dot = document.createElementNS(NS, "circle"); // 最新値だけに印を置く
  dot.setAttribute("cx", last[0]);
  dot.setAttribute("cy", last[1]);
  dot.setAttribute("r", 2.5);
  dot.setAttribute("fill", "#1f5f8b");
  svg.append(line, dot);
  return svg;
}
// 使い方（2 件未満、または有限でない値を含むと null が返るので、置く前に確かめる）:
// const svg = sparkline(values, "港店の 12 週の売上。最初 300、最新 260、最小 260、最大 310（万円）");
// if (svg) cell.replaceChildren(svg);
```

## 初見検証

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 港店だけが、最初の週より下がっている | 見出しの 1 文と、港店の右下がりの線 |
| 何を読み取れるか | 各店の最新週・前週比・12 週の範囲と、推移の形（南口店の 5 週目の谷など） | 数値の列と線 |
| どう読むか | 横は 12 週で右が最新。縦は行ごとの尺度で、店どうしの高さは比べない | 列見出しと注記 |

観察で確かめる: (1) 見出しを隠して線だけを見せ、「丘の上店は大きく動いているか」と聞く。範囲の列（148〜153）を見て「動いていない」と答えられるか。(2) 「港店と南口店のどちらが多く売れたか」と聞き、線の高さでなく数値で答えるか。どちらも答えられない場合は、注記と範囲の列の見せ方を直す。

## 点検

- 図の選び方: 値を引くだけなら数値の列で足りる。sparkline は、形（推移）を併せて見せたいときの追加で、5 店 12 週という規模は本 skill の例の設定
- 目標との比較が要る列は、sparkline でなく bullet graph を検討する（本 skill の整理）。bullet graph はゲージの置き換えとして設計され（S40）、直線の設計で読み取りが効率的、というのは Few の主張で、実験結果ではない（S41）
- 色: 線は 1 色で、系列の区別に使っていない（S60）。色を変えたらコントラスト比を再計算する。白黒印刷は、輝度の計算までで、実際の印刷は未確認
- 尺度: 「行ごとの尺度」を列見出しと注記の両方に書いた。最小幅の 10 % は目安で、読み手の観察で調整する
- 小さな上下に物語を作らない（偶然のパターンを読む偏りがある。S13）。港店が下がった原因や、下がりが偶然の範囲かは、この表から言えない（統計の判断は範囲外）
- 隣の領域: 数字の字形・桁のそろえは designer-typography、画面体験は designer-apple（いずれも導入されていれば）
- 画面の見え方は実機で確かめる
