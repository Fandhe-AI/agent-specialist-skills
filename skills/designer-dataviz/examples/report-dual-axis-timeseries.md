# 例: 月次の経営レポートの時系列比較（二軸を指数化に替える）

売上と広告費を 1 つの二軸グラフに重ねる依頼を、指数化した折れ線 1 枚と実数の表に組み替える例。月次レポートの時系列比較や、役員会のスライド 1 枚を作るとき、二軸の依頼を受けたときに開く。題材は架空の会社で、実在の製品・企業の図表は模倣しない。画面体験（カードの数・更新の動き）は扱わない。

## 依頼

- 会社: 架空の雑貨通販「ハルノ雑貨」。媒体は月次の経営レポート（PDF）と、役員会のスライド 1 枚
- 依頼文: 「売上と広告費を 1 つのグラフにまとめて。二軸で、動きが分かるように」
- 読み手: 役員 5 人。広告費を増やした月に売上も動いたかを確かめ、来月の広告予算を決める。二軸の読み方を学んでいるかは不明なので、学んでいない前提を置く
- 現状: 左軸（売上、100〜160）と右軸（広告費、0〜16）の折れ線 2 本。凡例あり。2 本は色だけで区別している

### 根拠の範囲（先に読む）

- 二軸は論争中で、避ける立場と条件つきで使う立場がある。Few は 2008 年に "I can’t think of a single case when there isn’t a better solution than a graph with a dual-scaled axis" と述べた（S38。区分 A）。Datawrapper は 2026-07 に "in some cases, dual-axis charts really are the best way to show the data" と見直し（S77）、一般の読み手は読み誤りやすいという元の批判は有効としている（S76）
- 二軸の実験的な根拠は、Datawrapper が引く 15 人の実験だけで（S129。区分 B。論文本体は未取得）、断定の根拠にしない
- 本例の図の選択（指数化を既定にする）は、S73・S75・S78 を踏まえた本 skill の整理である。数値の目安（縦横比・文字の大きさ・格子線の色）は規定ではない

## 目的の一文

役員が、広告費を増減した月に売上が同じ向きに動いたかを 1 枚で確かめ、来月の広告予算を議論する入口にする。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 右軸（広告費の別目盛り） | 軸の取り方で 2 本の位置関係が変わる（下の表）。ONS は、二軸を文章の "10 is bigger than 100" に例える（S73） |
| 凡例 | 色の照合を読み手に課す。折れ線は線を直接ラベルすれば凡例を避けられる（S67） |
| 色だけの系列の区別 | 色だけで意味を伝えない（S60）。実線と破線、丸と四角を併用する（S56） |
| 太い格子線・背景・枠 | 薄い灰色の格子線を最大 10 本に（S122）。飾りは削る（S70） |
| 「連動」「効果」など因果を示す語 | この図は因果を示せない（本 skill の整理）。同じ向きに動いた、までを言う |

残すもの: 単位・期間・出典・各月の値。Tufte は、図にデータの出どころと分析の過程の文書化を添えるよう述べる（S14）。単位と期間を添えるのは本 skill の整理である。

同じデータでも、二軸の取り方で見え方が変わる。各月の位置（縦軸の高さに対する割合 %）を計算した結果:

| 設定 | 売上 4 月 → 9 月 | 広告費 4 月 → 9 月 | 見え方 |
|---|---|---|---|
| A: 左 100〜160・右 0〜16 | 33.3 → 98.3 | 50.0 → 80.0 | 6 月と 7 月の間で 2 本が交差する |
| B: 左 100〜160・右 8〜13 | 33.3 → 98.3 | 0.0 → 96.0 | 7 月と 9 月に 2 本がほぼ重なる |
| C: 左 0〜180・右 0〜18（ともに 0 起点、6 区間） | 66.7 → 88.3 | 44.4 → 71.1 | 売上が常に上。交差しない |

C は S78 の 2 つのルール（目盛りの伸び率をそろえる・一方が 0 起点ならもう一方も 0 起点）に沿った設計の一例で、「6 区間にそろえた」という具体化は本 skill の解釈である。A と B はデータが同じでも、交差や重なりという別の物語を作る。

- 折れ線 1 枚（指数）と、実数を載せた表を 1 組にする。2 つの図に分ける案（上に売上、下に広告費。横軸をそろえる）も有力で、実数の形を見せたいときはこちらを選ぶ。どちらも二軸を使わない
- 二軸を残すなら、読み手を二軸の読み方を学んだ人（たとえば金融の実務者。S77）に限り、上の C のように両軸の起点と間隔をそろえ、軸の起点と単位を図に書く（S78）。指数化も併せて検討する（S78）
- スライドの 1 枚も同じ図と見出し。表は配布資料に回す（本 skill の整理）

見出しの数値の検算: 広告費 12.8 ÷ 8.0 = 1.6（+60 %）、売上 159 ÷ 120 = 1.325（+32.5 %）。5 つの月間変化（4→5、5→6、6→7、7→8、8→9 月）で、売上と広告費の増減の向きは 5 つとも一致した（下のコードの出力）。

## コード断片

外部のライブラリ・スクリプト・フォント・計測は使わない。まず指数と座標を計算する（標準ライブラリのみ）。

```python
months = ["4月", "5月", "6月", "7月", "8月", "9月"]
sales = [120, 126, 138, 150, 147, 159]       # 売上（百万円）
ads = [8.0, 8.8, 10.4, 12.0, 11.2, 12.8]     # 広告費（百万円）
X0, X1, Y0, Y1, LO, HI = 56, 440, 240, 30, 80, 180

def index(xs):
    return [round(x / xs[0] * 100, 1) for x in xs]

def px(i):
    return round(X0 + i * (X1 - X0) / (len(months) - 1), 1)

def py(v):
    return round(Y0 - (v - LO) / (HI - LO) * (Y0 - Y1), 1)

for name, xs in (("売上", sales), ("広告費", ads)):
    idx = index(xs)
    print(name, idx)
    print(" ".join(f"{px(i)},{py(v)}" for i, v in enumerate(idx)))
same = [(sales[i + 1] - sales[i]) * (ads[i + 1] - ads[i]) > 0 for i in range(5)]
print("同じ向き:", all(same))
```

## 初見検証

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 広告費と売上が毎月同じ向きに動いている | 見出しの 1 文 |
| 何を読み取れるか | 9 月は 4 月比で広告費 +60 %、売上 +32.5 %。広告費のほうが伸びが大きい。狭い画面でも、どちらが広告費の線かが初期表示で分かる | 線の両端のラベルと見出し |
| どう読むか | 縦軸は指数（4 月 = 100）で、80 から始まる。実数は表で見る | 縦軸の見出しと表 |

5 人程度（本 skill の目安）に、見出しを隠して図だけを見せ、「広告費と売上のどちらが大きく伸びたか」「因果は言えるか」を尋ねる。「言える」と答える人がいれば、補足の文言を前に出す。「二軸のほうが分かりやすい」と答える人が多い読み手なら、読み手を限った二軸の案（上の C）を検討する。

## 点検

- メッセージ: 図が言うことを数文で書けた。見出しの数値と表が一致する（検算済み）
- 軸: 縦軸が 0 起点でないことを図に書いた。折れ線では軸の操作が妥当な場合がある（S74）。一方、切り詰めを示す手がかりがあっても、主観的な影響は続くという研究がある（S98）ので、実数を表で併記した
- 色: 色を取り除いても、線種・記号・直接ラベルで 2 本を区別できる。比の計算は上のとおり（色を変えたら再計算）
- 二軸: 二軸を使わない。依頼者が二軸を求める場合は、読み手が読み方を学んでいるかを確認し、学んでいなければ指数化の理由（S73、S75、S78）を伝える
- 因果: 同じ向きに動いたことと、広告費が売上を動かしたことは別の話で、後者は統計的な検討が要る（範囲外）。偶然のパターンを読む偏りにも注意する（S13）
- 未確認: 図中の文字の大きさ・縦横比は目安で、出典を取得していない。印刷の仕上がりは実際の印刷で確かめる
