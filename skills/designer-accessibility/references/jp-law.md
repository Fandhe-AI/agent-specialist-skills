# 国内の制度の位置づけ

ウェブアクセシビリティについて、国内の制度が何を求め、何を求めていないかを、一次資料の文言で説明するための参照。「ウェブアクセシビリティは義務化されたのか」「合理的配慮と何が違うのか」「JIS 準拠と書いてよいか」と聞かれたとき、`../SKILL.md` の判断の型の 11 から開く。**法的な助言ではない。** 個別の事業者に何が義務か、どう表記すれば足りるかは判断しない。2026-11-16 時点の一次資料の照合で、「その文書がそう書いている」という事実として扱う。出典の詳細は `sources.md`。

## 先に読む

- 法令の現行の条文は、e-Gov 法令検索の 2026-11-02 時点のもの（S078 の媒体欄）。以後の改正は反映していない
- デジタル庁のガイドブックは、記載の厳密な正確性や網羅性を担保しないと自ら書く（S089）。区別の根拠は法文（S079・S081）と基本方針（S086・S087）に置く
- 国内の訴訟・苦情の統計は、台帳に無い。米国の数値を国内に当てはめない（S111・S113）
- 本 skill の整理（推測）と書いた箇所は、出典が述べていない応用

## 区別の要点（合理的配慮の提供と環境の整備）

| 区分 | 何か | 誰に | 義務の強さ | 根拠 |
|---|---|---|---|---|
| 社会的障壁 | 障害がある者にとって日常生活・社会生活で障壁となる、社会の事物・制度・慣行・観念その他一切のもの | - | - | S078・S210 |
| 合理的配慮の提供 | 障害者から現に社会的障壁の除去を必要としている旨の意思の表明があった場合に、負担が過重でないとき、必要かつ合理的な配慮をする | 行政機関等 | しなければならない（制定時の版から） | S080・S101 |
| 合理的配慮の提供 | 同上 | 事業者 | しなければならない（現行）。改正前は「努めなければならない」 | S081・S082 |
| 環境の整備 | 合理的配慮を的確に行うための、施設の構造の改善・設備の整備・関係職員への研修その他の必要な環境の整備 | 行政機関等・事業者 | 努めなければならない | S079 |
| 情報アクセシビリティの向上 | 基本方針は、障害者による円滑な情報の取得・利用・発信のための情報アクセシビリティの向上を、事前的改善措置として環境の整備に位置づける | 行政機関等・事業者 | 努力義務 | S086 |
| 情報の取得・意思疎通 | 障害者が必要とする情報を十分に取得・利用し、意思疎通を図れるようにするよう努める | 事業者 | 努める | S093 |

- 合理的配慮は、個別の場面で、意思の表明を受けて行う。環境の整備は、不特定多数の障害者を主な対象とする事前の改善である（S086）
- 基本方針の例: オンラインの申込手続のウェブサイトが利用しづらく、支援を求める申出があったとき、電話や電子メールで対応するのが合理的配慮の提供、以後、不便を感じないようにウェブサイトを改良するのが環境の整備（S087）
- デジタル庁のガイドブックは、2024 年 4 月 1 日から改正法が施行され、事業者による合理的配慮が義務化されること、ウェブアクセシビリティへの取り組みは、合理的配慮を提供するための環境の整備として努力義務であることを書く（S088）
- 本 skill の整理（推測）: 環境の整備が進んでいないと、個別の対応の負担が大きくなる。S087 の例は、この関係を示す例として読める

- 行政機関等の合理的配慮の提供は、施行当初から義務で、2024 年に義務になったのは事業者（S080・S081・S101）

## 規格と表記

| 項目 | 内容 | 根拠 |
|---|---|---|
| JIS X 8341-3 の経緯 | 2004 年 6 月に初めて制定。2010 年 8 月に WCAG 2.0 を包含して改正。2012 年 10 月に WCAG 2.0 が ISO/IEC 40500:2012 になった。2016 年 3 月に、その一致規格となる JIS X 8341-3:2016 に改正 | S094 |
| 一致の意味 | JIS X 8341-3:2016 は ISO/IEC 40500 と完全一致する形へ改正された。したがって達成基準の中身は WCAG 2.0 | S102・S094 |
| 国ごとの違い | 規格が同じ内容になり、国ごとに違うガイドラインや規格を使う必要がなくなった | S090 |
| 対応度の表記 | 「準拠」「一部準拠」「配慮」の 3 つ。「配慮」は、準拠・一部準拠に至らない場合に使う | S095 |
| JIS マーク | JIS X 8341-3:2016 は JIS マーク表示制度の対象規格ではない。適合したものに JIS マークを付ける行為はできない | S096 |
| 試験の範囲 | WAIC は、総ページ数が 100 ページを超えるとき方式 d) を推奨し、合計 40〜50 ページ程度を試験対象にするとよいとする | S097 |
| 改正の動き | 国際規格 ISO/IEC 40500 が 2025 年 9 月に WCAG 2.2 と同内容になったことを受け、JIS X 8341-3 の改正を検討している。方針は、ISO/IEC 40500:2025 との一致規格とし、日本独自の内容は付属書（参考）に分ける。改正版の公示は未確認 | S098・S099・S103 |
| 達成基準の数 | JIS X 8341-3:2016 は 61。WCAG 2.2 に基づいて改正されたら 86 になる見込み。A と AA は 38 から 55 に増える見込み（総務省） | S092 |
| 日本語訳 | WAIC の W3C 文書の日本語訳は、W3C Document License に準じる条件で利用できる。正式版は W3C のサイトの英語版 | S100 |

- 「JIS 準拠」と言うとき、中身は WCAG 2.0 の達成基準（S094・S102）。2.2 で足された 9 基準（S038。ターゲットの大きさ・焦点が隠れないことなど）は、JIS X 8341-3:2016 の要件ではない（本 skill の整理）。2.1 の追加分も同じ
- 表明する版と作る版を分ける。2.0 や 2.1 を求められる組織も、2.2 に更新できる。ただし 4.1.1 の試験・報告が残る場合がある（S003）。W3C は最新版の使用を勧める（S039）
- 総務省の運用ガイドライン（2024 年版）: 構築前にウェブアクセシビリティ方針を策定し、構築時に適合レベル AA に準拠（試験の実施と公開）し、できる限り WCAG 2.2 の達成基準に基づいて構築する（S091）

## 試験結果の公開ページに書くこと

本 skill の整理（推測）。表記の方式は WAIC の文書（S095・S097）、方針の位置づけは総務省（S091）による。

| 項目 | 書くこと | 注意 |
|---|---|---|
| 対象 | 試験したウェブページの範囲と数 | 全体を試験していないのに全体の準拠と書かない（S097 の目安は、100 ページ超なら方式 d)・合計 40〜50 ページ程度。ページの選び方の内訳は引用に無く、WAIC のガイドラインで確かめる） |
| 版 | 基準の版（JIS X 8341-3:2016）と適合レベル | JIS X 8341-3:2016 の中身は WCAG 2.0（S094・S102）。2.2 の基準を試験したなら、別に書く |
| 日付 | 試験した日 | 古くなったら更新する |
| 結果 | 準拠・一部準拠・配慮のいずれか（S095） | JIS マークを付けない（S096） |
| 未対応 | 未対応の項目と、今後の予定 | 「適合した」と書かない。未確認と未対応を分ける |
| 窓口 | 個別の申出を受ける窓口（合理的配慮の提供の入口） | サイトの改修（環境の整備）と、個別の申出への対応を混同しない（S087） |

- 公開の判定の例: デジタル庁は、コンテンツ単位の JIS 試験通過をリリース判定の条件とし、AA に準拠できていない状態ではコンテンツを公開しない、と書く（S168。同庁の運用の自己説明で、他の組織に求められる運用ではない）

## 海外（参考・時点情報）

国内の制度の相談では、対象外の背景として短く触れるだけにする。数値は誰が・いつ・どの範囲で数えたかを添える。

| 項目 | 内容 | 根拠 |
|---|---|---|
| EU | 欧州アクセシビリティ法（Directive (EU) 2019/882）は 2025-06-28 から適用。サービス提供者が従来から適法に使っていた製品を使い続けられる経過措置は 2030-06-28 まで。サービスを提供する零細事業者（microenterprises）は、同条の一定の要件と、その遵守に関わる義務が免除される | S104・S105 |
| 米国（連邦） | Section 508 の改定（最終規則 2017-01-18）は、電子コンテンツに WCAG 2.0 の A と AA を求める | S106・S109 |
| 米国（州・地方政府） | ADA Title II の最終規則（2024-04-24）は WCAG 2.1 の AA。適合期限は、2026-04-20 の暫定最終規則で、人口 5 万人以上は 2027-04-26、5 万人未満は 2028-04-26 に延びた | S107・S108 |

| 米国の判断 | 第 9 巡回区控訴裁判所は 2019 年、Domino's のサイトとアプリに ADA が及ぶとした地裁の判断に同意した（この事件での判断）。DOJ は 2022 年のガイダンスで、ADA の要件が Web で提供されるものにも及ぶ立場を示した | S114・S115 |

## 答え方の型

1. 何についての相談かを分ける: (a) 個別の申出への対応、(b) サイトを事前に直すこと、(c) 試験結果の表記、(d) 調達・契約の要件
2. (a) は合理的配慮の提供（事業者も 2024-04-01 から義務。S081・S084）、(b) は環境の整備（努力義務。S079・S086・S088）と答える。S087 の例を添える
3. (c) は WAIC の表記の 3 つ（S095）と JIS マークの扱い（S096）で答える。版は JIS X 8341-3:2016（WCAG 2.0）か、2.2 かを分けて書く
4. (d) と、個別の事業者に何が義務か・法的な責任の有無は、判断しない。専門家（弁護士など）に確認するよう伝える
5. 「義務化された」という言い方を聞いたら、何が義務化されたのかを聞き返す。義務になったのは事業者の合理的配慮の提供で、ウェブの事前の対応は環境の整備である（S081・S086・S088）
