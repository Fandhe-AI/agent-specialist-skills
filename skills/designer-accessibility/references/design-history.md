# 制度と規格の歴史・障害の捉え方

アクセシビリティの基準・制度・確かめ方が、どういう制約への応答として今の形になったかを、時代ごとにまとめる。「なぜ 4.1.1 は消えたのか」「JIS 準拠と WCAG 2.2 は何が違うのか」「社会モデルとは何か」と聞かれたとき、または制作の着手前に基準の版を確かめるときに開く。因果は、出典が述べている場合だけ S 番号つきで書く。出典が述べていない結びつきは「本 skill の整理（推測）」と書く。出典の詳細は `sources.md`。法的な助言ではない。国内の制度の位置づけは `jp-law.md`。

## 繰り返すパターン（本 skill の整理）

- 基準は、書かれた時代の技術を前提にする。技術が変わると、基準は改まる（4.1.1 は、支援技術が HTML を直接解析しなくなったために削除された。S004）。古い基準の項目を、今の画面に無条件に当てはめない
- 検査できる基準は、チェックリストになる。W3C 自身が、チェックリストとして扱うと技術面だけに目が行き、人の操作の面が失われると書く（S218）
- 規格と制度の版がずれる。法が規格の版を参照すると、規格の更新と法の参照の版が一致しなくなる（JIS は 2.0 と一致、ADA Title II は 2.1、ISO・EN は 2.2。S094・S107・S041）
- 自動化への期待と反動が交互に来る。ツールの限界の測定（S129）、ベンダーの割合の主張（S132）、手動との比較（S135）、オーバーレイへの批判（S221・S224）
- 部品の既定値が良くなると、「ライブラリを使ったから大丈夫」という誤解が起こりうる（本 skill の整理。出典は無い。ライブラリ自身が「fully accessible」と自己紹介する例は S243。区分 C）

## 規格と制度の変遷

### 時代 1: 最初の指針（1997〜2004）

- 当時の制約（本 skill の整理・推測）: ウェブの技術（HTML の版・スクリプト・支援技術）が定まらず、指針は特定の技術に寄りやすかった。WCAG 1.0 の本文は台帳に無く、技術依存の度合いは未照合
- 応答: W3C が WAI を発足させ（1997-04-07）、Berners-Lee は、個人の能力や障害に関わらず誰もが Web を使えることが「critical」だと述べた（S202。「critical」は引用ブロックの原語）。WCAG 1.0 が 1999-05-05 に勧告（S203）。米国は 1998 年に Rehabilitation Act を改正し、連邦機関の電子・情報技術にアクセシビリティを求め（S110）、Section 508 の原基準を 2000-12-21 に出した（S109）。日本は 2004 年 6 月に JIS X 8341-3 を初めて制定し、日本語特有の事項も網羅した独自の指針だった（S094）
- 副作用と反動: 国・団体ごとに別の指針が並んだ。デジタル庁は後に、規格が同じ内容になったことで、「国ごとに違うガイドラインや規格を使う必要がなくなりました」と書く（S090）。裏返せば、それ以前は国ごとに別だったと読める（本 skill の整理）
- 今の示唆: WCAG 1.0 は superseded（S201）。古い資料の項目を今の要件として持ち出さない

### 時代 2: 技術に依らない基準と国際規格化（2008〜2016）

- 当時の制約（本 skill の整理・推測）: 技術ごとに書くと古くなる
- 応答: WCAG 2.0 が 2008-12-11 に公開された（S040）。W3C は、より正確に検査でき、作り手に柔軟性がある、と掲げた（S204）。達成基準と、参考の Techniques を分けた（Techniques は必須ではない。S033）。JIS は 2010 年 8 月に WCAG 2.0 を包含して改正され、WCAG 2.0 が ISO/IEC 40500:2012（2012 年 10 月）になったのを受けて、2016 年 3 月に一致規格へ改正された（S094）
- 副作用と反動: W3C は、Techniques を調達の要件にすることに注意を促す（S033）。注意書きがある事実は確かめたが、誤用がどの程度広がったかは未確認
- 今の示唆: 国内で「JIS 準拠」と言うとき、中身は WCAG 2.0 の達成基準（S090・S102）。2.2 で足された基準は、含まれない

### 時代 3: 調達と法の結びつき（2016〜2018）

- 当時の制約（本 skill の整理・推測）: 規格はあっても、守る理由は各組織の判断に委ねられていた
- 応答: 日本は障害者差別解消法が 2016-04-01 に施行（S085）。制定時の版で、行政機関等の合理的配慮の提供は義務、事業者は努力義務（S101）。米国は 2017-01-18 に Section 508 を改定し、電子コンテンツに WCAG 2.0 の A と AA を求めた（S109・S106）。WCAG 2.1 が 2018-06-05 に公開（S040）
- 副作用と反動: 法が規格を参照すると、規格の更新と参照の版がずれる（S106 は 2.0）
- 今の示唆: 「どの版で表明するか」と「どの版で作るか」を分ける。2.2 は 2.1・2.0 を廃止せず（S039）、2.0・2.1 を求められる組織も 2.2 に更新できる。ただし 4.1.1 の試験・報告が残る場合がある（S003）

### 時代 4: 合理的配慮の義務化と情報アクセシビリティ（2021〜2024）

- 当時の制約（本 skill の整理・推測）: 事業者の合理的配慮は努力義務で、民間の取り組みに差があった
- 応答: 令和三年法律第五六号（公布 2021-06-04。S083）で、事業者の合理的配慮の提供が義務になり（S081。改正前は努力。S082）、施行は 2024-04-01（S084）。2022-05-25 に、情報アクセシビリティ・コミュニケーション施策推進法（事業者は努める。S093）。2023-03-14 の基本方針は、情報アクセシビリティの向上を環境の整備に位置づけ（S086）、ウェブの例で合理的配慮と環境の整備を区別した（S087）。デジタル庁のガイドブックも同じ整理（S088）
- 副作用と反動: 「ウェブアクセシビリティが義務化された」という言い方が流通する。一次資料の整理（S086・S088）と食い違う。どの程度広がったかは未測定
- 今の示唆: 相談では二つを分けて答える（`jp-law.md`）。法的な判断は専門家に委ねる

### 時代 5: WCAG 2.2 と各制度の追随（2023〜2026）

- 当時の制約: WCAG 2.2 は前進しつつ、すべての必要は満たさないと自ら書く（S002）
- 応答: WCAG 2.2（2023-10-05）は 9 基準を追加し 4.1.1 を削除（S038・S040）。焦点が隠れない（S022）、ドラッグの代替（S024）、ターゲットの大きさ（S025）、一貫した助け（S026）、冗長な入力（S028）、認証（S029）。ISO/IEC 40500:2025 は 2.2 の 2023 年 10 月版と同一（S041）。JIS は、ISO/IEC 40500:2025 との一致規格とする方針で検討中（S098・S099）。EU の EAA は 2025-06-28 から適用（S104）。ADA Title II は 2.1 AA（S107）で、適合期限は 2026-04-20 の暫定最終規則で 2027-04-26・2028-04-26 に延びた（S108）
- 副作用と反動: 版の混在が続く。2024 年 12 月の 2.2 の更新は、ISO/IEC 40500:2025 に反映されていない（S041・S098）。24 px は、作業部会が多くのサイトの平均のターゲットの大きさを見て選んだ値（S035）
- 今の示唆: 新規の設計は WCAG 2.2 の AA を基準に置く（W3C は最新版の使用を勧める。S039）。日本語の基準名で照合するときは、訳の版を確かめる（訳の更新は S099 の告知のページを見る）

### 時代 6: 次の世代の草案（2026〜）

- 応答: WCAG 3 の作業草案（2026-09-10 の版。S042）。W3C は、WCAG 3 は数年は完成せず、完成後も数年は WCAG 2 を廃止しないとし、今は 2.2 を満たすのが最善の準備だと書く（S044）。WCAG 2 の AA を満たせば WCAG 3 に近いが、違いはありうる（S043）。Using ARIA は 2026-02-24 に廃止扱いの草案になった（S063）
- 今の示唆: WCAG 3 の要件を、今の設計の根拠にしない。ARIA の第 1 規則は、規範の文書（S047・S060）を根拠に言い直す

## 障害の捉え方

| 見方 | 内容 | 根拠 |
|---|---|---|
| 社会モデル（源流） | 1975 年の UPIAS の討議の記録は、障害を、損傷の上に社会が課すものとして書く（原文は S206 の引用ブロックの英語） | S206 |
| 権利条約 | 障害は、機能障害のある人と、態度・環境の障壁との相互作用から生じる（前文 (e)。2006 年採択）。第 9 条は、情報通信技術を含むアクセシビリティを求める | S207・S208 |
| 国内の定義 | 社会的障壁は、障害がある者にとって日常生活・社会生活で障壁となる社会の事物・制度・慣行・観念その他一切のもの | S078・S210 |
| 規模 | 約 13 億人、世界人口の 16% が重い障害を経験（WHO のファクトシート、2023-03-07） | S211 |
| ユニバーサルデザイン | 適応や特別な設計なしに、できる限り全ての人が使える製品・環境の設計（NC State。1997 年の版）。同センターは、資金難で現在は活動していない（S213） | S212・S213 |
| インクルーシブデザイン | 人間の多様性の全域に基づく方法論（Microsoft）。一人ひとりに合わせた構成が最適（IDRC）。恒久的・一時的・状況的・変化する障害の必要を設計する（Inclusive Design Principles） | S214・S215・S216 |
| 縁石の切り下げ | 物理環境の障壁を直した例。1972 年に公式の最初の設置 | S217 |

- 医学モデルの一次資料は、台帳に無い（確認できなかったもの）。「医学モデル」「社会モデル」の語の出どころも未確認。UPIAS の文（S206）と権利条約の文（S207）は、障害を環境との相互作用で捉える見方の根拠として示すにとどめる
- 本 skill の整理（推測）: 相談を受けたら、「その人の何が足りないか」ではなく、「画面・手順・環境の何が締め出しているか」から問う。出典（S206・S207・S210）の定義に沿う
- 「皆のためになる」という言い方は、障害のある人の必要を、一般の使いやすさへ溶かす危険がある（本 skill の整理）。WAI は、使いやすさの実践・研究が、障害のある人の必要をしばしば考慮しないと書く（S219）。縁石の切り下げの話を、障害者の必要を後回しにする理由にしない
- 批判: Disability Dongle（障害者のための技術が、当事者の懸念にもかかわらず主流の注目と賞賛を集める。S227。区分 C）。共感だけでは、技術企業の質の高い注意を支え続けられない（S228。区分 C）。疑似体験やペルソナの演習は、作り手と障害者を切り離しうる（Bennett & Rosner。S229 の二次引用。区分 B）
