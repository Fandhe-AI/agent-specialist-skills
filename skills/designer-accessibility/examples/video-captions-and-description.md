# 例: 動画の字幕・音声解説・書き起こし（大学の公開講座）

架空の大学の公開講座の動画ページで、字幕・音声解説・書き起こしを、見た目の設計の段階で置き場を決め、動画の内容を音を聞かなくても、画面を見なくても得られるようにする例。題材は架空で、実在の製品・企業の画面の模倣は含まない。「動画に字幕を付けたい。音声解説と書き起こしも要るのか」と相談されたとき、動画の代替の種類と置き場、確かめ方を決めるときに開く。図の代替は designer-dataviz（導入されていれば）、文言の書き方は designer-ux-writing（同）。監査の手順は `audit-report-transit-status.md`。

## 依頼

- 製品: 架空の「あかね大学」の公開講座「庭木の剪定入門」第 3 回（約 12 分）の動画ページ（架空）
- 依頼文（架空）: 「講座の動画ページを作りたい。字幕は付ける予定。音声解説と書き起こしは、必要になったら後で考えたい。受講者には耳の聞こえにくい人も、見えにくい人もいる」
- 現状（前の版。架空）: 動画だけが置かれ、字幕・書き起こしは無い。ページを開くと、動画が自動で再生される
- 想定ユーザー: 耳が聞こえない・聞こえにくい人、目が見えない・見えにくい人、音を出せない場所で見る人、キーボードだけで操作する人、画面の読み上げを使う人
- 範囲外: 動画の中身（講義の内容）、実際の動画・字幕・音声のファイル、日本語の字幕の表記・表示時間の実務（台帳に出典が無い）、1.2.2・1.2.3・1.2.5 の例外の全文（WCAG 2.2 本体で確かめる）

### 根拠の範囲（先に読む）

- 出典のある事実: 字幕は、話し声と、理解に要る話し声以外の音の文字による版で、プレーヤー内に音声と同期して表示される。多くは、見る人が隠す・表示できる（S173）。音声解説は、内容の理解に要る視覚情報を説明し、台本に織り込む・別の動画・別ファイルの 3 つの方式がある。台本に織り込む方式は、多くの研修の動画に向くが、物語の動画には向かないことが多い（S174）。デザインの中に、画像とメディアの代替の置き場を用意する（S175）。自動で 5 秒を超えて動くものには、止める手段が要る（S019）。点滅の基準（S020）。キーボードで全機能（S018）
- 台帳の補足の参照（要旨のみ。W3C の書き起こしのページ）: 基本の書き起こしと、視覚情報を含む説明つきの書き起こしがある。この例は後者を使う
- 達成基準（S008。台帳の引用は見出しと本文の最初の部分で、例外の全文は WCAG 2.2 本体で確かめる）: 1.2.2 字幕（収録済み。レベル A）、1.2.3 音声解説またはメディアの代替（収録済み。A）、1.2.4 字幕（ライブ。AA。この例は収録済みなので該当なし）、1.2.5 音声解説（収録済み。AA）
- 台帳に原文が無い: 音声のみ・映像のみ・手話などの他の時間依存メディアの基準（未照合）
- 本 skill の目安（出典なし）: 配置の順序、文言、寸法、色。時刻の表記
- 外れる点: 書き起こしを動画の下に全文で置くか、折りたたむか、別ページにするかは、長さと使われ方で決める。この例は 12 分の動画を全文で同じページに置く

## 目的の一文

講義の動画を、音を聞かなくても、画面を見なくても、同じ内容が得られる 3 つの代替（字幕・音声解説・書き起こし）つきで公開し、その置き場を、見た目の設計の段階で決める。

## 削るもの

| 削るもの | 理由 | 代わりに |
|---|---|---|
| 自動再生 | 自動で始まり、5 秒を超えて動き、他の内容と並ぶ情報には、止める手段が要る（S019）。音を出せない場所では迷惑にもなる（本 skill の整理） | `controls` を付け、自動再生しない。`preload="none"` |
| 字幕を後回し | 字幕は、話し声と、理解に要る話し声以外の音を含む（S173） | 公開前に、字幕のファイルを付ける |
| 字幕を映像に焼き込む（常に表示） | 多くの字幕は、見る人が隠す・表示できる（S173） | 字幕のファイルを別に持つ |
| 要約を「書き起こし」と呼ぶ | 書き起こしは、話し声と音と画面の説明を欠かさない（本 skill の整理。補足の参照の「説明つきの書き起こし」） | 時刻つきの全文 |
| 音声解説を「必要になったら」 | 音声解説は、内容の理解に要る視覚情報（指差し・印・図）を説明する（S174）。後から台本を直すと、収録をやり直しうる（本 skill の整理） | 台本の段階で、解説を織り込む |
| 代替の置き場を決めない | デザインの中に、置き場を用意する（S175） | プレーヤーの直下に「この動画の別の見方」 |

## 構成

| 順 | 領域 | 内容 |
|---|---|---|
| 1 | 見出し・概要 | 講座名と回、長さ |
| 2 | プレーヤー | 動画。字幕のトラック。再生中の情報を、画面の外にも書き起こす |
| 3 | この動画の別の見方 | 字幕・音声解説つきの動画・書き起こし。プレーヤーの直下 |
| 4 | 書き起こし | 時刻つき。話し声・音・画面の説明を区別して書く |

## 仕様

### 3 つの代替

| 代替 | 内容 | 方式・注意 | 根拠 |
|---|---|---|---|
| 字幕 | 話し声と、理解に要る話し声以外の音（［ハサミを置く音］など）の文字による版。話者名を付ける | 見る人が隠す・表示できる。プレーヤー内で音声と同期する | S173・S008（1.2.2） |
| 音声解説 | 内容の理解に要る視覚情報の説明（先生が低い枝を指差す。切る位置に赤い印のテープがある） | 台本に織り込む方式（多くの研修の動画に向く）。別の動画・別ファイルの方式もある | S174・S008（1.2.3・1.2.5） |
| 書き起こし | 話し声・音・画面の説明を、時刻つきで 1 つの文章にする | 画面の説明は、先頭に「画面の説明:」と書く。色だけで区別しない。1.2.3 の「メディアの代替」に当たるかは、引用だけでは決まらない（判定保留） | 補足の参照（要旨）。S008 |

### 達成基準との対応（S008。判定は実際のメディアで）

| 基準 | レベル | この例の対応 | 結果（この例の範囲） |
|---|---|---|---|
| 1.2.2 Captions (Prerecorded) | A | 字幕のトラックを付ける（話し声と音） | 未確認（字幕の同期・内容は実メディアで） |
| 1.2.3 Audio Description or Media Alternative (Prerecorded) | A | 音声解説つきの動画と、画面の説明つきの書き起こし | 未確認（書き起こしが「メディアの代替」に当たるかは判定保留） |
| 1.2.5 Audio Description (Prerecorded) | AA | 音声解説つきの動画（台本に織り込む） | 未確認（実際の音声解説は未制作） |
| 1.2.4 Captions (Live) | AA | 収録済みのため、ライブの字幕は対象外 | 該当なし |

### 置き場と動き

| 項目 | 仕様 | 根拠 |
|---|---|---|
| 置き場 | プレーヤーの直下の「この動画の別の見方」に、字幕・音声解説つきの動画・書き起こしを並べる | S175 |
| 自動再生 | しない | S019 |
| 操作 | プレーヤーの操作は、キーボードだけでできる。実際のメディアで確かめる（この例は未確認） | S018 |
| 点滅 | 台本・映像の段階で、1 秒に 3 回を超える点滅を入れない | S020 |
| 下地 | メディアのファイルが無くても、16:9 の暗い下地と寸法を保つ | 本 skill の整理 |
| 読み上げ | プレーヤーに、見出しの文で名前を付け（`aria-labelledby`）、字幕・音声解説・書き起こしがあることを言う文を、説明として結ぶ（`aria-describedby`）。実測では、動画の要素はアクセシビリティツリーに出て、名前が空のままになりうる | 本 skill の整理・実測 |

### ダークの配色（`prefers-color-scheme: dark`）

ダークは、同じ変数を入れ替える（地 #12170F・文字 #E9EFE4・補助の文字 #B9C6B1・線 #8C9E83・緑 #8FCB6E・緑の上の文字 #10200A・面 #1C2418・焦点の輪郭 #F4F8EF・警告 #E9B949・誤り #FF9F8A）。色は WCAG の相対輝度式（S013）で計算した。文字は 4.5:1（S011）、境界・状態・焦点の輪郭は 3:1（S016）以上を目安にする。焦点の輪郭は、オフセット 2 px で隣が地になり、緑のボタンに接する（オフセット 0）と #F4F8EF / #8FCB6E は 1.79:1 で 3:1 未満になる。強制カラーでは色を上書きされるので、印は形（下線・輪郭の太さ）にも持たせる。

## 文言

| 場所 | 文言 | 意図 |
|---|---|---|
| 別の見方の見出し | 「この動画の別の見方」 | 3 つの代替をまとめて予告 |
| 字幕 | 「字幕: 見る人が、表示するか隠すかを切り替えられます（話し声と、内容に関わる音を含みます）。」 | 字幕に含まれるものを言う |
| 音声解説 | 「音声解説つきの動画（画面の内容を、別の声で説明します）」 | 何が違うかを言う |
| 書き起こし | 「書き起こし（画面の説明を含みます）」 | 画面の説明が入っていると予告 |
| 画面の説明 | 「画面の説明: 先生が低い枝を指差す。切る位置に、赤い印のテープが巻いてある。」 | 色（赤）は、画面の事実として書く。文字の色では区別しない |
| 音の表記 | 「［ハサミを置く音］」 | 角括弧で、話し声ではないと分かるようにする |
| プレーヤーの下の文 | 「この動画には、字幕・音声解説つきの動画・書き起こしがあります。動画を再生できないときは、下の書き起こしを読めます。」 | 代替の存在と、再生できないときの案内。動画の要素の中に書いた文は描画されないので、動画の外に置く |

## 点検

### 実測したもの（Chrome 157・ヘッドレス、2026-11-16）

| 項目 | 結果 |
|---|---|
| ツリー | 「画面の説明:」は HTML の本文の文字で、段落の文字としてツリーに出る（`::before` ではない）。`ariaSnapshot` では、h1・動画の下の文・h2・領域「この動画の別の見方」（リンク 2 つ）・領域「書き起こし（画面の説明つき）」。動画の要素は `ariaSnapshot` には出ず、ブラウザーのアクセシビリティツリー（CDP）では Video として出る。名前は h1 の文、説明は動画の下の文 |
| Tab の順路 | プレーヤー（メディア未読込の状態で 3 回止まる）→ 別の見方の 2 つのリンク → 末尾 |
| 幅 320・390 px | はみ出さない |
| 文字だけ 200%（作成者の CSS・文字サイズ設定 32） | どちらもはみ出さない（作成者の CSS は 1280 px と 320 px の両方） |
| 強制カラー | 焦点の輪郭は実線 3 px |
| 色の比 | 仕様の表の値 |
| ダーク | 本文 15.52:1・時刻 10.19:1・リンク 8.32:1・画面の説明の線 6.35:1・焦点の輪郭 16.90:1。幅 320・390 px ではみ出さない。強制カラーで輪郭は実線 3 px。動き 0 |
| 動きを減らす設定 | 作成者の CSS のアニメーションは、設定あり・なしとも 0。プレーヤー（ブラウザーの既定）の動きは、実際のメディアで確かめていない |
