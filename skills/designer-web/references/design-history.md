# デザイン史: 紙の発想から、素材としての Web、均質化と手触りへ

Web サイトの見た目（色・書体の組み合わせ・構図・画像と質感・余白・動き）が、どんな制約のもとで、どう変わってきたかをまとめたファイル。年表の暗記用ではなく、「いま採ろうとしている様式や慣習は、どんな制約から生まれたか」を確かめるための材料である。要点（見取り図・繰り返すパターン・媒体別の問い）と、時代別の詳細を 1 ファイルに置いた。中心の問いは次の 1 つ。

> その慣習を生んだ制約は、今回の媒体・見る人でも成り立つか。

成り立つなら、慣習は今も根拠を持つ。成り立たないなら、様式だけが残っている可能性がある。

このファイルを開くのは、相談者が背景を求めたとき、制作の着手前（「媒体別の使い方」の節）、慣習の由来が不明のとき、の 3 つである。

| 知りたいこと | 開く場所 |
|---|---|
| 全体像・横断の型 | 「見取り図」「繰り返すパターン」 |
| 媒体ごとに確かめる問い | 「媒体別の使い方」 |
| ある様式・慣習の由来（紙の発想・RWD・フラット・光沢・均質化・Liquid Glass など） | 「時代別の詳細」の 6 つの節 |
| 年が出典どうしで合わない項目 | 「年が食い違う・注意する出典」 |
| 空白・未検証 | 「確認できなかったもの」 |

## 読み方と記法

- 時点: 記述は 2026-11-15 時点（出典の取得日）。出典の詳細（引用原文・日付・URL・検証区分）は `sources.md` を参照する。傾向の台帳は `trends.md`。
- 各時代の 4 項目: 当時の制約 / 応答 / 副作用と反動 / 今の判断への示唆。4 項目めの「示唆」はすべて「本 skill の整理（推測）」で、出典が述べた因果ではない。因果（「A だから B になった」）は、出典が述べている場合だけ S 番号つきで書く。「当時の制約」を出典が述べていない時代は、「整理（推測）」または「出典なし」と書く。
- 区分は `sources.md` の凡例に従う（A 原典、B 第三者の転載、C 論評・批判、R 記者・機関・運営者の地の文、U 未検証）。B・C・R は区分を明記して要旨にし、英語の逐語で本人の発言としては示さない。R を研究結果の根拠にするときは、原論文を取得していなければ「原論文未取得」と添える。
- 年・日付: S 番号を添えた論旨上の年は、引用ブロックの原文に含まれるものに限る。記事の公開日は「〜年の記事」と書き、媒体・日付の項による。
- 英語の逐語は区分 A の出典だけで、1〜2 文に限る。日本語は要旨で、本人の発言ではない。
- 回答での使い方: 頼まれない限り、歴史を講釈しない。判断の根拠として 1 行で使う。

## 回答での使い方（例）

- 相談「固定の完成画面を 3 案作って選んでもらいたい」: 固定幅の詳細な画面案は、最終の見た目を作っているという誤解を生む（S13）。複数の完成案は、つまみ食いで寄せ集めになる（S14）。断片の粒度で比べる（S15、S17）。
- 相談「紙のように、すべてを思いどおりに配置したい」: 紙で知られる制御は、紙という媒体の制限の産物だと 2000 年の記事は述べる（S07）。画面幅は多様で、流動グリッド・柔軟な画像・メディアクエリと考え方の変更が要る（S08）。
- 相談「手作り感が今の流行なので採りたい」: 傾向は予測で、普及度は測れていない（S36、S37、S39）。流行は次の流行に置き換わる例が、2012 年の記事にある（S48）。理由が被写体にあるかで決める（本 skill の整理）。
- 相談「透明感・ガラスの見た目にしたい」: OS の素材を発表した側は、内容により焦点を当てるためと説明し（S44）、批判側は、見世物を使いやすさより優先していると評する（S45。iOS への批判）。Web では、比を測り直して使う（S74、S79）。

## 繰り返すパターン（本 skill の整理）

次の型は、出典を横断して読み取ったもので、出典が述べた法則ではない。例外は多い。

1. 制御の手放し: 紙の固定は紙の制約の産物（S07）。画面幅が多様になると、完成画面を 1 枚で決められなくなり（S08）、方向性の合意の道具も、完成画面から断片へ移った（S13、S15）。
2. 概念が先、見た目が後: Hay は、デザイナーは書体・色・列数を詰め、アートディレクターは概念から入ると対比した（S03）。Mall は、感情と技術的な実行を分けた（S04）。
3. 見た目の違いの目的化は、繰り返し批判される: 投稿ごとの違い（S05）、見世物の優先（S45）、手がかりを消したフラット（S47）。
4. 様式は周期で置き換わる: 光沢が引き、次の流行が来た（S48）。フラットは手がかりの欠落で見直された（S47）。今の傾向も、予測の段階にある（S36、S37、S39）。
5. 均質化と素材論は併存する: 測定されたページの見た目の収束（S50。原論文未取得）と、同じ素材を使うから似るという見方（S06）。どちらかに決めず、慣習の層と声を出す層に分ける（本 skill の整理）。
6. 賞・OS・ベンダーは、見栄えと新しさに偏る: 賞の評価の偏り（S35）、動きの完成度とアクセシビリティの落差の指摘（S34）、傾向の予測は売る側の主張（S36〜S41）。
7. 道具が変わると、制約が変わる: プラグインの演出は標準技術へ置き換わった（S68）。今の 3D・シェーダーの演出も、素材・時間・性能の予算を前提にする（S19〜S23、S84）。

## 媒体別の使い方

制作の着手前に、該当する媒体の問いを歴史から引き、その媒体の慣習の由来を確かめる。問いは判断を助ける材料で、結論ではない。

### ブランドサイト・店のサイト（`../examples/cafe-brand-site.md`）

1. 方向性は、概念から入ったか（S03）。感情の話と技術の話を分けたか（S04）。
2. 写真は実物か（S60）。撮影前なら、撮影の指示書に落としたか（本 skill の整理）。
3. 似た見た目は、素材のためか、既定値のためか（S06、S50。原論文未取得）。

### 特集ページ・展覧会（`../examples/exhibition-feature-page.md`）

1. 画面幅ごとの切り抜きを決めたか（S11、S12）。
2. 動きは主題を邪魔せず、注意を深めるか（S24、S25）。止める手段があるか（S75）。
3. 重さの目標を決めたか（S77）。画像の多用は否定されないが、文章中心のサイトの肥大は批判される（S82）。

### キャンペーン LP（`../examples/collage-campaign-lp.md`）

1. その傾向は予測で、普及度は測れていない（S36、S37、S39）。
2. 秩序の土台を残したか（Shopify は、構造化した寄せ集めを、精密で整理されたものと説明する。S36）。
3. 動きと質感で、可読性・重さを損なっていないか（S74、S77）。

### ポートフォリオ（`../examples/quiet-portfolio.md`）

1. ポートフォリオが UX の慣習に従うべきかは、両面ある（S28）。
2. 「静か」は予測（S41）。選んだ形跡があるか（本 skill の整理）。
3. 軽さも静けさの一部（S35、S82）。

### 作り直し・AI の既定値の点検（`../examples/ai-lp-rebuild.md`）

1. 同種の依頼で誰でも出す既定の案か（S55）。AI の提供元の文書の列挙は時点情報（S54）。
2. 均質化は測定されている（S50。原論文未取得）。慣習の層と声の層を分ける（本 skill の整理）。

## 時代別の詳細

### 1990 年代後半〜2003 年

- 当時の制約: 表組みレイアウトと font タグが 90 年代後半の制作を特徴づけ、2003 年になっても CSS は基本の書体と色の制御にとどまっていた（S70。追記行の原文）。紙の組版の感覚で、制御したいという欲求があった。Allsopp は、紙で知られる制御は紙の制限の産物で、Web に同じ制約は無い、と述べる（S07）。プラグインは、標準技術の無い領域の機能を担った。Flash の時代があった（S69。R）。
- 応答: {fray}（1996 年 9 月から）は、書き手とイラストレーターの個人サイトで、Zeldman は手作りの先行例として挙げる（S01）。CSS Zen Garden は、CSS で何ができるかを示す共同のギャラリーとして作られた（S70）。
- 副作用と反動: Flash は、標準技術が成熟して代替できるようになったことを理由に、Adobe が 2020 年末に更新・配布を止めると発表した（S68）。
- 今の判断への示唆（整理・推測）: 制御したいという感覚は紙の名残で、素材の性質と合っているかを疑う。演出が標準技術へ置き換わったことは、今の派手な演出も数年後に別の技術へ移る傍証になる。演出を方向性の核にせず、被写体と目的を核に置く。

### 2000 年代

- 当時の制約: ブログ・テンプレート・CMS が前提で、投稿ごとに見た目を変える運用は例外だった（整理・推測）。Zeldman は、Santa Maria のサイト刷新を、Web に本物のアートディレクションを求める声と読んだ（S01）。アートディレクションは学校であまり教えられず、実務で学ぶことが多かった（S03）。
- 応答: Hay は、アートディレクターは概念から入ると書いた（S03）。Santa Maria は、見た目の仕組みを 1 つにし、各記事の組みは枠内で個別に変える、という雑誌のような構想を述べた（S02。B）。Mall は、アートディレクションを感情を呼び起こすこと、デザインを技術的な実行、と分けた（S04）。
- 副作用と反動: Mall は同じ記事で、投稿ごとに見た目を変えただけのものを、アートディレクションと呼ぶことを批判した。見た目の違いは意図の結果で、原因ではない（S05。C）。光沢の様式は、2012 年の記事が、ガラスのボタン・ベベル・反射・派手なグラデーションが減ったと書く（S48。C。起点は未検証）。
- 今の判断への示唆（整理・推測）: 個別の見た目を足す前に、何を感じさせたいかの一文を先に書く。見た目の違いが目的になっていないかを毎回確かめる。ある時代の様式が数年で引くことは、今の様式にも当てはまると想定し、部品の理由を言える形にする。

### 2010〜2015 年

- 当時の制約: 画面幅が多様になり、1 枚の固定レイアウトで決められなくなった。RWD は流動グリッド・柔軟な画像・メディアクエリの 3 つの要素と、考え方の変更だと Marcotte は書く（S08）。画像で、画面幅ごとに別の切り抜きを出す問題は、MDN でも art direction problem と呼ばれる（S11、S12）。
- 応答: スタイルタイル（2012 年の記事）は、固定幅の詳細な画面案を避け、顧客と視覚の言葉を持つための見本を使う（S13）。エレメントコラージュは、Mall が、ワイヤーフレームやムードボードは抽象的すぎる傾向があると書き、最終案ではなく部品の集まりという期待を作る名前で提案した（S16）。制作会社は、ピクセル単位でこの見た目の承認を求めない運用として説明する（S15）。NN/g は、複数のムードボードで比べることを勧める（S17）。立場は分かれる。フラットデザインは 2012 年ごろに広まった様式と NN/g は書く（S47）。
- 副作用と反動: フラットは、クリックできる要素の手がかりの欠落という使いやすさの問題を生んだ（S47。C）。複数の完成案は、つまみ食いで寄せ集めになる（S14）。次の流行が、二股のリボンなどの形で支配的になったと 2012 年の記事は書く（S48。C）。2015 年の記事で Cegłowski は、文章中心のサイトの重量の肥大を問題にした。画像や動画を否定する講演ではない（S82。C）。Chimero は、Web を素材として扱うこと、似た見た目は同じ素材を使うため、と述べた（S06）。
- 今の判断への示唆（整理・推測）: 方向性の合意は、完成画面ではなく、色・書体・断片・雰囲気で取る。複数案の完成画面を並べて選ばせない。様式で語らず、押せる手がかりの有無で判断する。

### 2015〜2020 年

- 当時の制約: 配置の新しい手段が使えるようになり、Simmons は 2018 年のインタビューで、初めてハックか退屈なレイアウトかの二択でなくなった、と述べた（S09。書き起こし）。同じ時期に、ページの見た目の均質化が研究された。著者らは、デザインが 2007 年以降に有意に似てきており、レイアウトの平均距離は 30% 超縮小したと述べ、原因として、ソースコード・ライブラリの重なり、配色の標準化、モバイル対応を挙げる（S50。著者のプロジェクトページの要約で、原論文未取得。サンプルの偏りは `sources.md` の備考）。
- 応答: Chimero は、似た見た目を、同じ素材を使うための共通の解で、単一文化の証拠ではない、と述べた（S06）。Simmons の講演の題名に、Web の本物のアートディレクションと、レイアウトの実験が並ぶ（S10。題名のみ）。ブルータリズム系サイトの集積サイトは、自らを軽さ・楽観への反動と位置づける（S49。R。運営者の記載なし）。
- 副作用と反動: 均質化を問題と見る立場（S50。原論文未取得）と、素材に沿った収束と見る立場（S06）が併存する。Chayka は、プラットフォームとおすすめのしくみが趣味を均す、という論旨を空間（カフェ）で示した（S51。S52 は後の見直し。Web の話ではなく、借用の元として扱う）。
- 今の判断への示唆（整理・推測）: 似ていることを一律に悪としない。慣習（ナビ・フォーム・価格表）では似せ、声を出す場所（ヒーロー・写真・書体・動き）では、同じ既定値を使っていないかを確かめる。

### 2020〜2024 年

- 出典なし。グラスモーフィズム・ニューモーフィズムなどの様式の命名と普及は、検索結果の要約だけで、一次資料を取得していない（`sources.md` の未検証）。時期を推測で埋めない。

### 2025〜2026 年

- 当時の制約: OS の側が、透明素材を中心に置いた。Apple は、透明な素材が、内容により焦点を当てるのを助けると説明した（S44）。Google は、表現的な設計は 46 の調査と 18,000 人超の参加者の研究に基づくと説明する（S43。自己主張）。3D・スクロール連動が受賞作で目立ち、Awwwards の配点は Design 40・Usability 30・Creativity 20・Content 10 である（S29）。生成 AI は、制作の道具・画像の源になった。AI の提供元は、AI の出力が偏る見た目を、取得時点で列挙している（S54）。
- 応答: 受賞作の制作側は、方向性を絞る。Lusion は、書体・色を最小にし（約 99% が 1 書体、色は 4 値）、環境を足した（S19、S20）。Bruno は、性能が表現の制約だと述べる（S84）。傾向の報告は、手触り・コラージュ・手描き・静けさ・人の手仕事へ寄る（S36、S37、S39、S40、S41）。理由として、AI があふれることへの反動が挙げられる（S39、S40、S42。予測・解釈）。
- 副作用と反動: NN/g は、Liquid Glass を、見世物を使いやすさより優先していると評し、意味のない動きや、重ねたものの見えにくさを挙げる（S45、S46。C。iOS のアプリ UI への批判）。AI 製の見た目は、紫のグラデーション・Inter・角丸のカード・アイコンの箱の格子として語られる（S56。C。体感）。受賞作の動きの完成度に比べ、アクセシビリティが弱いという指摘（S34。C）、賞が見栄えに偏るという批判（S35。C。2016 年の記事）がある。WebAIM は、上位 100 万ホームページの 95.9% に WCAG 2 の失敗が検出されたと報じる（S80）。要素数は平均 1,437 に増えた（S81）。
- 今の判断への示唆（整理・推測）: 傾向は、ベンダーの予測と実測を分けて読む。実測に近いのは均質化の研究（S50。原論文未取得）と WebAIM（S80、S81）で、傾向記事は動機づけの材料にとどめる。流行を直輸入せず、別の参照と混ぜ、ブランドの核に従う（S36）。反 AI の手触りも、一斉に採れば次の定型になりうる（推測。S54 は cream＋セリフ＋テラコッタを偏りの第 1 項に挙げ、これは手触りを狙う様式と重なると本 skill は解釈する）。生成 AI の線引きの実例は、制作側の自己申告にとどまる（S21）。受賞作の技法は素材・時間・性能の予算を前提にする（S19〜S23、S83、S84）。
