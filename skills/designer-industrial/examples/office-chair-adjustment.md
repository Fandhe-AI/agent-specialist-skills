# 例: オフィスチェアの調整機構（調整範囲の仕様書）

小柄な人から大柄な人まで使うオフィスチェアの調整範囲を、「平均の人」でなく「人の分布」から決める手順の例。題材は架空の製品で、実在の製品の外観・名称は模倣しない。椅子の調整範囲の公的な数値は本 skill では取得できておらず、数値の出典が薄い領域の例である。数値は「出典あり」「本 skill の目安（出典なし）」「要確認」に分けて書く。調整機構を持つ家具・器具の仕様書を作るときと、出典が無い数値を確認事項に置く書き方を見たいときに開く。

## 依頼

- 製品: 事務用の椅子「ミナト」（架空。製造は架空の会社「あおば家具」）。肘付き・キャスター付き
- 依頼文: 「小柄な人から大柄な人まで合う椅子にして。調整は簡単に」
- 現状: 調整のレバーが 7 本あり、どれが何を動かすか分からない。座面の高さの範囲が、身長の高い人には足りないという声がある。商品説明は「人間工学に基づいた、誰にでも合う椅子」
- 想定するユーザー: 共有の執務室で、日替わりの席に座る人。座る前に説明を読まない

### 根拠の範囲（先に読む）

- 出典のある数値は 2 つだけである。調整範囲が覆う使用者の割合 90%（S35。宇宙機向けの基準で、その寸法について、理論上の値）と、AIST が 1991 年・1992 年に計測した青年群の手の寸法（S33・S34）。後者は椅子の寸法ではない
- 椅子の調整範囲（座面の高さ・奥行・アームの高さ・背もたれの強さ）と調整に要する力の公的な数値は、本 skill では取得できていない。この例の数値は、すべて「本 skill の目安（出典なし）」か「要確認」である
- 分布の形（正規分布）は本 skill の仮定で、S33 は分布の形を述べていない。実測のデータで確かめる
- 椅子の強度・安定性・耐久・ガスシリンダーの安全は範囲外。試験規格の番号は本 skill では取得していない。試験機関・有資格者に確認する

## 目的の一文

体格の異なる複数の人が、同じ椅子を、座ったまま手で自分の体に合わせ、結果をその場で確かめられる。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 調整レバー 7 本のうち、体の分布に効くと確かめていない 3 本 | 操作部品が少ないほど、配置を整理しやすい（本 skill の整理）。誤りを減らす配置の原則として、最もよく使う要素を届きやすくし、害のある要素を除くか隔てることが挙げられている（B。要旨。S36）。部品点数は、修理しやすさを表す要素にも挙がる（S45）。必要と分かった軸は後から足す |
| 軸ごとに別方式の操作（レバー・ダイヤル・ネジ） | 初見の人が、操作の方式から軸を当てにくくなる（本 skill の整理）。方式はレバーとダイヤルの 2 種類に絞る |
| 「誰にでも合う」という表現 | 分布の両端で確かめていない。確かめた範囲を書く（S33・S35） |
| 工具が要る調整 | 共有の席では誰も調整しなくなる。調整は手だけで完結させる（本 skill の整理） |

「隠す」は「削る」に数えない。レバーをカバーで隠しても、操作部品は残っている。

## 構成

形を決めている制約の表（S28 の考え方。観点の列挙は本 skill の整理）。

| 観点 | 制約 | 確かめ方 |
|---|---|---|
| 使う人 | 体格の分布が広い。日替わりで座る | 対象集団の寸法の分布（要確認） |
| 作り方 | 調整のストロークは既製部品の限界で先に頭打ちになる | 部品メーカーのデータシート（要確認） |
| 置く場所 | 共有の執務室。説明書を読まない | 初見検証 |
| 寿命 | 毎日使う。座面高さの機構は消耗する | 耐久は範囲外。試験機関に確認 |
| 直し方 | ガスシリンダー・キャスター・アームパッドを交換できる | 一般の工具で外せるか（S45 の考え方） |

調整軸は 4 つ。操作部品は軸ごとに 1 つで、座ったまま片手で届く位置に置く。

| 軸 | 合わせる体の寸法（候補。名称と定義は調査の解説書で確認） | 操作 | 誤操作の害（本 skill の整理） |
|---|---|---|---|
| 座面の高さ | 床から膝の裏までの高さ | 座面の右下のレバー（上下） | 座っていないときに押すと座面が動く。立ち上がる動きの途中で動く |
| 座面の奥行 | 尻から膝の裏までの距離 | 座面の前縁の下のレバー（前後） | 動く座面の縁で指や衣服を挟む |
| 背もたれの強さ | 体重 | 座面の下の、背もたれ側のダイヤル | 強さが体に合わず、背もたれが急に倒れる、または倒れない |
| アームの高さ | 座った姿勢での肘の高さ | アームの根元のレバー | 片側だけ動いて左右がずれる |

```text
   側面図（座った人から見て右）
        背もたれ
          |
          |
   [アームの高さ]  レバー（アームの根元）
   ======座面======  [ 座面の奥行 ]  レバー（前縁の下）
        |  [ 背もたれの強さ ]  ダイヤル（座面の下・背もたれ側）
        |  [ 座面の高さ ]  レバー（右下）
        |
     支柱（ガスシリンダー）
```

## 仕様

出典あり（区分 A で原文を確認）:

| 項目 | 値 | 根拠 |
|---|---|---|
| 調整範囲が覆う使用者の割合 | 90%（その寸法について。理論上）。宇宙機向けの基準で、民生品の目標は事業の判断 | S35 |
| 寸法データの出所 | 実際の使用者集団の調査から確立する | S35 |
| 古い寸法データの扱い | 時代変化が急速な集団では、数十年前の寸法は現在の使用者より小さい。データを盲信しない | S33（条件つきの記述） |
| 取得できた人体寸法 | 青年群（18〜29 歳）の手の寸法のみ。1991 年・1992 年の計測 | S33・S34。椅子の寸法ではない |

本 skill の目安（出典なし）と要確認:

| 項目 | 値 | 区分 |
|---|---|---|
| 調整軸の数・操作部品の数 | 4・4 | 本 skill の目安（出典なし） |
| 対象集団 | 国・年齢層・男女比・調査年 | 要確認 |
| 座面の高さの調整範囲 | 分布から計算する（下のコード断片） | 要確認 |
| 座面の奥行の調整範囲 | 同上 | 要確認 |
| アームの高さの調整範囲 | 同上 | 要確認 |
| 背もたれの強さの範囲 | 体重の分布から計算する | 要確認 |
| 調整のストローク | 既製部品の限界。必要な範囲より小さいなら、2 つの大きさに分ける案を検討する | 要確認（部品メーカーのデータシート） |
| 調整に要する力 | 公的な数値は取得できていない。比較対象の椅子で測り、同等以下を目標にする案 | 要確認 |
| 4 軸を同時に満たす割合 | 60% 以上 90% 以下（各軸で 90% のとき。軸の間の相関は未知） | 本 skill の計算（コード断片） |
| 色 | この例では指定しない。指定する場合は、ラベルと背景のコントラスト比を計算して示す | - |

90% は「その寸法について」の割合である（S35）。4 軸を同時に満たす割合ではない。各軸が 90% でも、全軸が同時に範囲に収まる割合は、最悪で 60%（1 - 4 × 0.1）まで下がりうる。実際の割合は、軸の間の相関を含む実測のデータで求める。

## 文言

| 場面 | before | after | 理由 |
|---|---|---|---|
| 商品説明の冒頭 | 人間工学に基づいた、誰にでも合う椅子 | 対象とした体格: （集団・調査年・出典を、確定後に記入）。範囲の外の方は、販売店で座って確かめられます | 「誰にでも」は、分布の両端で確かめていない（S33）。確かめた範囲を書く |
| 調整部のラベル | ADJ-1 / ADJ-2 / ADJ-3 | 座面の高さ / 座面の奥行 / 背もたれの強さ / アームの高さ | 略語を避け、動かす対象を語で言う |
| 調整の案内（座面の下の札） | 各レバーの用途は説明書を参照 | 座ったまま、手で動かします。工具は要りません | 初見の人が、使い始めの 1 手を迷わない |
| 範囲外の人への表示 | （なし） | 対象の範囲は商品ページに記載しています | 範囲を隠さない |

取扱いの警告文（座面が動く・指を挟む等）は、有資格者・試験機関の確認の対象で、この例では書かない。

英語の原文（S28、Charles Eames）: "Design depends largely on constraints. What constraints? The sum of all constraints." 日本語は要旨で、制約の表を先に書く根拠にする。本件への当てはめは本 skill の推測である。

## コード断片

調整範囲を、分布から求める計算（標準ライブラリのみ。外部の資源・計測は使わない）。入力はすべて仮の値で、単位は任意単位 u。実在の寸法ではない。

```python
from math import erf, sqrt

# 仮の入力（出典なし）。単位は任意単位 u で、実在の寸法ではない。実測の集団データで置き換える
GROUPS = [  # (集団の重み, 平均, 標準偏差)
    (0.5, 100.0, 5.0),   # 集団 1（仮）
    (0.5, 90.0, 4.5),    # 集団 2（仮）
]
COVER = 0.90             # 目標カバー率。90% は S35（宇宙機向け・理論上）の値。民生品の目標は要決定


def cdf(x, mu, sd):
    return 0.5 * (1 + erf((x - mu) / (sd * sqrt(2))))


def mix_cdf(x):
    return sum(w * cdf(x, m, s) for w, m, s in GROUPS)


def mix_quantile(p):
    # 探索区間は GROUPS から決める（各群の平均 ± 10 標準偏差の最小・最大）。単位に依存しない
    lo = min(m - 10 * s for _, m, s in GROUPS)
    hi = max(m + 10 * s for _, m, s in GROUPS)
    if not mix_cdf(lo) < p <= mix_cdf(hi):   # 区間の端に張り付く入力は、誤った値を返さず止める
        raise ValueError(f"分位 {p} が探索区間 [{lo}, {hi}] の外にある。GROUPS を確かめる")
    for _ in range(100):
        mid = (lo + hi) / 2
        lo, hi = (mid, hi) if mix_cdf(mid) < p else (lo, mid)
    return (lo + hi) / 2


tail = (1 - COVER) / 2
lo, hi = mix_quantile(tail), mix_quantile(1 - tail)   # 中央 90% を覆う範囲は本 skill の置き方
print(f"混合した集団の調整範囲: {lo:.1f} から {hi:.1f}（幅 {hi - lo:.1f} u）")

Z = 1.645                                             # 正規分布の 95 パーセンタイル（本 skill の仮定）
own = [(m - Z * s, m + Z * s) for _, m, s in GROUPS]
for i, (_, m, s) in enumerate(GROUPS):
    for j, (a, b) in enumerate(own):
        covered = cdf(b, m, s) - cdf(a, m, s)
        print(f"集団 {i + 1} を、集団 {j + 1} だけで決めた範囲 {a:.1f} から {b:.1f} で覆う割合: {covered:.1%}")

axes = 4
print(f"{axes} 軸を同時に満たす割合: {max(0, 1 - axes * (1 - COVER)):.0%} 以上 {COVER:.0%} 以下")
```

実行結果（仮の入力。本文の数値の根拠ではない）:

```text
混合した集団の調整範囲: 84.2 から 106.4（幅 22.2 u）
集団 1 を、集団 1 だけで決めた範囲 91.8 から 108.2 で覆う割合: 90.0%
集団 1 を、集団 2 だけで決めた範囲 82.6 から 97.4 で覆う割合: 30.1%
集団 2 を、集団 1 だけで決めた範囲 91.8 から 108.2 で覆う割合: 34.7%
集団 2 を、集団 2 だけで決めた範囲 82.6 から 97.4 で覆う割合: 90.0%
4 軸を同時に満たす割合: 60% 以上 90% 以下
```

読み方は 3 つある。(1) 混合した集団の範囲（22.2 u）は、どちらの集団単独の範囲（16.4 u・14.8 u）より広い。(2) 片方の集団だけで決めると、もう片方を覆える割合は 30.1% と 34.7% にとどまる。(3) 範囲の幅が既製部品のストロークを超えるなら、軸を足すのでなく、大きさを 2 つに分ける案を検討する（本 skill の整理）。

## 初見検証

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 足の裏が床に着くか、背中が背もたれに届くか | 座った直後の姿勢 |
| 何を操作できるか | 座面の高さ・座面の奥行・背もたれの強さ・アームの高さの 4 つ | 座面の下とアームの根元の 4 つの操作部品 |
| どう操作するか | 座ったまま、手で、ラベルの語に従う | 操作部品のラベルと、動かしたときの手応え |

説明を渡さずに、対象の分布の両端の人（小柄・大柄）を含めて座ってもらい、4 軸を合わせ終えるまでの手数と、迷った所を見る。両端の人が範囲の端に達しても合わない場合は、調整範囲か、大きさを分ける案に戻る。人数と合格の基準は、本 skill では定めない（要決定）。

## 点検

- 分布: 対象集団・調査年・出典を書いたか。平均でなく両端の人で確かめたか。古い寸法データを盲信していないか（S33）
- 90% の読み方: 「その寸法について」の割合と、4 軸を同時に満たす割合を取り違えていないか（S35）
- 数値の区分: 出典のない数値を、出典ありのように書いていないか。公的な数値が無い項目に「要確認」を残したか
- 疲労と誤り: 調整の操作は、座ったまま片手で、少ない力と手数で終わるか（B。S36）。害のある誤操作を、除くか隔てているか（B。S36）
- 修理: ガスシリンダー・キャスター・アームパッドに、一般の工具で届くか（S45 の考え方）
- 範囲外: 強度・安定性・耐久・ガスシリンダーの安全は、試験機関・有資格者に確認する項目に置いたか
- 推測の明示: 分布の形・調整に要する力・調整軸の必要性は、実測と実際の利用者で確かめる。この例では分からない
