# 例: 携帯用スピーカー（形と素材の指定書）

「Braun っぽく」「素材は高級に」という依頼を、素材・仕上げ・工程の制約に訳し、成形メーカーへの確認事項までを含む指定書にする例。題材は架空の製品で、実在の製品の外観・名称・ロゴは模倣しない。形・素材・量産が本 skill の範囲で、操作の割り当てと画面は別の skill に回す。制作の着手前に開く。

## 依頼

- 製品: 携帯用スピーカー「ひだまり」（架空。企画は架空の会社「あさぎ舎」）。屋内外に持ち出す、手に収まる箱形。外装は射出成形を想定し、量産数は未定
- 依頼文: 「Braun っぽいミニマルなスピーカーにして。素材は高級に見せたい」
- 現状: 外装案は 3 色（白・黒・金属調）、色ごとに別の素材。金属調は塗装の追加工程。前面に大きなロゴ。承認はレンダリング画像だけ。肉厚・抜き勾配は未確認。電池は内蔵を想定
- 想定ユーザー: 置き場所を選ばず、鞄に入れて持ち出す人

### 根拠の範囲（先に読む）

- Rams の発言は、Capsule のインタビュー（S03・S04・S05。区分 A）の原語を使う。「Braun っぽく」は様式でなく、長く使うこと・ロゴの小ささ・検討用の画像への注意として読む。本件への当てはめは本 skill の推測である
- SK 4 の透明カバーは、機関の地の文（R。S09）である。金属カバーが試験で振動した、という経緯をスピーカーの外装へ当てはめることは、本 skill の推測である
- 抜き勾配・リブの値は受託企業の目安（R。S38 から S42）で、規格ではない。値は企業ごとに食い違う。肉厚には出典がなく、材料と成形メーカーの確認が前提である
- 電気安全・電池の安全・防水等級・音響性能・材料の物性は、この例の範囲外。有資格者・認証機関・材料メーカーへの確認事項に置く

## 目的の一文

持ち出す人が、置き場所を選ばずに音を流し、数年後も同じ外装のまま使い続けられる、手に収まる 1 つの箱を作る。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 外装 3 色 → 2 色 | 色数を減らすと、工程と在庫が減る。無印良品は「素材の選択」「工程の点検」「包装の簡略化」から見直すと述べる（S20。企業の自己説明） |
| 色ごとに別の素材 → 1 素材 | 素材が違うと金型・収縮・仕上げの確認が色の数だけ増える（本 skill の整理） |
| 金属調の塗装 | 追加工程。見た目だけの理由なら削る。素材が実際の理由（振動・剛性）で決まる場合だけ再検討する（S09 の例は試験結果が素材を決めた） |
| 前面の大きなロゴ | Rams は、小さなロゴのほうがはるかに強いと述べる（S04）。目立たせる動機は誰のためか |
| 光沢とシボの混在 | 表面処理を 1 種にする。金型の仕上げと再現性の確認が 1 本で済む（本 skill の整理） |
| 継ぎ目を隠す化粧パネル | 「隠す」は「削る」に数えない。前殻と後殻の継ぎ目は 1 本にして見せ、部品を減らす |
| レンダリングだけの承認 | 見栄えの良さが検討不足を隠す（S05）。試作で確かめる |

## 構成

### 依頼語の訳

| 依頼語 | 訳す先（本 skill の整理） | 根拠 |
|---|---|---|
| Braun っぽく | 長く使う前提、技術と結びついた更新、外観の抑制。白と丸ボタンの話にしない | S03・S04 |
| ミニマル | 削る要素と、残す余地。簡素を様式にしない | S20 |
| 素材は高級に | 素材の格でなく、細部（接合・素材の選択・仕上げ）を量産で保つこと | S29（R。公式ページの引用・原典未照合） |

### 制約の表

Eames は、設計は制約に大きく依存し、その制約はすべての制約の総和だと答えた（S28。英語の原文は "Design depends largely on constraints. What constraints? The sum of all constraints."。日本語は要旨）。形を描く前に、次の表を埋める。

| 制約 | 内容 | 状態 |
|---|---|---|
| 使う人 | 片手で持ち上げる。鞄に入れる | 置いた前提 |
| 作り方 | 射出成形。2 ピース外装 | 成形メーカーに確認 |
| 置く場所 | 屋内外。水が掛かりうる | 防水等級は範囲外。要確認 |
| 寿命 | 数年使い続ける。電池の交換 | 電池規則を確認（下の点検） |
| 直し方 | 電池ふたからのみ、ねじ 2 本で届く | 本 skill の目安 |

### 外装

| 面 | 内容 |
|---|---|
| 上面 | 操作部 3 つ |
| 側面（両側） | 前殻と後殻の継ぎ目 1 本。指をかける浅い凹み |
| 下面 | 電池ふた（ねじ 2 本）。ふたの継ぎ目は前殻・後殻の継ぎ目とは別 |

- 外装は前殻と後殻の 2 ピースで、両者の継ぎ目は 1 本（下面の電池ふたの継ぎ目は別）。化粧パネルを足さない
- 両側面に、指をかける浅い凹みを置く。持つ場所を形で示す（値は本 skill の目安。試作で確かめる）
- 電池は下面のふたからだけ届く。外装の分解を要しない。詳しい分解経路は、修理しやすさを主題にした別の例（`repairable-cordless-vacuum.md`）を参照する

## 仕様

| 項目 | 指定 | 区分 | 根拠 |
|---|---|---|---|
| 外装の素材 | 熱可塑性樹脂 1 種。種類は要確認 | 要確認 | 材料の物性・難燃・耐候は範囲外 |
| 色 | 生成り`#E8E2D6`・墨`#2B2B2E`の 2 色 | 本 skill の目安（出典なし） | 淡い色は着色が安く、濃い色は汚れや欠点を隠しやすいという実務者の見解（B。S43） |
| 表面 | 艶消し 1 種。シボ・塗装を足さない | 本 skill の目安（出典なし） | 工程の点検（S20） |
| ロゴ | 1 面だけ、型に彫る。高さ 8 mm 以下 | 本 skill の目安（出典なし） | 小さなロゴ（S04）。印刷の工程を足さない |
| 主壁の肉厚 | 2.5 mm（仮置き） | 本 skill の目安（出典なし）。成形メーカーの確認で置き換える | 厚すぎる部位はひけ・反り・ボイドの原因（R。S39） |
| リブ厚（主壁 2.5 mm のとき） | 1.25〜1.50 mm | 目安（出典あり・値は企業ごとに異なる） | 60% 以下（S40）、0.5 倍（S41）、50〜60%（S42） |
| 外壁の抜き勾配 | 2 度以上。深さ 60 mm の部位は 2.4 度以上 | 目安（出典あり・値は企業ごとに異なる） | 最小 2 度（S41。原文は all vertical walls）、25 mm あたり 1 度（S38）。S42 は壁とリブの両方に 0.5〜1%（% 表記のまま） |
| 外装の共振 | 試作で、音量を上げたときの外装のびびりを確かめる | 本 skill の推測 | S09 は別の製品の例 |
| 寸法・質量 | 要確認 | 要確認 | 公的な基準は取得していない |

## 文言

成形メーカーへの確認依頼文（案）:

> 外装（前殻・後殻）を射出成形で量産する予定です。材料と金型の能力に照らして、次を回答してください。(1) 主壁の肉厚の推奨と、2.5 mm 案の可否。(2) 外壁とリブの抜き勾配。当方は受託企業の目安として外壁 2 度以上を見込み、深さ 60 mm の部位は 2.4 度を仮置きしています。(3) リブの厚さ（主壁の 50〜60% の範囲を見込み）と高さ。(4) ひけ・反りが出やすい部位。(5) 艶消し 1 種の表面で、ロットを越えて色と艶を保てるか。

承認の文言: 「レンダリングでなく、試作 3 回で承認する。最後の試作は量産の金型で成形したものにする。」

英語の原文（S05、Rams、Capsule）: "speedy renderings also result in designs that have not been thought completely through because everything looks so good at first glance" 日本語は要旨で、検討用の画像の見栄えは、検討不足を隠す。

公式ページ（S29。区分 R。原典未照合）は、線材の太さ・木の選択・鋳物の仕上げ・接合が製品を作るという趣旨を、Charles Eames の言葉として載せる（要旨。本人の発言としては使わない）。本件への当てはめは本 skill の推測で、外装の継ぎ目と仕上げを量産で保てるかを、素材の格より先に確かめる。

刻印・印字の字形と組みは、別の skill（導入されていれば designer-typography）へ回す。法定の表示は範囲外。

## コード断片

CMF の指定を機械可読にした例（YAML）。成形メーカーと共有し、値の区分を持たせる。

```yaml
product: ひだまり
finish: { surface: matte, count: 1 }
colors:
  - { name: 生成り, srgb: "#E8E2D6", basis: "本 skill の目安" }
  - { name: 墨,     srgb: "#2B2B2E", basis: "本 skill の目安" }
molding:
  wall_mm:    { value: 2.5, basis: "本 skill の目安（出典なし）", confirm: 成形メーカー }
  rib_ratio:  { value: [0.5, 0.6], basis: "受託企業の目安 S40 S41 S42", confirm: 成形メーカー }
  draft_deg:  { value: 2.0, at_depth_60mm: 2.4, basis: "受託企業の目安 S41（最小）・S38（深さ 60 mm の経験則）", confirm: 成形メーカー }
```

肉厚とキャビティ深さから、受託企業ごとの値を並べて食い違いを見せる計算（標準ライブラリのみ。`python3 molding_check.py 2.5 60`）:

```python
import sys

wall, depth = float(sys.argv[1]), float(sys.argv[2])  # mm。肉厚は仮置き、深さは図面から
# 出典: (リブ厚の下限係数, 上限係数, リブ高さの上限（リブ厚の倍数。無ければ None）)
guides = {"S40": (None, 0.60, 3), "S41": (0.50, 0.50, None), "S42": (0.50, 0.60, None)}
for sid, (lo, hi, h) in guides.items():
    if lo is None:
        rib = f"{hi * wall:.2f} mm 以下"
    elif lo == hi:
        rib = f"{hi * wall:.2f} mm"
    else:
        rib = f"{lo * wall:.2f}-{hi * wall:.2f} mm"
    print(f"リブ厚 {sid}: {rib}" + (f"、高さはリブ厚の {h} 倍まで" if h else ""))
print(f"抜き勾配 S38: {depth / 25:.2f} 度以上（25 mm あたり 1 度）")
print(f"抜き勾配 S39: {depth / 25.4:.2f} 度以上（1 inch あたり 1 度）")
print("抜き勾配 S41: 外壁（原文は all vertical walls）は 2 度以上（最小の推奨）")
```

実行結果（`2.5 60`）: S40 は 1.50 mm 以下、S41 は 1.25 mm、S42 は 1.25-1.50 mm。S38 は 2.40 度以上、S39 は 2.36 度以上、S41 は外壁 2 度以上。値が食い違うため、成形メーカーと材料のデータシートで確定する。

## 初見検証

試作（量産の金型で成形したもの）を、説明なしで初めて渡す。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | どちらが前か（音の出る面）。落とさずに持てるか | 両側面の凹みと、グリルのある前面 |
| 何を操作できるか | 上面の 3 つの操作部 | 操作部が上面に 3 つだけ見える |
| どう操作するか | 指で押す。割り当てと合図は別の skill で決める | 押したときの手応え（値は試作で確認） |
| どこを持つか | 両側面の凹みに指をかける | 凹みへ自然に指が行くか |
| 電池はどこか | 下面のふた | ふたとねじを、説明なしで見つけられるか |

片手で持ち上げて鞄へ入れる動きと、屋外で置く動きを分けて見る。操作の割り当てと文言・音の合図は、導入されていれば designer-apple の hardware-ui 例と分担する。

## 点検

- 様式の再生産: 白・丸・薄いを、方針の代わりにしていないか。簡素は様式でないと企業自身が断る（S20）。控えめな美学と最適化された機能が革新の制約にもなると、Rams 自身が認める（S01）
- 受託企業の目安: 値を規格として確定していないか。企業ごとに食い違う（S38 から S42）。データシートと成形メーカーで確かめたか
- レンダリング: 試作で確かめたか（S05）。仕上げ（接合・素材の選択・仕上げ）を量産で再現できるか（S29。R）
- 長く使うこと: 外観も長持ちするか（S03）。電池の交換経路があるか
- 電池規則: 内蔵電池が、ポータブル電池の取り外し・交換の義務（第 11 条）の対象か、例外に当たるかを、条文全体で確かめたか。適用日は 2027-02-18 である（S46）。本例は適合判断をしない
- 範囲外: 電気安全・防水等級・音響性能・材料の物性は、有資格者・認証機関・材料メーカーへの確認事項に置いた
- 推測の明示: 肉厚・ロゴの大きさ・色・凹みの形は出典がなく、試作で置き換える
