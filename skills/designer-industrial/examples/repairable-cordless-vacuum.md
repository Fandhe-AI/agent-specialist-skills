# 例: 修理しやすいコードレス掃除機（分解経路の設計メモ）

「薄くて継ぎ目がなく、でも修理しやすい」という依頼を、電池・ホース・モーター・ブラシに届く分解の経路の設計メモに訳す例。題材は架空の製品で、実在の製品の外観・名称は模倣しない。規制は製品群ごとに確かめる手順として示し、適合の判断はしない。家電・掃除機の着手前に開く。

## 依頼

- 製品: コードレスのスティック掃除機「そよ」（架空。企画は架空の会社「かもめ電器」）。ホースを付けてハンディとしても使う
- 依頼文: 「薄くて継ぎ目のない掃除機にして。でも修理もしやすく」
- 現状: 外装は接着と隠しツメの一体外装。電池は外装の内側に接着。ブラシ室のふたも接着。ねじは 4 種で、うち 1 種は専用の工具が要る。ホースは本体の根元に固定
- 想定ユーザー: 電池やブラシを自分で交換したい家庭の使用者と、修理業者

### 根拠の範囲（先に読む）

- 規制の本文（S44 から S49）は、保存日の本文である。ESPR（S44・S45）の掃除機向けの要件が確定したかは確認していない。掃除機の規則（S49。規則番号 No 666/2013）は、第 1 条で有線（electric mains-operated）と hybrid を対象とし、battery operated を適用外とする（2013 年の官報版の保存コピー）。本例のコードレス機には適用されず、現行かも確認していない。S49 の数値は、有線機の規則の値を参考にした本 skill の目安として扱う。修理する権利の指令（S47）は、附属書 II に挙げる EU 法で修理しやすさの要件がある製品だけが対象である。日本・米国の法令は取得していない。適合の判断はしない
- 「薄くても修理しやすい」は、評価側（C。S54）の主張である。採点は同社のエンジニアによるもの（S53）で、同社は修理用の部品・工具を販売する企業である（台帳の備考）。題材はスマートフォンである（S53・S54）。掃除機へ当てはまるとは書かれていない。一般則として使わない
- 手順数・工具の種類・留め具の数の基準は、本 skill の目安（出典なし）である
- 電気安全・電池の発火・モーターの性能試験・材料は範囲外。有資格者・認証機関への確認事項に置く

## 目的の一文

電池・ブラシ・ホース・モーターが故障したとき、家庭の使用者か修理業者が、市販の工具で、本体を壊さずに届く掃除機にする。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 外装の接着・溶着 | 壊さずに開けられない。ESPR は、早期の陳腐化の理由に、重要な部品の分解の妨げを挙げる（S44） |
| 電池の接着 | 第 11 条の対象になる場合、電池は市販の工具で取り外せることが求められ、専用の工具・熱・溶剤を要しない。専用の工具が製品に無償で付属する場合などの例外がある（S46。条文の全体と例外を読む） |
| 専用ねじ（特殊な工具） | 第 11 条の対象になる場合、専用の工具は原則として要しない（無償で製品に付属する場合は例外。S46）。修理の要素に、市販の工具との適合がある（S45） |
| ねじ 4 種 → 1 種 | 部品点数と標準部品も修理の要素である（S45）。工具の持ち替えを減らす（本 skill の整理） |
| ホースの固定 | 差し込み式にし、非破壊で外せる（有線機向けの S49 が非破壊の分解の情報を挙げることを参考にした本 skill の目安） |
| 継ぎ目を完全に隠す一体外装 | 「隠す」を「削る」に数えない。継ぎ目は見える分割線 1 本にする |
| 薄さそのものの追求 | 厚みの下限を、電池・モーターの収まりと分解経路から決める。薄さを目的にしない（本 skill の整理） |

## 構成

### 分解経路の図

故障しやすい部品を、経路の浅い所に置く。評価側は、最も重要で壊れやすい部品の交換しやすさを採点の 80% とすると述べる（C。S54。同社の採点方法）。何が壊れやすいかは、本 skill の推測である。

```text
 本体
  +-- 電池ふた(ねじ 2 本) ------------------ 電池
  +-- 本体カバー(ねじ 4 本) -- ダクト(爪) -- モーター
  +-- ホース差込口(ロックレバー) ----------- ホース
  +-- ブラシ室ふた(ねじ 2 本) --------------- ブラシ
  留め具は 1 種のねじ。接着なし。工具はプラスドライバーと手
```

### 規制の確認手順

規制は製品群ごとに異なる。確認した結果は、条文・版・確認日とあわせて設計メモに書く。適合の判断は有資格者に任せる。

| 手順 | 確認すること | 根拠・注意 |
|---|---|---|
| 1 | 製品群を決める。ESPR の掃除機向けの要件が確定したか | ESPR は枠組みの法令（本 skill の整理。S44）。確定状況は未確認 |
| 2 | 電池が第 11 条の対象か、例外に当たるか | 適用日は 2027-02-18。発売時期と照らす。洗える機器などの例外がある（S46）。条文全体を読む |
| 3 | 掃除機の規則（No 666/2013）の対象か。有線と hybrid が対象で、battery operated は適用外。hybrid（有線と電池の両方で動く）にする場合は対象になりうる | S49 第 1 条。本例は電池式のため対象外と読める（判断はしない）。現行かは未確認 |
| 4 | 修理する権利の指令の対象か | 附属書 II に挙げる EU 法で修理しやすさの要件がある製品だけ（S47） |
| 5 | 部品の供給期間の要件があるか | 7 年はスマートフォン等の規則の値（S48）。掃除機の値ではない。要確認 |

## 仕様

| 項目 | 値 | 区分 | 根拠 |
|---|---|---|---|
| 電池 | 市販の工具で取り外し・交換できる（第 11 条の対象になる場合） | 出典あり（法令の趣旨） | S46 第 11 条。2027-02-18 から適用。専用の工具が無償で付属する場合などの例外あり。適用の判断はしない |
| ホース | 4 万回の揺動の後も使える | 本 skill の目安（有線機の規則の値を参考。電池式は適用外） | S49 は有線・hybrid が対象 |
| モーター寿命 | 500 時間以上 | 本 skill の目安（同上） | S49 |
| 非破壊の分解の情報 | ホース・吸込口・モーター・外装・ケーブルについて用意する | 本 skill の目安（同上） | S49 |

## 文言

修理の手順書（電池の交換。案）。修理の手順書は修理しやすさの要素である（S45）。電源・充電の安全の注意は、有資格者の確認の後に加える。

1. 電源を切り、充電器から外す。
2. 本体の電池ふたの、ねじ 2 本を、プラスドライバーで外す。
3. ふたを外し、電池を引き抜く。
4. 新しい電池を差し込み、ふたをねじで留める。

製品の文言:

| 場面 | before | after | 理由 |
|---|---|---|---|
| 取扱説明 | お客様による分解・修理はできません | 電池・ブラシ・ホースは、手順書のとおり交換できます。それ以外は販売店へ | 直せる範囲を、使う人に伝える。after は案。電池の取扱い警告は有資格者の確認後に追加し、確認前は公開しない。保証・安全の表示の義務は範囲外 |
| 修理の窓口 | （記載なし） | 手順書の入手先と、部品の注文先 | 修理の情報と部品の入手性（S45） |

英語の原文（S46）: "readily removable and replaceable by the end-user at any time during the lifetime of the product." 日本語は要旨で、製品に組み込まれたポータブル電池を、使用者がいつでも取り外し・交換できるようにする。適用の範囲と例外は条文全体で確かめる。

## コード断片

分解経路を機械可読にした表（JSON。初案）。ブラシ室のふたが接着のままである。

```json
{
  "allowed_tools": ["プラスドライバー", "手"],
  "max_steps": 3,
  "parts": [
    {"id": "battery", "steps": ["電池ふたを外す", "電池を引き抜く"], "tools": ["プラスドライバー", "手"], "adhesive": false, "destructive": false, "fastener_types": 1},
    {"id": "motor", "steps": ["本体カバーを外す", "ダクトを外す", "モーターを引き抜く"], "tools": ["プラスドライバー", "手"], "adhesive": false, "destructive": false, "fastener_types": 1},
    {"id": "hose", "steps": ["差し込み口のロックを外す", "ホースを引き抜く"], "tools": ["手"], "adhesive": false, "destructive": false, "fastener_types": 0},
    {"id": "brush", "steps": ["ブラシ室のふたを外す", "ブラシを引き抜く"], "tools": ["手"], "adhesive": true, "destructive": false, "fastener_types": 0}
  ]
}
```

点検の計算（標準ライブラリのみ。`python3 check_parts.py parts.json`）。基準は本 skill の目安で、規制適合の判定ではない。

```python
import json, sys

with open(sys.argv[1], encoding="utf-8") as f:
    d = json.load(f)
ng = 0
for p in d["parts"]:
    problems = []
    if len(p["steps"]) > d["max_steps"]:
        problems.append(f"手順 {len(p['steps'])} > {d['max_steps']}")
    if not set(p["tools"]) <= set(d["allowed_tools"]):
        problems.append("許可外の工具")
    if p["adhesive"]:
        problems.append("接着あり")
    if p["destructive"]:
        problems.append("非破壊でない")
    if p["fastener_types"] > 1:
        problems.append("留め具が 2 種以上")
    ng += bool(problems)
    print(f"{p['id']:8s} {'要見直し: ' + '、'.join(problems) if problems else 'OK'}")
sys.exit(1 if ng else 0)
```

実行結果（初案）: battery・motor・hose は OK、brush は「要見直し: 接着あり」で終了コード 1。ブラシ室のふたをねじ留めへ改め（`adhesive` を false、`tools` に「プラスドライバー」を足し、`fastener_types` を 1 にする）、再実行して全件 OK になることを確かめる。

## 初見検証

試作を、説明なしで初めて渡す。使用者と修理業者の 2 通りで見る。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 電池・ブラシ・ホースは自分で外せる部品である | 外装に、ふたと分割線が見える |
| 何を操作できるか | 電池ふた・ブラシ室ふた・ホースの差込口 | ねじと、ロックレバーが見える |
| どう操作するか | ねじを回して、ふたを外し、部品を引き抜く | 手順書なしでふたを見つけるまでの時間と迷い |

手順書を渡して、電池を交換してもらう。手順数・工具の持ち替え・迷った所を記録する。電源を切る手順など、安全の確認は有資格者に任せる。

## 点検

- 分解の経路: 電池・モーター・ホース・ブラシに届くまでに外す部品を、図にしたか。接着・溶着・専用の工具を残していないか（S44・S46）
- 規制: 上の確認手順で、条文・版・確認日を記録したか。S49 は有線・hybrid の規則でコードレスには適用されず、値は参考の目安にとどめたか。S48 の 7 年はスマートフォン等の規則の値で、掃除機には使っていないか
- 薄さ: 薄さと修理の両立を、評価側（C。S54）の主張として扱ったか。一般則にしていないか
- 抑制: 見た目を揃えて、修理できなくしていないか。控えめな美学と最適化された機能が革新の制約にもなると、Rams 自身が認める（S01）。長く使われることは、見た目だけでなく技術にも求められる（S03）
- 範囲外: 電気安全・電池の発火・モーターの試験・材料は、有資格者・認証機関への確認事項に置いた
- 推測の明示: 手順数・工具・留め具の基準、壊れやすい部品の見立ては出典がなく、実際の修理と故障の実績で置き換える
