# 例: 手持ちの介護用検温器（人体と使用誤りの検討書）

「持ちやすく、モダンに」という依頼を、使う人の体の分布と、使い間違えたときの害から検討し直す例。題材は架空の製品で、実在の製品の外観・名称は模倣しない。見た目は、害を生む使用誤りを除去・低減した後に決める。規制適合の判断はしない。手持ちの医療・介護機器の着手前に開く。

## 依頼

- 製品: 手持ちの検温器「ミモリ」（架空。企画は架空の会社「ひだ医工」）。介護施設で、片手に持ち、入居者に向けて測る。表示は小さな画面にある
- 依頼文: 「介護職員が片手で使う検温器を、持ちやすくモダンに」
- 現状: 細身の円筒の握り、小さな丸ボタン 3 つ（測定・モード・単位）、艶消しの黒い本体、極小の印字。測定部は握りの先端
- 想定ユーザー（置いた前提）: 手袋をして、もう片方の手で入居者を支える職員。夜間にも使う。年齢・体格はさまざま

### 根拠の範囲（先に読む）

- 手の寸法は、AIST の 1991 年・1992 年の計測の、青年群（18〜29 歳）の平均値だけを数値として取得している（S33・S34）。高齢者群（60 歳以上）は計測されているが、値を取得していない。職員の年齢は青年群に限らない
- 把持力・押す力の公的な数値は取得していない。取手・ボタンの寸法・操作力・質量は、すべて本 skill の目安（出典なし）である
- 使用誤りの考え方は、FDA のガイダンス（S37）を転用する。米国の拘束力のない推奨で、日本の薬機法・IEC 62366 は取得していない。この検温器が医療機器に当たるか、どの要件が適用されるかは判断しない。有資格者・認証機関への確認事項である
- 画面の文言・表示は designer-apple、調査の設計は designer-ux-research（いずれも導入されていれば）に回す

## 目的の一文

手袋をした職員が、片手で、入居者を支えながら、落とさず、押し間違えず、読み間違えずに体温を測る。

## 削るもの

| 削るもの | 理由 |
|---|---|
| ボタン 3 つ → 測定の 1 つ | 押す所が増えると押し間違えが増える（本 skill の整理）。モード・単位は二次の操作へ回す。疲労と誤りを減らす配置を、ユニバーサルデザインの原則が挙げる（B。S36） |
| 見た目優先の細い握り | 手の小さい人にも大きい人にも合うかを試作で確かめるまで、径を決め打ちしない |
| 艶消しの黒い本体 | 濃い色は汚れや欠点を隠しやすい、という実務者の見解（B。S43）。汚れが見えにくいことは、ここでは害になりうる（本 skill の推測。衛生基準は範囲外） |
| 測定ボタンと電池ふたの同形・同色 | 押す所を取り違えるため、形と位置で分ける |
| 極小の印字 | 夜間・手袋・老眼の人は読みにくい（本 skill の推測）。字形・大きさは designer-typography に回す |
| 「モダン」を示すための装飾 | 目的に寄与しない。見た目は、使用誤りの除去・低減の後に決める（この順序は本 skill の整理。S37 は害の除去・低減を目的に置く） |

## 構成

### 使用の流れに沿った点検

疲労と誤りの点検を、操作の流れに沿って行う（S36）。害の重さは本 skill の整理で、S37 は重さの尺度を示していない。

| 段階 | 動作 | 起こりうる使用誤り | 害（本 skill の整理） | 除去・低減の方針 |
|---|---|---|---|---|
| 1 取り出す | 片手で持つ | 逆向きに持ち、手で測定部をふさぐ | 値が不正確になり、判断を誤る（重） | 持つ所の形で向きが決まる。測定部は握りの外に出す |
| 2 向ける | 入居者に向ける | 測定部の向きが定まらない | 再測定。夜間は負担（中） | 測定部と握りの軸を揃える |
| 3 押す | 親指で押す | 別のボタンを押す | 値が出ない（軽） | 押すボタンは 1 つ。形と位置で他の部品と区別 |
| 4 読む | 画面を見る | 手や影で表示が隠れる、読み違える | 値の読み違い（重） | 表示面の向きと影を試作で確認。表示の中身は別の skill |
| 5 置く・落とす | 片手がふさがる | 落下して破損、または気づかず誤差 | 中 | 滑りにくい面。落としたときの確認は有資格者へ |
| 6 次の人へ | 測定部に触れる | 汚れの残り | 衛生（範囲外） | 溝と継ぎ目を増やさない形にする。洗浄・消毒の方法は範囲外 |

### 見取り図

```text
 [ 測定部 ]  <- 握りの外に出す。向きは形で分かる
     |
 +---+------+
 | [ 表示 ] |  <- 表示面は、手と影で隠れない向き
 |          |
 |  ( 測定 )|  <- 親指が届く位置（小さい手で確認）
 |          |
 |  ( 握り ) |  <- 径は 3 種の試作で確認。滑りにくい面
 +----------+
```

## 文言

本体のラベル（案）。字形・大きさは designer-typography へ。法定の表示・取扱上の注意の義務は範囲外。

| 場所 | before | after | 理由 |
|---|---|---|---|
| 測定ボタン | MEAS | 測定 | 略語を避ける |
| 測定部の近く | （無し） | 測定部をふさがない（向きの矢印を添える） | 段階 1 の使用誤りを、本体で言う |
| 電池ふた | （測定ボタンと同形） | 電池（ふたの形を変える） | 取り違え防止 |

試作を試してもらうときの依頼文（案）: 「手袋をつけて、片手で持って、測ってください。持ちにくい所・押しにくい所・間違えそうな所を、そのまま声に出してください。」

英語の原文（S37、FDA）: "use errors that occur during use of the device that could cause harm or degrade medical treatment are either eliminated or reduced to the extent possible" 日本語は要旨で、害を生む使用誤りを、除去するか、可能な範囲で低減する。本件への当てはめは本 skill の推測である。この文書は米国の規制当局の推奨で、同文書は、ガイダンス文書は一般に法的に強制できる責任を定めないと述べる（S37）。

## コード断片

分布から設計の範囲を求める計算（標準ライブラリのみ。`python3 grip_range.py 平均 標準偏差 カバー率`）。標準偏差は使用者集団の実測で与える。AIST の標準偏差は本 skill で取得しておらず、下の実行例の 4.0 は例示で、出典のない仮の値である。

```python
import sys

if len(sys.argv) != 4:
    sys.exit("使い方: grip_range.py 平均mm 標準偏差mm カバー率（例 0.90）。標準偏差は実測で与える")
mean, sd, cover = float(sys.argv[1]), float(sys.argv[2]), float(sys.argv[3])
Z = {0.80: 1.282, 0.90: 1.645, 0.95: 1.960}   # 正規分布の仮定（本 skill の仮定）。両側の z 値
if cover not in Z:
    sys.exit("カバー率は 0.80・0.90・0.95 のみ対応")
z = Z[cover]
print(f"平均 {mean:g} / SD {sd:g} / 中央 {cover:.0%} 区間（z={z}）: {mean - z * sd:.1f} - {mean + z * sd:.1f} mm")
```

実行例（SD は例示の 4.0）:

- `python3 grip_range.py 82.1 4.0 0.90` → 中央 90% 区間 75.5 - 88.7 mm（男子の手幅）
- `python3 grip_range.py 73.0 4.0 0.90` → 中央 90% 区間 66.4 - 79.6 mm（女子の手幅）
- 男女を合わせると、例示の値では 66.4 から 88.7 mm。この幅の両端の人に、試作を持ってもらう。仮の SD による例示で、設計値にしない
- 男女それぞれの平均 ± z·SD を並べた範囲は、男女を合わせた分布（混合分布）の分位ではない。合わせた分布の範囲は、実測の分布から求める

試作の確認記録の雛形（CSV）。両端の人と、手袋の有無を行にする。

```csv
被験者,手幅_mm,手袋,径_mm,持てた,親指が届いた,落としかけた,向きを間違えた
A,66,有,30,,,,
B,89,有,38,,,,
```

## 初見検証

試作を、説明なしで初めて渡す。手袋をつけたまま、もう片方の手で人形か補助者を支えてもらう。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 測定部をふさがない。落とさない | 測定部が握りの外にあり、向きが形で分かる |
| 何を操作できるか | 測定のボタン 1 つ | 押せる部品が 1 つだけ見える |
| どう操作するか | 持って向けて、親指で押す | 親指が届く位置（小さい手の人でも） |
| どこを持つか | 握りの滑りにくい面 | 持ち替えずに測れたか |
| 読めるか | 表示を、手や影に隠されずに読む | 夜間の暗さと手袋で、表示面の向きを確認 |

手の小さい人・大きい人・手袋の有無を分けて見る。迷った所と、間違えた所を、そのまま記録する。

## 点検

- 分布: 集団・年・出典を書いたか。青年群の平均値だけでは両端が分からない。より新しい調査を確かめたか（S33）。高齢者群の値は未取得である
- 分析への過信: 人間工学の値で形が決まるわけではない。Ulm でも、分析だけでは足りないという対立があった（R。S12）。Eames は、分析が不完全であるリスクが大きいと述べる（S28）
- 使用誤り: 害を生む使用誤りを、除去または低減したか。見た目の検討は、その後か（順序は本 skill の整理。除去・低減は S37）
- 疲労・誤り: 操作の流れの全段階で点検したか（S36）
- 試作: 検討用の画像でなく、実物の試作で確かめたか（S05）
- 色: 濃い色が汚れを隠しうることを確かめたか（S43。実務者の見解）
- 範囲外: 医療機器の規制・衛生・洗浄・消毒・電気安全・測定精度は、有資格者・認証機関への確認事項に置いた
- 推測の明示: 握りの径・ボタンの大きさ・質量・色は出典がなく、実測と利用者で置き換える。実在の製品の形を写していない
