# 例: 家庭用の電気ケトル（形・肉厚・注ぎ口の指定書）

家庭用の電気ケトルの外装について、形・肉厚・注ぎ口・握り部を、成形の制約と人の手の分布から詰める指定書の例。題材は架空の製品で、実在の製品の外観・名称は模倣しない。操作・画面・文言は扱わない（導入されていれば designer-apple の hardware-ui の例が受け持つ）。成形の値は受託企業の目安で、成形メーカーへの確認事項に置く。電気・熱・食品接触の安全は範囲外である。外装の形を成形の制約に結ぶときと、企業ごとに食い違う値の扱いを見たいときに開く。

## 依頼

- 製品: 家庭用の電気ケトル「ヒノデ」（架空。製造は架空の会社「きた製作所」）。外装は樹脂の射出成形を想定する
- 依頼文: 「注ぎやすく、液だれせず、ふたの開け閉めが楽なケトルにして」
- 現状: 注ぎ終わりに湯が胴の外へ伝う。ふたが固く両手が要る。外装に厚い部分と薄い部分が混在し、表面にひけが出る。外装は金属調の塗装。握り部が太く、手の小さい人が持ちにくいという声がある
- 想定するユーザー: 家庭の台所で、片手で持ち上げて注ぐ人。手の大きさはさまざま

### 根拠の範囲（先に読む）

- 注ぎ口の形は、卓上しょうゆびんが 3 年・ほぼ 100 の試作で詰められた、という機関の記述（R。S27）を背景に置く。常温の調味料で、熱湯のケトルとは条件が違う。その注ぎ口の形をケトルへ写さない。この例では、注ぎ口の形を試作の変数にして、試験で比べる
- 抜き勾配・肉厚・リブの値は、受託企業の設計ガイドの目安（R。S38 から S42）で、規格ではない。値は企業ごとに食い違う。材料のデータシートと成形メーカーで確かめる
- 握り部と口径は、AIST の青年群の平均値（S33・S34）を出発点にする。パーセンタイルではなく、握り内径の定義と、握り部の太さとの関係は本 skill で照合していない（関係は本 skill の推測）
- 電気安全・熱・食品接触（湯に触れる材料）・ふたのロック・最高水位の表示・蒸気・転倒時の湯こぼれは範囲外。値も決めない。有資格者・認証機関に確認する

## 目的の一文

手の大きさの異なる人が、片手で水を入れ、湯を狙った所へ注ぎ終えられる。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 注ぎ口まわりの装飾的な縁取りと段 | 注ぎ口は湯の流れを決める形だけにする。縁取りが流れを良くするかは、注ぎの試験で確かめる（本 skill の整理） |
| 外装の凸ロゴ・厚い装飾の盛り上がり | 厚すぎる部位は、ひけ・反り・ボイドの原因になる（R。S39）。ロゴは平らな印刷か浅い刻印にする |
| 金属調の塗装 | 塗装の追加工程は、外観の都合だけで入れない。素材の色で見せる（S20 の考え方の転用。工程を省くと見た目が変わる例） |
| ふたの飾りつまみ | ふたを開ける指掛かりは、機能の形にする。装飾を足さない。蒸気・熱接触の観点は有資格者・認証機関へ確認（本 skill の範囲外） |

「隠す」は「削る」に数えない。継ぎ目を隠すための化粧部品は足さない。

注ぎの試験（常温の水）:

- 条件: 満水・半量の 2 通りと、傾ける速さ 3 通り（ゆっくり・普通・速い）。本 skill の目安（出典なし）
- 見るもの: 注ぎ終わりに胴の外面へ伝う水の有無（拭き取り紙で確かめる）、狙った所とのずれ、注ぎ始めの飛び出し
- 熱湯での試験は、安全の手順を決め、有資格者の確認を得てから行う。この例では扱わない

色（本 skill の目安。出典なし）。外装は 2 色にとどめる。淡色は着色が安く、濃色は汚れや欠点を隠しやすい、という実務者の見解がある（B。S43）。

| 名前 | 値（画面上の指定） | 用途 |
|---|---|---|
| 生成り | #F2EEE6 | 淡色の本体 |
| 墨 | #2B2B2E | 濃色の本体。淡色の本体に印刷する文字 |

コントラスト比（WCAG の相対輝度式で計算）: 墨 / 生成り（淡色の本体への印刷）12.20、生成り / 墨（濃色の本体への印刷）12.20。凸でない浅い刻印は、色でなく陰影で読ませるため、この比の対象外で、実物で確かめる。判定の基準値（4.5:1・3:1）は本 skill で原文を照合していない（未照合）。画面上の値は、実物の樹脂の着色と照明で変わる。検討用の画像の見栄えに頼らず、実物の色見本で確かめる（S05）。

## コード断片

目安を換算して並べるだけの計算（標準ライブラリのみ。外部の資源・計測は使わない）。入力は仮の値で、仕様値ではない。

```python
# 仮の入力（出典なし）。実際の値は、材料のデータシートと成形メーカーとの確認で置き換える
DEPTH_MM = 200.0     # 外殻のキャビティ深さ（仮）
WALL_MM = 2.5        # 公称肉厚（仮）。確定した値ではない

# 抜き勾配: 目安（出典あり・値は企業ごとに異なる）。換算して並べるだけで、仕様値にしない
rule_of_thumb = DEPTH_MM / 25.0   # S38: キャビティ深さ 25 mm あたり 1 度（S39 は 1 インチあたり 1 度で、ほぼ同じ値）
outer_min = 2.0                   # S41: 外壁の最小 2 度
print(f"抜き勾配: 経験則 {rule_of_thumb:.1f} 度 / 外壁の最小 {outer_min:.1f} 度。食い違うので成形メーカーに確認")

# リブ: 目安（出典あり・値は企業ごとに異なる）。S42 の「%」で書かれた勾配は度に換算しない
RIBS = [("S40", "60% 以下", 0.60), ("S42", "50〜60%", 0.60), ("S41", "0.5 倍", 0.50)]  # (出典, 原文の表現, 比の大きい側)
for src, text, upper in RIBS:
    print(f"リブ厚（{src}）: 主壁の {text} -> 公称肉厚 {WALL_MM} mm のとき、比の大きい側で {upper * WALL_MM:.2f} mm")
print(f"リブ高さ（S40）: リブ厚の 3 倍まで -> リブ厚 {0.60 * WALL_MM:.2f} mm のとき {3 * 0.60 * WALL_MM:.2f} mm 以下")
```

実行結果（仮の入力。本文の仕様値ではない）:

```text
抜き勾配: 経験則 8.0 度 / 外壁の最小 2.0 度。食い違うので成形メーカーに確認
リブ厚（S40）: 主壁の 60% 以下 -> 公称肉厚 2.5 mm のとき、比の大きい側で 1.50 mm
リブ厚（S42）: 主壁の 50〜60% -> 公称肉厚 2.5 mm のとき、比の大きい側で 1.50 mm
リブ厚（S41）: 主壁の 0.5 倍 -> 公称肉厚 2.5 mm のとき、比の大きい側で 1.25 mm
リブ高さ（S40）: リブ厚の 3 倍まで -> リブ厚 1.50 mm のとき 4.50 mm 以下
```

## 初見検証

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | どちらが注ぎ口で、どこを持つか | 注ぎ口の突き出しと握り部の位置 |
| 何を操作できるか | ふたを開ける、持ち上げて注ぐ | ふたの指掛かりと握り部 |
| どう操作するか | 片手で握り部を持ち、傾けて注ぐ。ふたは片手で開ける | 握り部の形と、ふたの動き |

説明を渡さずに、常温の水で、手の大きさの異なる人（小さい手・大きい手の両端を含む）に、ふたを開けて水を入れ、注いでもらう。空・半量・満水で持ち上げ、片手で足りるか、持ち替えたか、注ぎ終わりに外面が濡れたかを見る。熱湯は使わない。

## 点検

- 制約の表: 使う人・作り方・置く場所・寿命・直し方を書いたか。目的を一文で言い直せたか
- 成形の値: 受託企業の目安を、規格として確定していないか。食い違い（2° と深さ 25 mm あたり 1 度）を示し、成形メーカーへの確認事項に置いたか。% の勾配を度に換算していないか
- 肉厚: 厚い部位を作っていないか（S39）。公称肉厚は仮の入力のままで、確定した値として書いていないか
- 握り部と口径: 平均値でなく両端の手で確かめたか。年と集団を明記したか（S33・S34）。握り内径の定義を照合したか
- 注ぎ口: S27 の形を写していないか。試作の変数と、常温の水での試験の手順があるか
- 色: 画面上の値を実物で確かめたか。判定の基準値は未照合と明記したか
- 失敗パターン: 受託企業の目安を規格と取り違えていないか。検討用の画像の見栄えが検討不足を隠していないか（S05）
- 範囲外: 電気安全・熱・食品接触・ふたのロック・最高水位・蒸気・転倒時の湯こぼれを、有資格者・認証機関への確認事項に置いたか
- 推測の明示: 注ぎ口の形が液だれを抑えるか、握り部の太さが合うか、ふたの操作力が楽か、は試作と実際の利用者で確かめる。この例では分からない
