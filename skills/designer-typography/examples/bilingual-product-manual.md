# 例: 日英併記の製品マニュアル（A5・20 ページ）

日本語と英語を併記する取扱説明書の文字組を決める例。型番・単位・数字の組み方、警告ブロックの階層、日英併記の行長と行間、和文の両端そろえと欧文のハイフネーションの扱いを示す。題材は架空の製品と会社で、実在の製品・社名・安全表示の様式は含まない。開くのは、和欧混植の説明書・仕様書を組むとき。

## 依頼

- 場面: 架空の会社「ナギ電機」の家庭用ポータブル電源「ナギ電源 NK-300」の取扱説明書。A5 縦・20 ページ・黒 1 色の印刷物で、同じ PDF を Web でも配る
- 依頼文: 「取扱説明書を日本語と英語で併記して作って。警告・型番・単位が多い。読みやすくそろえたい」
- 読み手: 日本語の読み手と英語の読み手が半々。多くは机の上で冊子を開き、手順を見ながら操作する。警告は、読み飛ばされても気づける必要がある
- 制約: 製品の警告表示の法令・規格への適合、翻訳の正確さは、本 skill が判断しない（点検を参照）

### 根拠の範囲（先に読む）

- 日本語の数値は JLREQ（書籍）に、欧文の助言は Butterick（実務家。C）にある。製品マニュアルに直接当たる出典は無い。以下は、それらを和欧併記の A5 に当てはめた本 skill の整理である
- 数字と単位の間の空き、警告の階層、行送りの値は出典が無く、本 skill の目安（出典なし）。社内の表記規則・印刷会社の入稿規定を先に確認する
- 欧文の左そろえやハイフネーションの助言（S49。C）は英語の本文向けで、和文には当てはまらない（S08）。同じ版面で両方を組むので、言語ごとに分けて決める

## 目的の一文

日本語の読み手も英語の読み手も、自分の言語の手順と警告を迷わず追え、型番と数値は言語を問わず同じ形で読める。

## 削るもの

| 入れない要素 | 理由 | 削り方 |
|---|---|---|
| 全角の英数字（ＮＫ－３００） | 横組みの欧字はプロポーショナルが基本で、全角は勧められない（S07） | 英数字・記号は半角に統一 |
| 日本語へのイタリック | 傾けただけの斜体になり、可読性に劣る（S28） | 和文の強調は太さ。英文の強調は太字またはイタリック |
| 警告の色分け | 黒 1 色の印刷では色が使えない。色だけでは階層が伝わらない | 反転した見出し帯・枠の太さ・枠の有無で 3 段に分ける |
| 数値・型番の二重掲載 | 日英で別の表記になり、食い違いの元になる | 仕様表の値の列は 1 つにして、日英で共有する |
| 書体 3 系統以上 | 階層はサイズ・太さ・空きで足りる（S35 の考え方） | 和文・欧文は 1 系統ずつ。等幅は使わない |
| 手動の和欧間スペース | `text-autospace` との二重になる（S13・S20） | ソースに入れず、自動の空きに任せる |

## 構成

併記の方式は 3 つある。依頼の読み方（手順を見ながら操作する）と版面の算術で、A を選ぶ。

| 方式 | 利点 | 難点 |
|---|---|---|
| A 項目ごとに日本語→英語を交互 | 対応が一目で分かり、改訂も項目単位 | 読み手は反対の言語を読み飛ばす |
| B 左右 2 段 | 対訳が横に並ぶ | 段幅約 54 mm は、和文 9 pt で約 17 字。S02 の 40 字や S66 の 20〜29 字（R。原論文未取得）より短く、禁則の調整が増えると推測する |
| C 前半に日本語・後半に英語 | 各言語で通して読める | 2 部の対応づけと更新漏れの管理が要る |

```text
 1 表紙           2 目次           3〜4 安全上のご注意（警告・注意）
 5〜6 各部の名称   7〜14 使いかた（番号付き手順）
15〜17 仕様（表） 18 お手入れ・トラブル  19 用語表  20 連絡先
```

```text
+-------------------------------------+
| ▲ 警告   WARNING                    |  反転した見出し帯・太枠 2 pt
| 水につけたり…しないでください。…    |  日本語 9 pt
| Do not immerse the unit in water…   |  英語 10 pt（同じ行送り 14 pt）
+-------------------------------------+
```

## 仕様

A5 は 148 x 210 mm。1 pt = 25.4 / 72 mm。

| 項目 | 値 | 根拠 |
|---|---|---|
| 文字サイズ | 日本語 9 pt・英語 10 pt | 和文書籍は一般に 9 pt・最小 8 pt、欧文書籍は 10 pt か 12 pt（S02）。英語は S46 の印刷 10〜12 pt（C）の下限 |
| 行長 | 36 字 x 9 pt = 324 pt = 114.3 mm。余白は左右 16.85 mm（(148 − 114.3) / 2） | 書籍の上限 40 字（S02）の内側で、字数の整数倍（S03）。36 字は本 skill の目安 |
| 警告・注意の枠内 | 和文 34 字 x 9 pt = 306 pt = 107.95 mm。枠の内側の幅（324 pt − 両側の枠線）から 306 pt を引いた残りを、左右の余白に等分する（警告の帯・本文とも同じ値） | 行長は字数の整数倍にする（上の行長の行と同じ考え方）。左右の余白を 8 pt に固定すると、Chrome 156 の PDF の実測で警告の枠内は 305.0 pt（33.9 字）になり、両端そろえの 1 行目が 32 字で字間が開いた。枠線は整数 px に丸められる（305.0 pt との差から推定）ので、pt の引き算で余白を決めずに「内側の幅 − 306 pt」で決める。34 字は本 skill の目安（出典なし）。本例の指定の実測は、警告・注意とも 306.0 pt = 34.0 字で、警告の 1 行目が 34 字（PDF） |
| 手順の字下げ | 番号の字下げ 2em = 18 pt（body が 9 pt）。和文は 324 − 18 = 306 pt = 34 字 | 枠内と同じ 34 字になる。2 行にした手順を PDF に出した実測で、和文の 1 行目が 306.0 pt（番号を除いて 34 字）。本 skill の目安 |
| 言語の指定の範囲 | `lang` ごとの文字サイズ・そろえは `body` 以下の要素に当て、`html` に当てない。言語の指定が無い要素（表の数値・字下げの `em`）は body の 9 pt | `html` に `lang="ja"` があるため、`[lang="ja"]` だけだと文書全体が 9 pt・両端そろえになった（Chrome 156 の実測で `html` が 12 px・`justify`）。`body` 以下に限る本例の指定では、`html` は 16 px・`start`。本 skill の整理 |
| 英語の 1 行の字数 | 同じ 114.3 mm。10 pt で約 65〜70 字と推測する。組んだ見本で実測する | 推測。S46 の 45〜90 字（C）に収まる見込みで、S38 の「60 字を超えると読みにくい」（B）の主張は超える。1 つの最適値にしない |
| 行送り | 14 pt 一定（和文 155%・英文 140%） | 行間を一定にする（S02）。英文の 140% は S48 の 120〜145%（C）の内側。和文は本 skill の目安 |
| サイズの段階 | 章見出し 18 pt・本文（和 9 pt／英 10 pt を 1 段とみなす） | Vignelli の内規は 1 ページ 2 サイズ・見出しは約 2 倍（S34。印刷の欧文）。和欧を 1 段とみなすのは本 skill の整理 |
| そろえ | 和文は両端そろえ。英文は左そろえ・ハイフネーションなし | 和文は行頭・行末をそろえるのが原則（S08）。欧文の両端そろえはハイフネーションが前提（S49。C）で、手動のままでは粗くなる |
| 禁則 | `line-break: strict` | 長音・小書き仮名を行頭に置かない（S04、S17）。厳格さは媒体で選ぶ。安全文書は厳格側とする（本 skill の選択） |
| 段落・項目 | 日本語・英語の組は 14 pt 空ける。字下げなし | 短い項目の連なりで、段落ではない（本 skill の選択）。長い説明の段落は 1 字下げ（S09） |
| 欧字 | 半角のプロポーショナル。和文中の欧文の語間は 1/3 em が原則 | S07 |
| 和欧間 | ソースに手動スペースを入れず `text-autospace` に任せる | S13・S20。対応は D01（Chrome・Edge 140、Firefox 145、Safari 18.4。2026-11-15 時点） |
| 型番 | `NK-300`・`NK-AC30`。半角ハイフン 1 種類。行末で割らない | 本 skill の目安 |
| 数値と単位 | 記号の単位（W・Wh・kg・mm・°C）は、数値との間に改行しない空き（`&nbsp;`）。日本語の単位（秒・回）は空けない。% は空けない | 本 skill の目安。規格・社内規則は未照合 |
| 範囲・寸法 | 日本語は「0〜40 °C」、英語は「0–40 °C」。寸法の × は前後に改行しない空き | 本 skill の目安。波ダッシュの文字コードは 1 種に固定する |
| 括弧・句読点 | 日本語は「。」「、」と全角の（）。英語は半角の , . () | 文書内で統一する（S29。公用文向けの規範） |
| 警告の階層 | 警告: 反転した帯＋太枠 2 pt。注意: 白地の帯＋枠 1 pt。お知らせ: 左の縦罫 1 pt のみ | 本 skill の目安。シグナルワードや様式の規格は未照合 |

コントラスト比（WCAG の相対輝度式で計算。基準 4.5:1。S67。PDF を画面で見る場合の値で、印刷ではインキと用紙で決まる）:

| 組み合わせ（前景 / 背景） | 比 |
|---|---|
| 本文 #111111 / 白 | 18.88 |
| 反転した帯の文字 白 / #111111 | 18.88 |
| ページ番号・注記 #444444 / 白 | 9.74 |

## 文言

| 項目 | 日本語 | 英語 | 理由 |
|---|---|---|---|
| 警告 | 水につけたり、濡れた手で電源プラグを抜き差ししたりしないでください。感電・火災・故障の原因になります。 | Do not immerse the unit in water, and do not plug or unplug the power cord with wet hands. Doing so may cause electric shock, fire, or malfunction. | 禁止を先に言い、結果を後に置く。日英とも 2 文 |
| 注意 | 充電中は、本体を布や布団で覆わないでください。熱がこもります。 | Do not cover the unit with cloth or bedding while charging. Heat may build up. | 注意は警告より短く、結果も軽い |
| 手順 1 | 電源ボタンを2秒間押し続けます。 | Press and hold the power button for 2 seconds. | 数字は半角。「2秒間」は空けず、英語の単位は語として空ける |
| 仕様 | 定格出力 / 300 W | Rated output / 300 W | 数値と単位は日英で共有し、値の列を 1 つにする |
| 範囲 | 使用温度 / 0〜40 °C | Operating temperature / 0–40 °C | 範囲の記号だけは言語ごとの行を持つ（例外） |
| 本文中の型番 | NK-300は定格出力300 Wです。 | The NK-300 has a rated output of 300 W. | 日本語側は和欧間を空けない。「300 W」の空きは手動で入れる |

用語は日英で 1 対 1 にする（19 ページの用語表）。例: 本体 = the unit、電源プラグ = power plug、電源コード = power cord。同じ概念に別の語を使わない。

## コード断片

A5 の印刷・PDF 用の HTML/CSS。外部のスクリプト・フォント・計測は使わない。用紙の単位は pt と mm（印刷媒体のため。画面の本文には使わない）。`@page`・`hyphens` の対応状況は本台帳で未照合で、使う直前に確認する。

```html
<html lang="ja">
<section class="sign warning" aria-labelledby="w1">
  <h3 id="w1"><span lang="ja">▲ 警告</span><span lang="en">WARNING</span></h3>
  <div class="pair">
    <p lang="ja">水につけたり、濡れた手で電源プラグを抜き差ししたりしないでください。感電・火災・故障の原因になります。</p>
    <p lang="en">Do not immerse the unit in water, and do not plug or unplug the power cord with wet hands. Doing so may cause electric shock, fire, or malfunction.</p>
  </div>
</section>
<ol class="steps"><li class="pair">
  <p lang="ja">電源ボタンを2秒間押し続けます。</p>
  <p lang="en">Press and hold the power button for 2 seconds.</p>
</li></ol>
<table class="spec"><tr>
  <th><span lang="ja">定格出力</span><span lang="en">Rated output</span></th>
  <td class="num">300&nbsp;W</td>
</tr></table>
```

```css
@page { size: 148mm 210mm; margin: 18mm 16.85mm 20mm; }
:root { --ja: 9pt; --en: 10pt; --pitch: 14pt;
  --measure: calc(var(--ja) * 36);                 /* 324pt = 114.3mm */
  --inner: calc(var(--ja) * 34); }                 /* 枠内・手順の和文 306pt = 107.95mm */
body { margin: 0; color: #111; line-height: var(--pitch); font-size: var(--ja);   /* 言語の指定が無い要素（表の数値・手順の字下げ）は 9pt */
  font-family: "Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif; }
.page, .sign, .spec { inline-size: var(--measure); }
body [lang="ja"] { font-size: var(--ja); text-align: justify; line-break: strict; text-autospace: normal; }   /* body 以下に限る。html の lang には当てない */
body [lang="en"] { font-size: var(--en); text-align: start; hyphens: manual;
  font-family: "Noto Sans", "Helvetica Neue", Arial, sans-serif; }
p { margin: 0; }
.pair { margin: 0 0 var(--pitch); break-inside: avoid; }      /* 日英の組の間は 1 行 */
.model { white-space: nowrap; }

.sign { --inset: calc((100% - var(--inner)) / 2);   /* 枠の内側の幅から 34 字分を引いた残りを左右に分ける。枠線の太さに左右されない */
  box-sizing: border-box; break-inside: avoid; }
.sign > h3 { margin: 0; padding: 0 var(--inset); font-weight: 700; }
.sign > h3 [lang="en"] { margin-inline-start: 1em; }

.warning { border: 2pt solid #111; }
.warning > h3 { background: #111; color: #fff;                 /* 反転の帯 */
  -webkit-print-color-adjust: exact; print-color-adjust: exact; } /* 背景の印刷が切られると白地に白文字で消えるため、背景を必ず出す */
.caution { border: 1pt solid #111; }
.caution > h3 { border-block-end: 1pt solid #111; }            /* 白地の帯 */
.note { border-inline-start: 1pt solid #111; padding-inline-start: 8pt; }

.steps { margin: 0; padding-inline-start: 2em; }              /* body が 9pt なので 2em = 18pt。和文は 306pt = 34 字 */
.spec { border-collapse: collapse; }
.spec th, .spec td { padding: 3.5pt 0; border-block-end: 0.5pt solid #111; text-align: start; vertical-align: top; }
.spec th span { display: block; }
.num { font-variant-numeric: tabular-nums; white-space: nowrap; }  /* 対応は未照合。無くても崩れない */
```

## 初見検証

日本語の母語話者と英語の母語話者に、それぞれ 2 人ずつ確かめる（人数は本 skill の整理）。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 警告・注意・お知らせの順に重いと、説明なしで言える。白黒の印刷で区別できる | 3〜4 ページの警告ブロック |
| 何を操作できるか | 自分の言語の手順だけを番号で追え、反対の言語に迷い込まない | 7 ページの手順 |
| どう読み進めるか | 日本語と英語の境目が分かり、英語の読み手が日本語の段落を飛ばせる | 日英の組 |
| 数値を読めるか | 「300 W」「3.6 kg」が 1 つの塊で、言語に関わらず同じ位置にある | 15 ページの仕様表 |
| 型番を探せるか | 型番が行末で割れず、拾い読みで見つかる | 本文中の型番 |

境目が分からなければ、日英の間を 7 pt 空ける（行送りの 14 pt の格子から外れるので、そのときは格子を外すと決めて記録する）。

## 点検

- 行長・行送り: 日本語は 36 字（114.3 mm）、警告・注意の枠内と手順は 34 字（107.95 mm）。枠の中で字間が開いていないか、書き出した PDF で 1 行目の字数を数える。英語の 1 行の字数を実測し、S46・S38 の範囲と並べて判断する。行送りは 14 pt 一定
- そろえ: 日本語は両端そろえで行末のばらつきが無い。英語は左そろえで、ハイフネーションに頼っていない（S08・S49）。約物の前後が不自然に広がっていないか、書き出した PDF で確認する
- 和欧間: 自動の空きと手動スペースの二重が無い（S13・S20）。漢字・かな・数字・欧字のそれぞれの境で空きが同じに見えるか、実機で確認する（かなとの境の挙動は未照合）
- 表記: 全角英数が無い（S07）。日本語にイタリックが無い（S28）。ハイフン・波ダッシュの文字コードが 1 種。句読点・括弧が日本語と英語で別々に統一されている（S29）
- 用語: 日英の用語表と本文が一致している
- 色: 黒 1 色で階層が成り立つ。色を足すなら追加の手がかりにとどめる。ブラウザーの印刷で「背景のグラフィック」を切った設定でも、警告の帯が読めるか（反転の帯は背景に頼るので `print-color-adjust` で背景を出す。印刷ダイアログの設定は実機で確かめる）
- 範囲外: 警告表示の法令・規格への適合、安全上の表現、翻訳の正確さは、製品安全の担当・法務・翻訳者に確認する。入稿規定・用紙・書体の使用許諾と PDF への埋め込みは、印刷会社・権利者に確認する
- 失敗パターン: 欧文の助言（左そろえ・字間）を和文へ持ち込んでいないか。WCAG の試験値（0.12em など）で本文を組んでいないか（S25）
