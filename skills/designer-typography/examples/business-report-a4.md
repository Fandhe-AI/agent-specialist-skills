# 例: 社内の事業報告書（A4・印刷と PDF）

約 20 ページの四半期の事業報告書の組みを、基本版面から先に決める例。字下げ・見出しの階層・表の文字組・和欧混植と約物の統一を扱う。Web の数値（16 CSS px・行間 175% など）を印刷へ持ち込まず、印刷物の出典のある範囲で組む。題材は架空で、実在の企業・数値は含まない。制作の着手前に開く。

## 依頼

- 会社: 架空の機械部品メーカー「ハナミズキ工業」。報告書は「2026 年度 第 2 四半期 事業報告書」（約 20 ページ。数値はすべて架空）
- 依頼文: 「四半期の事業報告書（A4）の組み体裁を決めて。表と欧文の用語（EBITDA・YoY など）が多い」
- 想定する読み手: 経営会議の出席者。事前に A4 に印刷して読み、PDF でも受け取る。片面印刷・左上ステープルを前提にする（本 skill の前提。実際の運用は確認する）
- 言語: 和文。欧文の用語・数字・単位が混じる横組み

## 目的の一文

経営会議の出席者が、A4 に印刷した約 20 ページを、見出しだけ拾って全体の結論をつかみ、必要な章の本文と表を読み間違えずに読める体裁にする。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 見出し 5 段階（章・節・項・目・号） | サイズと太さを 3 段（章・節・項）に絞る。Vignelli は 1 ページのサイズを原則 2 つまでとする（S34。欧文の印刷向けの内規） |
| 書体 3 種 | 1 系統で太さを変える。和文書体の種類を決める出典は無い |
| 本文を欧文の流儀の「字下げなし・段落間を空ける」にする | 和文の書籍は 1 字下げ、段落間は通常行間と同じが既定（S09）。「どちらか一方」は欧文の助言（S46） |
| 左そろえ（ragged right） | 和文の書籍本文に対応する概念は無く、行頭・行末をそろえるのが原則（S08） |
| 表の縦罫・濃い網掛け・色分け | 数値の列の読みを妨げる。白黒印刷でも区別できる太さ・罫線で分ける（本 skill の整理） |
| 本文より小さい注記を 3 サイズ以上 | 表・注・柱を 8 pt の 1 つにそろえる（S02 の最小） |
| 全角の数字・全角の欧字・手動の半角スペース | 全角の欧字は勧められない（S07）。数字は本 skill の整理で半角にそろえる。和欧間の空きは 1 つの方式にそろえる（S13） |

## 構成

```text
 +------------------------------------+  A4 縦 210 x 297 mm
 |  柱（8 pt。章題）                  |  上余白 34.0 mm
 |  +------------------------------+  |
 |  | 章見出し 20 pt（3 行取り）   |  |  版面 141.1 x 223.7 mm
 |  | 本文 10 pt  40 字 x 40 行    |  |  左右の余白は各 34.4 mm
 |  | 節見出し 10 pt 太字          |  |
 |  | 表 8 pt（行 16 pt）          |  |
 |  +------------------------------+  |
 |  ノンブル（8 pt）                  |  下余白 39.3 mm
 +------------------------------------+
```

- 全体: 表紙 → 目次 → 1 章「要点」（1 ページ）→ 事業別の章 → 付録（表）。章は新しいページから始める
- 基本版面は本文ページで 1 つ。章の最初のページは見出しを 3 行取りにするだけで、版面は変えない（書籍は基本の組体裁が 1 つ。S11）
- 設計の順序: 基本版面（文字サイズ・行長・行間・段）を先に決め、そこから実ページを作る（S11）

## 仕様

基本版面の寸法（pt を 25.4 ÷ 72 で mm に換算）:

| 項目 | 値 | 計算・根拠 |
|---|---|---|
| 判型 | A4 縦 210 × 297 mm | A 判は √2 の比率（S37） |
| 本文の文字サイズ | 10 pt | 目安（出典なし）。書籍は一般に 9 pt、最小 8 pt（S02） |
| 行長 | 40 字 = 400 pt = 141.1 mm | 文字サイズの整数倍（S03）。40 字は書籍の上限の目安で、超えるなら段組（S02） |
| 行送り | 16 pt（行間 6 pt） | 一定にする（S02）。16 pt は目安（出典なし） |
| 行数 | 40 行 | 版面の高さ = 39 × 16 + 10 = 634 pt = 223.7 mm |
| 余白 | 左右 34.4 mm、上 34.0 mm、下 39.3 mm | 210 − 141.1 = 68.9（左右に 2 分）。297 − 223.7 = 73.3（上 34.0・下 39.3） |
| 1 ページの字数 | 1,600 字 | 40 × 40 |
| 章見出し | 20 pt・太字・3 行取り（48 pt）。題は 1 行 20 字（400 pt）以内。折り返すなら 2 行・40 字以内で、行送りは 24 pt | 本文の 2 倍（S34 の内規に倣う）。取りの量と 24 pt は目安。2 行 x 24 pt = 3 行 x 16 pt = 48 pt（下の「章見出しの組み」） |
| 節見出し | 10 pt・太字・前に 1 行空き | 太さと空きで分ける（S32）。サイズは増やさない |
| 項見出し | 10 pt・本文の太さ・番号つきで独立 1 行 | 同上 |
| 表・注・柱・ノンブル | 8 pt | S02 の最小。表の行は 16 pt（文字行 12 pt + 上下 2 pt）で本文の行送りに合わせる |
| 字間 | 空けないベタ組（`letter-spacing` を指定しない） | 和文の字面は正方形で、詰めて組む（S01） |
| 段落 | 頭を 1 字下げ、段落間の空きなし | S09 |
| そろえ | 両端そろえ | S08。調整は語間（欧文間隔）だけでなく他の複数の箇所でも行う |
| 禁則 | 行頭禁則あり、ぶら下げなし | S04。ぶら下げは JIS X 4051 本体の規定ではない（S06） |
| 和欧混植 | 欧字はプロポーショナル。和欧間の空きは組版ソフトの設定に一本化する | S07。設定値（四分アキなど）は本 skill で未照合（S13 は CSS の既定が 1/8 と述べる） |

寸法表は、JLREQ の考え方（行長 = 文字サイズの整数倍、版面の高さ = 行送り × (行数 − 1) + 文字サイズ）で出した字面の寸法である。CSS の行ボックスは 1 行 16 pt で、上下に半行間（3 pt = 1.06 mm）を含むため、40 行で 640 pt（225.78 mm）になる。そこで `@page` の上下余白は寸法表より 1.06 mm ずつ小さくする（上 32.94 mm・下 38.28 mm。本 skill の整理）。

章見出しの組み（本 skill の整理。出典なし）:

- 1 行は 400 pt で、20 pt の字が 20 字。数字・空白も 1 字と数えて、1 行の題は 20 字以内にする
- 2 行に折り返すときは 40 字以内。2 行目が 1〜2 字だけにならないよう、言葉を削る。3 行になる題は書き直す
- 章見出しの高さは、題が 1 行でも 2 行でも 48 pt に固定する。行送りを 24 pt にして、2 行で 2 x 24 = 48 pt、本文の 3 行分（3 x 16）と同じにする。1 行の題は枠の上に置き、下の 24 pt は空く（見出しの前後を 16 pt の倍数に保つため）
- 章の最初のページは、見出し 48 pt + 本文 37 行（37 x 16 = 592 pt）= 640 pt で、通常ページの 40 行（40 x 16 = 640 pt）と同じ
- 例の題「第3章 売上は計画超え、利益率は低下」は、第・3・章・空白を含めて 18 字で 1 行に収まる（18 x 20 = 360 pt ≤ 400 pt）

1 ページに使うサイズは、通常のページで 10 pt と 8 pt の 2 つ。章の最初のページだけ 20 pt が加わる（S34 は原則 2 つで例外ありと述べる）。

表の組み（JLREQ の表の節は本 skill で未読。以下はすべて本 skill の目安で、出典なし）:

| 項目 | 値 |
|---|---|
| 罫線 | 上下 0.75 pt、見出し行の下 0.5 pt、内部は横罫 0.25 pt、縦罫なし |
| 見出し行 | 太字 + 淡い網掛け（`#e6e6e6`）。色だけに頼らず太字を併用する |
| 数値の列 | 右そろえ。桁と小数点位置をそろえる。単位は列見出しに 1 回だけ（「（百万円）」） |
| 文字列の列 | 左そろえ。列幅は内容に合わせる |
| 注記 | 表の下に 8 pt。灰色（`#595959`）にして本文と区別する |

コントラスト比（WCAG の相対輝度式で計算。基準は文字 4.5:1。S67。印刷の色は刷りで確認する）:

| 組み合わせ（前景 / 背景） | 比 |
|---|---|
| 黒 `#000000` / 紙（白） | 21.00 |
| 黒 / 表見出しの網掛け `#e6e6e6` | 16.83 |
| 注記の灰 `#595959` / 紙（白） | 7.00 |
| 注記の灰 / 網掛け | 5.61 |

## 文言

数値は架空。空きは手で入れず、組版ソフトの設定に任せる。

| 場所 | before | after | 理由 |
|---|---|---|---|
| 章見出し | 第3章 事業概況について | 第3章 売上は計画超え、利益率は低下 | 見出しだけ拾って結論が分かる（本 skill の整理）。18 字で、1 行 20 字の上限に収まる |
| 数値 | 営業利益は１２．３億円（前年同期比＋４．２％） | 営業利益は12.3億円（前年同期比+4.2%） | 表記を一方式に統一する（S29）。数字・記号を半角にするのは本 skill の整理（S07 が述べるのは全角の欧字を勧めないこと） |
| 欧文 | ＥＢＩＴＤＡ | EBITDA | 全角の欧字は勧められない（S07） |
| 句読点 | 売上は増えた，利益は減った． | 売上は増えた、利益は減った。 | 一つの文書内で統一する（S29）。民間の報告書は「、」「。」に統一する（本 skill の選択） |
| 空き | 営業利益は 12.3 億円（半角スペースを手で入力） | 営業利益は12.3億円（空きはソフトの設定） | 手動と自動の二重を避ける（S13） |
| 表の単位 | セルごとに「百万円」 | 列見出しに「（百万円）」を 1 回 | 数値の列を読みやすくする（本 skill の整理） |

## コード断片

印刷専用の最小例。画面に使い回さない（画面は可変幅で、紙の固定を持ち込まない。S51）。`@page` の対応と、PDF にするツールの違いは本 skill で未照合のため、実装前に印刷プレビューで確認する。新しい CSS（`text-autospace`・`text-spacing-trim`）の対応は 2026-11-15 時点の D01 による。実際の制作は組版ソフトで同じ数値を設定してよい。外部の CDN・スクリプト・フォントは使わない。

```html
<section class="chapter">
  <h1>第3章 売上は計画超え、利益率は低下</h1>
  <h2>3.1 事業別の売上</h2>
  <p>機械部品事業の売上は、前年同期を上回った。主因は新規の受注である。</p>
  <h3>3.1.1 国内</h3>
  <table>
    <caption>表3-1 事業別の売上（百万円）</caption>
    <thead><tr><th>事業</th><th class="num">計画</th><th class="num">実績</th><th class="num">差</th></tr></thead>
    <tbody>
      <tr><td>機械部品</td><td class="num">1,200</td><td class="num">1,284</td><td class="num">+84</td></tr>
      <tr><td>金型</td><td class="num">640</td><td class="num">612</td><td class="num">-28</td></tr>
    </tbody>
  </table>
  <p class="note">注: 数値はすべて架空。</p>
</section>
```

```css
@page { size: A4; margin: 32.94mm 34.44mm 38.28mm; }   /* 内容 141.12 x 225.78 mm = 40 行 x 16 pt。行ボックスは上下に半行間 3 pt を含むので、字面の位置は寸法表と同じ（上 34.0・下 39.3） */
html { font-size: 10pt; }
body { margin: 0; font: 1rem/16pt "Hiragino Sans", "Yu Gothic", "Noto Sans CJK JP", sans-serif;
  text-align: justify; line-break: strict;                     /* S08・S04 */
  text-autospace: normal; text-spacing-trim: normal; }          /* あれば使う。無くても崩れない */
p { margin: 0; text-indent: 1em; orphans: 2; widows: 2; }       /* 1 字下げ・段落間なし（S09） */
h1 { font-size: 20pt; line-height: 24pt; block-size: 48pt; margin: 0; break-before: page; }   /* 3 行取り = 48 pt。題は 20 字 x 2 行まで（2 x 24 = 48 pt） */
h2 { font-size: 1rem; line-height: 16pt; font-weight: 700; margin: 16pt 0 0; break-after: avoid; }
h3 { font-size: 1rem; line-height: 16pt; font-weight: 400; margin: 0; break-after: avoid; }

table { width: 100%; margin: 16pt 0 0; border-collapse: collapse; font-size: 8pt; line-height: 12pt; break-inside: avoid; }
caption { text-align: left; font-weight: 700; padding-bottom: 2pt; }
th, td { padding: 2pt 4pt; text-align: left; }                  /* 行の高さ 12 + 4 = 16 pt */
th { font-weight: 700; background: #e6e6e6; border-top: 0.75pt solid #000; border-bottom: 0.5pt solid #000; }
td { border-bottom: 0.25pt solid #000; }
tbody tr:last-child td { border-bottom: 0.75pt solid #000; }
.num { text-align: right; font-variant-numeric: tabular-nums; }
.note { margin: 0; text-indent: 0; font-size: 8pt; line-height: 16pt; color: #595959; }
```

罫線の太さが加わり、表全体の高さが 16 pt の倍数にそろわないことがある。表のあとで本文の行位置が半端にずれる場合は、組版ソフトで調整するか、表の下に余白を足してそろえる。柱とノンブルは `@page` のマージンボックスで書けるが、対応は未照合のため、対応しない環境では組版ソフトで出す。

## 初見検証

目次と章見出しだけを見せ、本文は読ませずに 3 つの問いに答えてもらう。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 今期の結論（売上は計画超え・利益率は低下） | 章見出しと 1 章「要点」 |
| 何を読めばよいか | 結論の根拠は 3 章の表 3-1 | 目次・章見出し・表の題 |
| どう読み進めるか | 章の見出しから節へ、節から表へ。数値は列見出しの単位で読む | 見出しの階層（章 20 pt・節は太字・項は番号つき）と表の単位 |

答えられない場合は、本文を足さず、見出しを結論の形に直し、見出しの階層を見直す。

## 点検

- 印刷: A4 に実寸（拡大縮小なし）で白黒印刷し、本文 10 pt と表の 8 pt が読めるか。網掛けと太字で表見出しが区別できるか。PDF を拡大しても表が崩れないか
- 基本版面: 行長が 40 字ちょうどで、全行が同じ長さ（段落の最終行を除く。S03）。行送りが一定（S02）。見出しの前後が 16 pt の倍数
- 章見出し: 題が 1 行 20 字（折り返すなら 2 行・40 字）以内で、見出しの高さが 48 pt。本文の最初の行が、章の最初のページでも 16 pt の格子に載っている
- 約物・和欧: 句読点・括弧・数字・単位の表記が一方式（S29）。全角の数字・欧字・手動の半角スペースが残っていない（S07・S13）。日本語にイタリックを使っていない（S28）
- 失敗パターン: Web の数値（16 CSS px・行間 175%。S27）と Web の行長の目安（36 字。本 skill の目安）を印刷へ持ち込んでいない。欧文の「字下げか段落間の一方」を持ち込んでいない（S09・S46）。見出しの段階を増やしていない
- 色: 上の比がすべて 4.5:1 以上（S67）。印刷の色は刷り上がりで確認する
- 推測の明示: 10 pt・16 pt・余白・表の罫線は本 skill の目安で、この報告書での実測ではない。表の組みの規則（JLREQ の表の節）と `@page` の対応は未照合。入稿規定・印刷会社の設定・フォントの許諾は、相談者が確認する
