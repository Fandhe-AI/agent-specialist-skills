# デザイン史: ロゴ・アイデンティティ・ガイドラインの変遷

制作とレビューの判断に歴史を使うための参照。年表の暗記用ではなく、「いま作っているロゴや規則は、どんな制約から生まれたか」を確かめるための材料である。企業の標識、システムとしてのアイデンティティ、日本の CI、公開が前提の発表、可変アイデンティティ、商標の境界を、時代ごとに同じ 4 項目で書く。本ファイルは 1 本で完結する（要点と時代別の詳細を分けていない）。中心の問いは次の 1 つ。

> そのロゴ・ルールは、どんな制約から生まれたか。今回の媒体・組織・利用者でも、その制約は成り立つか。

成り立つなら、慣習は今も根拠を持つ。成り立たないなら、様式だけが残っている可能性がある。出典が薄い論点（Saul Bass、Unimark と NYC 地下鉄の標準マニュアルの本文、Wolff Olins 自身の説明、亀倉雄策と田中一光の本人の発言）は、「詳細は未照合」と明記して補わない。

このファイルを開くのは、相談者が背景を求めたとき、制作の着手前（「媒体別の使い方」の節）、レビューで「由来」の項目が不明のとき、の 3 つである。

## 読み方と記法

- 時点: 本ファイルの記述は 2026-11-15 時点（出典の取得日）。出典の詳細（引用原文・日付・URL・検証区分）は `sources.md` を参照する。
- 各時代の 4 項目: 当時の制約 / 応答 / 副作用と反動 / 今の判断への示唆。4 項目めの「示唆」はすべて「本 skill の整理」で、出典が述べた因果ではない。因果（「A だから B になった」）は、出典が述べている場合だけ S 番号付きで書く。
- 区分は `sources.md` の凡例に従う（A 原典、B 第三者の転記・再話、C 論評、R 記者・機関の地の文、U 未検証）。逐語で本人の発言として示してよいのは区分 A だけで、B・C・R は区分を明記した要旨にする。Rand の文章・発言（S01 から S03）は愛好家サイトの転記（B）なので、本ファイルでは英語の逐語で本人の発言として示さず、要旨にする。
- 日本語の記述は本 skill の言葉で、発言者本人の発言ではない。
- 企業・機関の沿革や発表（S05、S08、S17、S18）は、その組織が述べた範囲で使う。理由・因果は組織の説明であり、社内の実際の意思決定と同じとは限らない。
- 年が出典どうしで食い違うもの、数が合わないものは、両側を挙げて注記する（5 件。一覧は「年が食い違う出典・数値が合わない出典」）。
- ガイドラインの数値（最小サイズ・余白）は、その組織の紋章やロゴに対する規定で、他のロゴへそのまま適用できるとは原文は述べていない。
- 回答での使い方: 頼まれない限り、歴史を講釈しない。判断の根拠として 1 行で使う。

## 回答での使い方（例）

歴史は、判断の根拠として 1 行で添える。講釈にしない。

- 相談「ロゴを新しくすれば会社が変わると思う」: 企業が新ロゴを求めたとき、IBM は新時代を示しつつ連続性も伝えるロゴを求めたと述べる（S05）。新しさだけを求めた依頼ではなかった。まず「変える理由」と「残すもの」を言語にさせる（本 skill の整理）。Rand は、新しい・更新したデザインが事業を魔法のように変えるという信念は珍しくなく、新しさを示せても、会社が主張に見合わなければ短命だと書く（S01、B。要旨）。
- 相談「発表前に常連へ聞かず、新ロゴを一斉に出したい」: Gap は新ロゴを取りやめたとき、進め方に誤りがあったと述べた（S24）。ロゴの良し悪しより、誰の持ち物を、どう変え、どう発表するかが問われた（本 skill の整理）。
- 相談「商標調査はしたので安全だ」: 東京 2020 のエンブレムは、発表前に商標調査を経たとされながら、使用中止になった（S17）。調査は登録上の確認で、模倣の疑念や世論への対応とは別である（本 skill の整理）。法的判断はせず、専門家へ渡す（S15、S16、S32）。
- 相談「無印良品のようにシンプルにしたい」: 無印良品自身が、ミニマリズムというスタイルではないと述べる（S09）。様式でなく、「空っぽ」の器という設計方針として翻訳する（S09、S10、本 skill の整理）。
- 相談「ガイドラインを厚くして守らせたい」: 規則が複雑なほど守られなくなる、という指摘がある（S30、C。意見で実証はない）。固定する資産を少数に絞る（本 skill の整理）。

## 繰り返すパターン（本 skill の整理）

次の型は、複数の時代を横断して読み取ったもので、出典が述べた法則ではない。例外は多い。

1. 制約が先で、規則は後から付く。NASA は、旧エンブレムが当時の技術で複製・印刷しにくかったと述べる（S08）。Rand は、ストライプを署名の下に引く偽造防止の線という発想から得たと語る（S02、S03。B・要旨。IBM のロゴとの対応は台帳の備考の読み）。形は、複製・読み取りの制約への応答として生まれる。
2. 簡素にしても永続は保証されない。NASA の "worm" は 1975 年に導入され、1992 年に退役し、2020 年に復活した（S08）。退役の理由は取得した NASA の記述に無い。
3. ロゴ単体からシステムへ。Vignelli は、本物のアイデンティティはロゴだけでなく全体の方式に立つと書く（S06）。NASA（S07）・英国政府（S14）・CNCF（S19）のガイドラインは、改変の禁止・余白・版・色を定める。
4. 固定と可変の釣り合い。Vignelli は、多様性が過ぎれば断片化し、同一性が過ぎれば記憶に残らないと書く（S06）。Pentagram は、固定のアイデンティティと多様性の祝福を両立させたと述べる（S13）。
5. 変更は、持ち主の目線で受け止められる。Bierut は、人は目立ちたいのでなく溶け込みたいと論じる（S12）。Gap の撤回（S24）、London 2012 への批判（S26、S27）、UC の新ロゴに反対する請願（署名 54,000 超。S12）は、発表の仕方と受け止めの問題として読める（本 skill の整理）。
6. 規則は判断の道具で、自己目的化すると反動が来る。Vignelli は、変更のための変更が動機であることが多く、それは誤った動機だと書く（S06）。批判側は、ガイドラインが統制の道具になっていると主張する（S29、S30。意見で実証はない）。
7. 差別化と機能の綱引き。Base Design は、サンセリフと鮮やかな色が多様な媒体で拡縮・可読になると認めたうえで、没個性化を批判する（S28）。批判側も機能面の理由は否定していない。
8. 商標調査は必要だが、安全の保証にならない。公的機関自身が調査の限界を述べる（S15、S16、S32）。

| ロゴ・ワードマーク | 何を識別させるためか。単色・極小で成立するか。意味の源は中身の質か、見た目か（Rand の主張。B・要旨で、権威として再生産しない） | 1、5 |

## 時代別の詳細

### 1. 企業の標識が装飾から簡素へ（IBM の例、〜1950 年代）

- 当時の制約: 出典は制約を明示していない。IBM の沿革のロゴ一覧は、1924・1947・1957・1972・1981 の各年を並べる（S05）。個々の旧ロゴの字形の詳細は、取得した引用範囲では未照合。
- 応答: 1956 年、Watson Jr. が Paul Rand を起用し、新時代を示しつつ連続性も伝えるロゴを求めた（S05）。Rand は、製品を売るのではないので説得する相手は依頼主だけで、問題を最小の分母まで削る必要がある、と語った（S02、B・要旨）。Rand は、ストライプを署名の背景に引く細い平行線という法的文書の発想から得たと語る（S02、S03。B・要旨。IBM のロゴとの対応は台帳の備考の読み）。
- 副作用と反動: ストライプを囚人服のようだと揶揄する人がいた（S02。Rand が伝えた他者の発言で、揶揄した人物は特定されていない）。Rand は、識別の問題に好き嫌いが関わるべきでないと書く（S01、B・要旨）。批判側は、Rand の絶対的な言い方は客観的分析を装った価値判断を含むと評した（S04、C。因果は未確認）。
- 今の判断への示唆（本 skill の整理）: ロゴの更新は、見た目の変化だけでなく「何を変え、何を続けると伝えたいか」の宣言になる。依頼を受けたら、まず「変える理由」と「残すもの」を言語化させる。Rand の言葉は権威でなく、一つの立場として使う（S04）。

### 2. システムとしてのアイデンティティ（1960〜1970 年代）

- 当時の制約: 組織が大きくなり、標識・車両・文書・建物に同じ標識が大量に現れる。NASA は、旧エンブレムが 1970 年代の技術では複製・印刷が難しく、複雑な比喩と見る人もいたと述べる（S08）。
- 応答: IBM は 1972 年に 8 本線のロゴを出し、以後ほぼ変えていない（S05）。1970 年の NYC Transit Authority Graphics Standards Manual は Unimark の Vignelli と Noorda が設計した（再刊の販売元の説明。「引用ではない参照」の表。マニュアル本文と制作経緯は未照合）。NASA は 1975 年に、Federal Design Improvement Program から生まれた簡素なデザイン（Danne & Blackburn の作）を導入した（S08）。1976 年 1 月付の Graphics Standards Manual は、ロゴタイプを改変・歪めてはならない、輪郭だけの文字で示してはならない、第二の色が使えるときだけ NASA 赤を使うと定める（S07）。ロゴの周囲の最小の余白として、縦のストローク幅 3 本分が推奨される（S07。引用原文の行に適用対象の語は無く、台帳の備考はデカール用の推奨と読む。ロゴ一般の規定として使わない）。Vignelli は、本物のアイデンティティはロゴだけでなく全体の方式に立つと書く（S06）。
- 副作用と反動: NASA の "worm" は 1992 年に退役し、1950 年代後半の図案が主役に戻った。服や土産物には残った（S08）。2020 年に復活した（S08）。なぜ戻したかの理由は取得した NASA の記述に無い。Rand は、良いアイデンティティが売るのではなく、良い製品が売ると語る（S03、B・要旨）。Vignelli は、変えようとする動機が変更のための変更であることが多く、それは誤った動機だと書く（S06。「それ」が指す対象は引用の外で、ロゴの変更を指すと読めるが、本 skill の読みである）。
- 今の判断への示唆（本 skill の整理）: ガイドラインは、制約（複製・印刷・組織の規模）への応答として生まれた。制約が変わった今は、何を固定し何を動かすかを、ロゴ単体ではなくシステム単位で決める。NASA の例は、複製しにくい形を簡素化した事例であり、簡素な形の永続が保証されない事例でもある（S08）。

### 3. 日本: 国家行事と企業文化（1964 年から 1980 年代）

- 当時の制約: 取得した出典から、制約を述べることはできない。この時代の日本のロゴ・CI は、一次の資料が薄い。亀倉雄策と田中一光の本人の発言は取得できていない。詳細は未照合。
- 応答: 1964 年東京五輪のエンブレムとポスターを亀倉雄策が手がけた（S21、S22）。コカ・コーラの記事は、1960 年に 6 人のデザイナーによるコンペがあり、審査員は亀倉案を一目で選んだとする（S21。B・企業の広告記事の再話。別の報道は異なる経緯を伝えるが未取得）。公式ポスター第 4 号の AD は亀倉、写真は早崎治で、1964 年（S22）。加島卓は、亀倉はシンボルマークを重視し、そのデザインの多くが直線と曲線で構成されると評する（S23、R。筆者の評価で、亀倉本人の発言ではない）。1980 年に無印良品が誕生し、素材の選択・工程の点検・包装の簡略化を基本とした（S09）。のちに原研哉が、田中一光の考え方を引き継いでアートディレクションを担当する（S10。田中の起用年は未取得）。
- 副作用と反動: 無印良品は、自らを「これはスタイルとしてのミニマリズムではありません」と述べ、「空っぽの器」だと説明する（S09、A）。原は、「シンプル」は西洋の近代主義から生まれた、合理性にのっとったものの形の考え方だと述べ、そんな懐の深さを「空っぽ」＝エンプティと呼ぶと述べる（S10、A）。広告は答えでなく、いい問いを投げかけることだとし、実際にどう役に立っているかは自分でもよく分からないと述べる（S10、A）。
- 今の判断への示唆（本 skill の整理）: 「無印っぽく」「シンプルに」の依頼は、見た目の様式ではなく、「空っぽ」の器という設計方針の翻訳が必要になる。ブランドの効果は測りにくいと当事者が述べている（S10）点も、効果を約束することに慎重になる根拠になる。地域のブランドでは、佐藤可士和が今治タオルで、各社の特色より先に「今治」を前面に出すべきだと厳しく言っていたと述べる（S11、A。確認できた本人の発言はこの範囲のみで、一般化しない）。

### 4. 世論が批評する時代（2007 年から 2015 年）

- 当時の制約: ロゴの発表がネットで即座に共有され、専門家でない人が評価に加わる。Bierut は、グラフィックデザインの批評は誰でも参加できる観戦型の競技になったと書く（S12、A）。
- 応答（出来事）: London 2012 のエンブレムは、Wolff Olins のデザインで（S26、S27）、2007 年 6 月の発表直後に、デザイン専門家と一般から批判を受けた（S26、S27）。署名の数は、同じ記事内で 28,000 超（本文）と 30,000 超（副見出し）が併存する（S27）。費用は ABC が約 80 万ドルと書く（S27）。Marketing Week によれば、発表時の発言として、大会は誰のものでもあるという趣旨が引かれ（S26、B・要旨）、批判者の一人は書体の水準と未完成の印象を批判した（S26、B・要旨）。Wolff Olins 自身の説明は未取得で、詳細は未照合。Gap は新ロゴを取りやめ、声明で進め方に誤りがあった、オンラインのコミュニティと関わる機会を逃したと述べた（S24、S25。B）。同記事は、Gap が前の週には新ロゴを擁護していたと報じる（S24）。UC のロゴに反対する Change.org の請願は、署名 54,000 超を集めた（S12）。東京 2020 のエンブレムは、2015 年 7 月 24 日に発表され、同年に使用中止が発表された（S17。日付と出来事の対応は PDF の表組みの読み）。
- 副作用と反動: Bierut は、デザイナーは差別化と独自性を過大評価し、ほとんどの人は目立ちたいのでなく溶け込みたいと論じる。後から変えることを、人々の家に入って持ち物を取り上げ、望んでいないものに替えることにたとえる（S12、A）。Tropicana のパッケージ変更は、Bierut の文中で Gap・London 2012 と並べて言及される（S12）。個別の事実（売上への影響など）は取得していない。東京 2020 は、東京都の資料によれば、組織委員会が発表前に商標調査を経ており問題ないと述べていたが（S17、R）、国民の理解を得ることは困難と判断して使用中止になった（S17、R。組織委員会の判断の要約で、盗用の有無の認定ではない）。
- 今の判断への示唆（本 skill の整理）: 公開が前提のブランドは、デザインの良し悪しの前に、「誰の持ち物を変えるのか」「どう発表し、どう聞くのか」の設計がいる。Gap の声明が反省したのも、ロゴそのものでなく進め方だった（S24）。東京 2020 の事例は、商標調査が済んでも、模倣の疑念や世論への対応は別の問題として残ることを示す（S17。この解釈は本 skill の整理）。

### 5. 可変アイデンティティ・デジタル・没個性化（2010 年代〜）

- 当時の制約: 媒体が画面・小サイズ・動きへ広がり、1 つの固定ロゴだけでは足りなくなる。英国政府のアイデンティティ・システムは、サイズごとに詳細版・縮小版・デジタル用の簡略版を用意し、版ごとに最小サイズを定める（S14。紋章の幅 20 mm 以上、5 mm または 60 ピクセル以上、デジタル用は高さ 50 から 30 ピクセルでの使用。紋章に対する規定で、ロゴ一般の基準ではない。2012 年版で、現行は未確認）。
- 応答: MIT Media Lab のアイデンティティは、7×7 のグリッドに基づくロゴを起点に、23 の研究グループへ拡張した（S13）。Pentagram は、固定のアイデンティティを確立しつつ、活動の多様性を祝福する体系だと述べる（S13。Pentagram 版の採用年は同ページに無く、未確認）。Vignelli は、アイデンティティと多様性の釣り合いを説く（S06）。
- 副作用と反動: Base Design の Brunfaut は 2018 年に、ブランドの要点は差別化なのに、目立たず溶け込むようにデザインされたブランディングがあると批判した。同じ文章の中で、サンセリフと鮮やかな色が媒体をまたいで拡縮・可読になるという機能面の理由も認めている（S28、C）。ガイドラインを統制の道具とする批判（S29）や、一貫性そのものを目的にするなという主張（S30）も出ている（C。意見で実証は示されていない）。Wally Olins は晩年に、ブランディングは複雑になりすぎている、強く関与する指導層がいればプログラムは根づくと述べた（S31、B・要旨）。
- 今の判断への示唆（本 skill の整理）: 小さい版・単色版・動く版を、あらかじめガイドラインに組み込む（S14 の型）。ただし規則が複雑になるほど守られなくなる、という指摘もある（S30）。固定する資産と動かす資産を分ける（S06 の釣り合い。本 skill の整理）。没個性化は「サンセリフだから悪い」ではなく、差別化が目的を失うことが問題と読める（S28。整理）。

### 6. 法務の境界（商標）

- 当時の制約: ロゴは、デザインであると同時に商標でもある。
- 応答: USPTO は、出願が拒絶される最も多い理由の一つは、既登録の商標に類似し混同のおそれがあることだと述べ、連邦データベースの審査官の調査とは別に、州のデータベースとインターネットの調査は出願者の責任だとする（S15）。類似は、外観・称呼・観念・商取引上の印象で見られうる。検索で登録可否の明確な答えは得られず、弁護士への相談を検討するよう勧める（S16）。日本では、INPIT が J-PlatPat の機能は基本的なものに限られる、高度な調査は民間事業者を勧める、利用の結果の損害に責任を負わないと述べる（S32）。団体の側では、PSF が、商標は法的要件に沿って使わないと危うくなりうると述べ（S20）、CNCF はロゴの変更や拡縮を禁じる（S19）。いずれも米国法・日本の公的機関の案内で、法的判断ではない。
- 副作用と反動: 東京 2020 のエンブレムは、商標調査を経たと組織委員会が述べたが、使用中止になった（S17）。
- 今の判断への示唆（本 skill の整理）: この skill は、類否・登録可否・侵害の有無を判断しない。制作側が行うのは、調査が必要な論点（名称・図形・指定商品）を示し、専門家（弁理士・弁護士）に渡すことまで。「見つからなかった」は「使ってよい」の根拠にならない（S15、S16、S32 が述べる調査の限界）。
