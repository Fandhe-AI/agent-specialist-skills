# 例: ブランドガイドライン 1 冊の構成

ボランティアが毎年一部入れ替わるイベントのために、ブランドガイドラインを「分厚いマニュアル」でなく「10 分で読めて守れる 1 冊」に組み直す例。ガイドラインの章立て、固定する核の絞り方、運用の責任者を決めるときに開く。題材は架空の団体で、実在の団体・イベント・ロゴの模倣は含まない。

## 依頼

- 団体: 瀬戸内の港町で毎年、古書と新刊のブックフェアを開く「瀬戸内ブックフェア実行委員会」（架空）。運営はボランティアで、毎年メンバーの半数ほどが入れ替わる（`event-visual-identity.md` と同じ設定）。デザインの経験者がいない年もある
- 使う場面: チラシ・看板・SNS 画像・名札・協賛社への案内状。データは共有のフォルダにある
- 依頼文: 「誰が作っても同じになる、分厚いマニュアルにしたい」
- 関連: 毎年のマークの組み立て（固定の核と年ごとに動く要素）は `event-visual-identity.md` で扱う。本例はそれを含む、ガイドライン全体の章立てと運用を扱う
- 置いた前提（確認が取れていない）: 責任者は未定。予算は少ない。ロゴの商標登録の予定は未定。協賛社や出展者にロゴを使わせる場面がある

## 目的の一文

初めて参加するボランティアが、チラシを 1 枚作る前に 10 分で読み終え、守る項目を迷わず言える。

「分厚い」は目的ではなく手段である。規則が複雑なほど、チームは従わなくなる、という指摘がある（S30、C・要旨。意見で実証は無い）。厚さでなく、守られる量を目的に置く。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 全媒体のテンプレート（チラシ 8 種など） | 複雑さが守られなさを招く（S30、C・要旨）。チラシ・看板・SNS 画像の 3 つに絞る |
| 書体 5 種・色 12 色 | 固定は少数に絞る（本 skill の整理）。書体 1 系統、固定の色は主色 1 色 |
| 誤用 30 例 | 重要な禁止に絞り、図で示す（図で示すのは本 skill の整理。S07 は改変・歪み・輪郭だけの文字を禁じる）。4 例にする |
| 写真の色調・文体の細かい規定 | 年ごとに動かす要素。担当に任せる |
| すべての制作物への承認制 | ガイドラインが審査・統制の道具になるという批判がある（S29、C・要旨）。承認は看板と印刷物だけにし、他は使う前の 3 つの確認で自己点検する（本 skill の整理） |
| 紙の製本だけの配布 | 変更を反映できない。紙 1 冊と、更新できる PDF の両方を持つ（本 skill の整理） |

## 構成

章立ては本 skill の整理である。公開されているガイドラインに見られる項目（改変の禁止、色、余白、版ごとの最小サイズ、使わせ方の規定。S07、S14、S19、S20）を参考に、10 ページに収める。

| ページ | 章 | 内容 |
|---|---|---|
| 1 | はじめに | 目的の一文・守る 10 項目の予告・ブランド担当の名前と連絡先 |
| 2 | 名称とロゴ | 名称の表記。ロゴは 2 つのレイアウト（横組み・マークのみ） |
| 3 | 余白と最小サイズ | 余白の単位・レイアウトごとの最小サイズ |
| 4 | 色 | 固定の主色・年ごとの副色（4 色から 1 色）・使ってよい組の表（コントラスト比つき） |
| 5 | 書体 | 1 系統。ライセンスの確認結果と入手先 |
| 6 | 誤用の禁止 | 誤用 4 例と、正しい 1 例を図で並べる |
| 7 | 使う前の 3 つの確認 | 自己点検の 3 問（文言に示す） |
| 8 | 素材の置き場と連絡先 | データの場所・質問の窓口 |
| 9 | 引き継ぎ | 担当の任期・交代の手順・変更履歴 |
| 10 | 使わせ方 | 協賛社・出展者へロゴを使わせる条件。法的な部分は専門家に確認する |

固定する核と、動かす要素:

| 区分 | 内容 | 根拠 |
|---|---|---|
| 固定（4 つ） | 名称の字面・骨格（3×3 の格子の四隅の 4 マス）・主色（紺 1 色）・配置（マークが左、名称が右、年号は名称の下） | 固定は少数（本 skill の整理）。多様性が過ぎれば断片化し、同一性が過ぎれば記憶に残らない（S06、A） |
| 動かす | 塗るマス・副色・テーマ語・写真・イラスト | 年ごとの担当が決める。副色は計算してから使う（仕様）。詳細は `event-visual-identity.md` |

書体は固定の資産に数えず、守る 10 項目の 1 つとして 1 系統に絞る（本 skill の整理）。

運用の責任者（本 skill の整理）: 実行委員会の代表が、ブランド担当 1 名（`event-visual-identity.md` の引き継ぎ担当と同じ人）と副担当 1 名を指名する。副担当は翌年に担当へ上がり、2 年で交代する。年度の引き継ぎ会で、冊子を読み合わせる。強く関与する指導層がいれば、ブランディングのプログラムは根づく、と Olins は晩年に書いた（S31、B・要旨）。規則より、運用の体制が先である。

## 仕様

出典のある値と、本 skill の目安（出典なし）を分ける。

| 項目 | 値 | 根拠 |
|---|---|---|
| 版ごとに最小サイズを定める | 詳細・縮小・簡略の版に分ける型。本例はレイアウト（横組み・マークのみ）ごとに最小サイズを定める | S14 の型。値は英国政府の紋章に対する規定で、ここへ流用しない |
| 余白は最小の距離で、可能なら広く取る | 除外領域は紋章の幅 1 つ分 | S14。紋章の規定 |
| 色の使い方 | フルカラー・全黒・全白の色。余白を保つ。本来の比率を崩す拡縮・引き伸ばしの禁止（比例の拡大縮小は禁じていない） | S19 の型。本例の色は通常（主色と今年の副色）・1 色（主色）・反転（白）の 3 通りで、`event-visual-identity.md` と同じ |
| 冊子の長さ・規則の数 | 10 ページ・10 項目 | 本 skill の目安（出典なし） |
| 余白（仮置き） | マークの 1 マスの幅 | 本 skill の目安。値は実物で確かめる |
| 最小サイズ（仮置き） | 横組みレイアウトは幅 28 mm、マークのみのレイアウトは 24 px または幅 8 mm | 本 skill の目安。印刷物で試して確定する |

コントラスト比（WCAG の相対輝度式で計算。基準は文字と背景の組で 4.5:1。S33）。年ごとに副色を変えるため、組を表で決めておく。

| 前景 / 背景 | 比 | 判定・用途 |
|---|---|---|
| main #1b2f5b / paper #f7f3ea | 11.82 | 見出し・本文・ロゴ |
| ink #1e1e24 / paper | 14.97 | 本文 |
| grey #5c5c66 / paper | 5.97 | 補助の文字 |
| white #ffffff / main | 13.09 | 反転 |
| 副色 A #b4441c / paper | 5.01 | 年号などの文字（副色 A） |
| 副色 B #1f7a5c / paper | 4.74 | 同上（B。4 色のうち最小で、基準を 0.24 上回る） |
| 副色 C #8a2f6b / paper | 7.02 | 同上（C。2027 年の例） |
| 副色 D #0b6e99 / paper | 5.12 | 同上（D） |
| white / 副色 A〜D | 5.55・5.25・7.78・5.67 | 副色の地に白の文字 |
| 副色 A〜D / main | 2.36・2.49・1.68・2.31 | 使わない（4.5 未満） |
| ink / main | 1.27 | 使わない |

図形・UI 部品の 3:1 は未照合で、判定に使っていない。表にない組は使わない。反転では主色と副色の比が 1.68 から 2.49 で、色だけで固定と可変を分けられないため、位置で分ける（`event-visual-identity.md` も同じ）。誤用の図にも「×」と文字を添える（本 skill の整理）。

## 文言

守る 10 項目（読み手はボランティアのため、文言は丁寧語で書く）。`event-visual-identity.md` の「毎年、マークについてはこの 5 行だけを守る」は、この 10 項目のうちマークに関わる部分に、塗るマスの数と公開前の聞き取りを足した手順である（本 skill の整理）:

| # | 項目 | 型の出典 |
|---|---|---|
| 1 | 名称は「瀬戸内ブックフェア」と書きます | 本 skill の整理 |
| 2 | ロゴの形（四隅の 4 マス）を変えません。引き伸ばしません | S19 の型 |
| 3 | 輪郭だけの文字にしません | S07 の型 |
| 4 | ロゴの周りに、マークの 1 マス分の余白を空けます | S14 の型 |
| 5 | 最小サイズより小さくしません。狭い場所はマークだけを使います | S14 の型 |
| 6 | ロゴの色は、通常・1 色（主色）・反転（白）の 3 通りだけです | S19 の型を本例の色に合わせた |
| 7 | 文字と背景は、色の表にある組だけ使います | S33 |
| 8 | 書体は 1 系統だけ使います | 本 skill の整理 |
| 9 | 迷ったら、ブランド担当に聞きます | 本 skill の整理 |
| 10 | 変えたくなったら、担当に提案します | 本 skill の整理 |

| 場所 | before | after | 理由 |
|---|---|---|---|
| 冒頭 | 本ガイドラインは、ブランドの一貫性を担保するために策定された | このロゴは、瀬戸内ブックフェアを見分けるための印です。10 分で読めて、守るのは 10 項目だけです。 | 目的を先に言い、量を示す（S30、C・要旨） |
| 誤用の図の説明 | 以下の使用は禁止されている | ×: 引き伸ばしたロゴ。形が変わるので使いません。 | 禁止は図と短い理由で示す（本 skill の整理。禁止の内容は S07、S19） |
| 引き継ぎ欄 | 担当者: | 今年の担当: ____ 副担当: ____ 次の担当は副担当です。 | 責任者を名前で残す（S31、B・要旨） |

使う前の 3 つの確認（7 ページ。本 skill の整理）:

| # | 問い | 当てはまる項目 |
|---|---|---|
| 1 | ロゴの形・色・文字を変えていないか | 2・3・6 |
| 2 | 余白と最小サイズを守っているか | 4・5 |
| 3 | 文字と背景の組は、色の表にあるか | 7 |

誤用 4 例と正しい 1 例（6 ページ。図で示す。禁止の内容は S07、S19）:

| 例 | 内容 | 禁止の出典 |
|---|---|---|
| × 1 | マークを引き伸ばす・歪める | S19（本来の比率を崩す拡縮・引き伸ばしの禁止）、S07（歪めない） |
| × 2 | 輪郭だけの文字にする | S07 |
| × 3 | 四隅を副色で塗る・表にない色に変える | S19（変更の禁止）の型。四隅は固定（本 skill の整理） |
| × 4 | 余白に他の要素を食い込ませる | S19（余白を保つ） |
| ○ 1 | 余白を空け、通常・1 色・反転のいずれかの色で置く | 項目 4・6 |

## コード断片

外部 URL・フォント・スクリプトは使わない。許可した組だけを CSS のクラスにし、表にない組が書けない形にする。

マーク（固定の四隅の 4 マスだけ。単色。年ごとに塗るマス（3〜4 マス）と名称の文字は含めない。名称の文字は、書体のライセンスを確認してから組む。可変のマスは `event-visual-identity.md`）:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 120 120" role="img" aria-labelledby="sbf-t">
  <title id="sbf-t">瀬戸内ブックフェア</title>
  <g fill="currentColor">
    <rect x="4" y="4" width="32" height="32"/><rect x="84" y="4" width="32" height="32"/>
    <rect x="4" y="84" width="32" height="32"/><rect x="84" y="84" width="32" height="32"/>
  </g>
</svg>
```

色と許可する組（表の値と一致させる）:

```css
:root {
  /* ブランド共通の色（固定の核は主色 --sbf-main だけ。他は用途ごとの色） */
  --sbf-main: #1b2f5b; --sbf-paper: #f7f3ea; --sbf-ink: #1e1e24; --sbf-grey: #5c5c66; --sbf-white: #ffffff;
  /* 年ごとに動かす（2027 年の例は C。A #b4441c・B #1f7a5c・D #0b6e99 も 4.5:1 以上） */
  --sbf-flex: #8a2f6b;
  --cell: 0.8rem;                 /* 余白の単位 = マークの 1 マスの幅（仮置き） */
}
/* 許可した組だけ。表にない組はクラスを作らない */
.on-paper-main  { color: var(--sbf-main);  background: var(--sbf-paper); }   /* 11.82 */
.on-paper-ink   { color: var(--sbf-ink);   background: var(--sbf-paper); }   /* 14.97 */
.on-paper-grey  { color: var(--sbf-grey);  background: var(--sbf-paper); }   /* 5.97 */
.on-paper-flex  { color: var(--sbf-flex);  background: var(--sbf-paper); }   /* 7.02（C の場合） */
.on-main-white  { color: var(--sbf-white); background: var(--sbf-main); }    /* 13.09 */
.on-flex-white  { color: var(--sbf-white); background: var(--sbf-flex); }    /* 7.78（C の場合） */

.logo-slot { padding: var(--cell); }
.logo-slot svg { display: block; width: calc(var(--cell) * 3.75); height: auto; }   /* マーク 120 = 1 マス 32 の 3.75 個分 */
```

誤用の図（色に頼らず、図と文字で禁止を示す）:

## 初見検証

初めてのボランティアに冊子を渡し、10 分後に聞く（人数は本 skill の目安で、3 人程度）。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 守る 10 項目のうち 3 つを言える（形を変えない・余白・色の表） | 1 ページと 7 ページ |
| 何を操作できるか | チラシで使ってよい色の組を、表から選べる | 4 ページの表 |
| どう操作するか | 迷ったときの連絡先を言える。誤用 4 例と正しい 1 例を混ぜて見せ、正しい 1 例を当てられる | 8 ページと 6 ページ |

答えられない項目は、説明を足さず、項目を減らすか配置を見直す。1 年後の引き継ぎ会で、実際に作られた制作物に守られていない項目が無いかも確かめる（本 skill の整理）。

## 点検

- 量: 固定が 4 つ、規則が 10 項目、冊子が 10 ページに収まっている（数値は本 skill の目安）
- 禁止: 誤用を図で示した（本 skill の整理。禁止の内容は S07、S19）。「変えるな」だけの禁止が残っていない
- 運用: ブランド担当・副担当・任期・引き継ぎの手順が決まっている（S31、B・要旨）。決まっていなければ、冊子は形だけになる
- 統制: ガイドラインが創造を縛る道具になっていないか。批判（S29、S30。C。意見で実証は無い）を踏まえ、承認は看板と印刷物だけにした
- コントラスト: 色の表の組をすべて計算し、使う組を 4.5:1 以上にそろえた（S33）。年ごとに副色を変えるときは、先に計算する
- 商標・使用許諾: 名称・ロゴの形・指定商品または役務の確認項目と、協賛社・出展者への使わせ方を、弁理士・弁護士へ渡す。類否・登録可否・許諾の可否は判断しない。商標は法的要件に沿って使わないと危うくなりうる、という PSF の方針は参考で、法的判断ではない（S20）。S15・S16 は米国、S32 は日本の案内で、互いの制度に当てはまらない
- 書体・素材: 書体と写真素材のライセンスを確認する
- 模倣: NASA・英国政府・CNCF は項目の型を借りただけで、実在のガイドラインの内容を写していない
- 効果: ガイドラインがあれば守られるとは言えない。守られたかは、翌年の制作物で確認する（本 skill の整理）
- 推測の明示: ボランティアの実際の読み方・運用の続けやすさは、この例からは分からない。最終判断は実行委員会が行う
