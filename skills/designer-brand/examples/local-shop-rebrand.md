# 例: 地域の小売店の CI 刷新

創業 60 年の町のパン店が、「古く見える」を理由にロゴの一新を考えたとき、何を残し何を変えるかを先に決め、持ち主である常連への発表まで設計する例。刷新の相談を受けたとき、全面刷新と軽い修正を比べるとき、発表と撤回のリスクを考えるときに開く。題材は架空の店で、実在の店・製品・ロゴの模倣は含まない。

## 依頼

- 店: 創業 60 年の町のパン店「潮風堂」（架空。実在の店とは無関係）。店頭の看板・包み紙・紙袋・レジ横のスタンプ・店内の値札にロゴを使う
- 現行のロゴ（架空）: 紺の角丸の枠の中に筆文字の店名「潮風堂」。枠の下に、金色の細い波の線が 3 本。生成り色の地に置く
- 依頼文: 「古く見えるので、ロゴを一新したい」
- 依頼主: 二代目の店主。常連が多く、看板と包み紙で店を覚えている人が大半
- 置いた前提（確認が取れていない）: 常連への聞き取りは未実施。売上・包材の在庫・切り替えの費用は未確認。商標登録の有無は不明

## 目的の一文

看板と包み紙で常連が「あの店」と見分けられる標識を保ったまま、小さな刻印や単色の紙袋でも潰れずに読める。

「古く見える」は目的ではなく感想である。更新が事業を魔法のように変えるという信念は珍しくなく、新しさの示唆も、会社が主張に見合わなければ短命だ、と Rand は書く（S01、B・要旨）。変える理由が事業の変化でなく、依頼主の自負や流行でないかを先に確かめる（S01、B・要旨）。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 店名の字面・書体の全面変更 | 常連の認知の核。後から変えるのは、人々の家に入って持ち物を取り上げ、望まないものに替えることにたとえられる（S12、A） |
| 流行の細い線・淡いパステル | 包み紙の刻印で潰れる。流行に寄せると差別化を失うという批判もある（S28、C・要旨） |
| 紺と生成りの変更 | 現行の色の核。残す資産として扱う（本 skill の整理） |
| 英字の併記 | 小サイズで読めなくなる。必要になってから足す（本 skill の整理） |
| 「刷新しました」の一斉告知 | 持ち主に聞かずに出さない。Gap は進め方に誤りがあったと述べた（S24、B・要旨） |
| 全面刷新の同時切り替え | 在庫の包材を無駄にし、撤回もしにくい（本 skill の推測。費用は未確認） |

## 構成

IBM は 1956 年に、新時代を示しつつ連続性も伝えるロゴを求めたと述べる（S05、R。企業の説明）。「新しさ」と「連続性」の両方を問う型を使い、まず資産を棚卸しする。

資産の棚卸し（残す・変える・決めない）:

| 資産 | 現行 | 判断 | 理由 |
|---|---|---|---|
| 店名の字面 | 筆文字の「潮風堂」 | 残す | 常連の認知の核（本 skill の整理） |
| 紺と生成り | 看板・包み紙の基調 | 残す | 色の核。値は変えない |
| 角丸の枠 | 枠 + 店名 | 残す | 形の核 |
| 波の線 | 金色・3 本・細い | 変える | 刻印で潰れる。2 本・太くして、小さくても残す |
| 金色 | #B89B5E | 変える | 生成りの上で文字（値札の見出し）に使うと 4.5:1 に届かない（下の表で 2.30） |
| 包み紙の配置 | 枠を中央に 1 つ | 決めない | 店主と相談。紙の型と在庫に依る |

変える理由が「変更のため」になっていないかを行ごとに点検する。変更のための変更は誤った動機だと Vignelli は書く（S06、A）。「古く見える」は変える理由に入れない。

全面刷新と軽い修正の比較（本 skill の推測。常連のデータと費用の見積もりが無いため、最終判断は店主が行う）:

| 観点 | A 全面刷新 | B 軽い修正（本 skill の第一案） |
|---|---|---|
| 常連の認知の継承 | 失うおそれ | 保たれる |
| 小サイズ・単色の改善 | 設計次第 | 波の線で直接改善 |
| 新しさの伝わり | 強い | 弱い（連続性を優先） |
| 発表の負担と撤回のしやすさ | 大きい・戻しにくい | 小さい・戻しやすい |
| 費用 | 未確認 | 未確認（切り替えの範囲が小さい） |

発表の手順（Gap の反省が進め方だった点を踏まえる。S24、B・要旨。手順そのものは本 skill の整理）:

1. 試作の包み紙を、店頭で常連の数人に見せ、聞く（先に見せる）
2. 変わった点と変わらない点を、一言で伝える（文言を参照）
3. 反応を聞く窓口を置く（レジ横の意見箱と店主）
4. 戻す条件を先に決める（例: 「前の方がよかった」という声が複数あれば、波の線だけ戻す）
5. 包材は旧在庫を使い切ってから切り替える（推測。在庫は未確認）

Gap は声明で、オンラインのコミュニティと関わる機会を逃したと述べた（S25、B・要旨）。この店は対面なので、関わる場は店頭になる。

## 仕様

出典のある値と、本 skill の目安（出典なし）を分ける。

| 項目 | 値 | 根拠 |
|---|---|---|
| 版 | 標準版（枠・店名・波 2 本）と縮小版（枠・店名のみ）。単色版は紺 1 色 | 版ごとに最小サイズを定める型は S14 に倣う。版の分け方は本 skill の目安 |
| 最小サイズ（仮置き） | 標準版は幅 40 mm、縮小版は幅 18 mm。スタンプで試し押しして確定する | 本 skill の目安（出典なし）。S14 の値は英国政府の紋章に対する規定で、流用しない |
| 波の線 | 現行は 3 本・線幅 1.5。新は 2 本・線幅 3（枠の幅 120 に対する単位） | 本 skill の目安 |
| 余白 | 枠の高さ 1 つ分（仮置き） | 本 skill の目安。値は実物で確かめる |
| 色 | 紺 #1B2F4A、生成り #F6EEDC、金茶 #7A5A12（旧 #B89B5E）、クラフト紙 #D9B77E | 紺・生成りは現行の値のまま残す。金茶と旧金は本 skill の仮の値 |
| 禁止 | 形を変えない・引き伸ばさない・輪郭だけの文字にしない | S19、S07 の型 |

コントラスト比（WCAG の相対輝度式で計算。基準は文字と背景の組で 4.5:1。S33）:

| 前景 / 背景 | 比 | 判定・用途 |
|---|---|---|
| 紺 / 生成り #F6EEDC | 11.71 | 看板・値札の文字 |
| 紺 / クラフト紙 #D9B77E | 7.10 | 紙袋の文字 |
| white #FFFFFF / 紺 | 13.53 | 反転（紺の地に白） |
| 旧金 #B89B5E / 生成り | 2.30 | 使わない（4.5 未満） |
| 金茶 #7A5A12 / 生成り | 5.51 | 値札の見出し・波の線 |
| 金茶 / クラフト紙 | 3.34 | 使わない（4.5 未満。クラフト紙の上には紺だけ） |

図形（波の線）のコントラストの基準（3:1）は未照合で、判定に使っていない。金茶は文字にも使うため、文字の基準で選んだ。

## 文言

| 場所 | before | after | 理由 |
|---|---|---|---|
| 店頭の掲示 | ロゴを刷新しました。新生・潮風堂をよろしくお願いします | 包み紙の線を少し太くしました。店名と紺と生成りは、これまでどおりです。 | 変わるものと変わらないものを一言で伝える（本 skill の整理。S24 の教訓） |
| 常連への一言 | 新しいデザインです。いかがですか | 新しい包み紙の見本です。どこが変わったか分かりますか。気になる点があれば教えてください。 | 評価を迫らず、聞く姿勢を示す（S12 の、誰の持ち物を変えるかという視点。本 skill の整理） |
| 店主への説明 | ロゴが古い | 変える理由は、小さな刻印で線が潰れることと、金色が値札の文字として 4.5:1 に届かないこと。「古く見える」は常連の反応で確かめる | 変更のための変更を避ける（S06） |

## コード断片

店名の筆文字は現行のデータを変えずに使うため、断片には含めない。外部 URL・フォント・スクリプトは使わない。

標準版（枠と波。店名の位置は空けてある）:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 120 88" role="img" aria-labelledby="shio-t">
  <title id="shio-t">潮風堂</title>
  <style>
    .frame { fill: none; stroke: var(--shio-navy, #1B2F4A); stroke-width: 4; }
    .wave  { fill: none; stroke: var(--shio-gold, #7A5A12); stroke-width: 3; stroke-linecap: round; }
    .mono .frame, .mono .wave { stroke: currentColor; }   /* 単色版（スタンプ・紙袋） */
  </style>
  <rect class="frame" x="2" y="2" width="116" height="84" rx="12"/>
  <!-- 店名: 現行の筆文字データ（パス化済み）をここへ差し込む。形は変えない -->
  <g id="shopname"></g>
  <path class="wave" d="M24 62q9-9 18 0t18 0t18 0t18 0"/>
  <path class="wave" d="M24 72q9-9 18 0t18 0t18 0t18 0"/>
</svg>
```

縮小版は、上の断片から 2 本の `.wave` を除く。

色の継承と変更（表の値と一致させる）:

```css
:root {
  /* 残す（現行と同じ値） */
  --shio-navy: #1B2F4A;    /* 看板・包み紙・枠 */
  --shio-cream: #F6EEDC;   /* 地の色 */
  /* 変える（理由: 生成りの上の文字として 4.5:1 に届かない。2.30 から 5.51） */
  --shio-gold: #7A5A12;    /* 旧: #B89B5E */
  /* 包み紙（クラフト紙）の地。文字は紺だけ */
  --shio-kraft: #D9B77E;
}
.price-title { color: var(--shio-gold); background: var(--shio-cream); }
.wrap-kraft  { color: var(--shio-navy); background: var(--shio-kraft); }
/* 金茶はクラフト紙の上に置かない（3.34） */
```

## 初見検証

旧と新の包み紙を、並べずに 1 枚ずつ見せる。常連と、初めての人の両方に数人ずつ聞く（人数は本 skill の目安）。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか（どこの店か） | 常連は新しい包み紙も「潮風堂」と答える | 店名・紺と生成り |
| 何を操作できるか（何が変わったか） | 変えた点（線が太い・色が少し濃い）を挙げられる、または気づかない | 波の線・金茶 |
| どう操作するか（どう伝えるか） | 店頭の掲示 1 文で、変わらない点が分かる | 掲示と窓口 |

常連が同じ店と分からないなら変えすぎである。変わったことに誰も気づかなければ、軽い修正が成功しているとも読める（本 skill の整理）。

## 点検

- 残す・変える: 資産ごとに分け、変える理由が変更のためになっていない（S06）。依頼主の自負や流行が動機になっていないか（S01、B・要旨）を店主に確かめた
- 発表: 先に見せ、変わる点と変わらない点を一言で伝え、聞く窓口を置き、戻す条件を決めた（S12、S24、S25）
- 成立: 単色（紺 1 色）・縮小版・スタンプで潰れないかは、試し押しで確かめる（未実施。要確認）
- コントラスト: 文字として使う組をすべて計算し、4.5:1 以上にそろえた（S33）
- 商標: 店名・図形（枠と波）・指定商品（パン・菓子など）の確認項目を洗い出し、弁理士・弁護士へ渡す。登録の有無は不明で、類否・登録可否は判断しない。調べて見つからなかったことは、使ってよい根拠にならない（S15・S16 は米国、S32 は日本の案内で、互いの制度に当てはまらない）
- 模倣: 実在の店・ロゴの形や配色を写していない
- 効果: 刷新で来店が増えるとは言えない（S01、B・要旨）。反応は常連の声と包材の切り替え後の様子で見る
- 推測の明示: 常連の反応・費用・売上・包材の在庫は、この例からは分からない。A と B の比較は推測で、最終判断は店主が行う
