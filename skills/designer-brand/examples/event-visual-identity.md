# 例: イベントのビジュアルアイデンティティ（固定の核と年ごとに動く要素）

毎年開く催しの見た目を、「固定する核」と「年ごとに動かす要素」に分けて組み立てる例。ボランティアが入れ替わっても同じイベントと分かり、毎年違う見た目にもできる設計を示す。題材は架空で、実在のイベント・ロゴ・配色の模倣は含まない。ブランドガイドライン全体の章立てと運用は `brand-guidelines-booklet.md` を参照する。

## 依頼

- 組織: 瀬戸内ブックフェア実行委員会（架空）。毎年秋に港町で 2 日間開く本の市で、運営はボランティア。毎年メンバーの半数ほどが入れ替わる（架空の設定）
- 依頼文: 「毎年違う見た目にしたいが、同じイベントだと分かってほしい。2027 年版を作って」
- 想定する見る人: 前回までの来場者、初めて知る人、出展する書店
- 使う場面: ポスター、Web のヘッダー、SNS のアイコン（小サイズ）、トートバッグ（1 色刷り）
- 置いた前提: 過去の 2025・2026 年版は、本例で仮に作る。名称「瀬戸内ブックフェア」は継続する

## 目的の一文

港町の本の市「瀬戸内ブックフェア」を、前回の来場者にも初めての人にも、ポスターから 1 色刷りのトートバッグまで同じイベントとして識別させ、年が変わったことも見分けさせる。

## 削るもの

| 削るもの | 理由 |
|---|---|
| 毎年ゼロから描き起こす進め方 | 引き継ぎのたびに作り直すと同一性が途切れる。同一性が過ぎれば記憶に残らず、多様性が過ぎれば断片化する（S06） |
| 固定する資産の長い一覧 | 固定は少数に絞る（本 skill の整理）。本例は 4 項目 |
| マスの数・位置の自由 | 規則が複雑なほど守られなくなる、という指摘がある（S30、C。意見で実証はない）。塗るマスは 3〜4 個とする |
| 自由な副色 | 文字に使えない色が混ざる。コントラストを計算した 4 色の表から選ぶ |
| マークの中の年号 | 1 色・小サイズで潰れる。年号はマークの外に置く |
| グラデーション・影・多色 | 1 色刷りで再現できない。Rand は、単色かつ極小で再現できることが唯一の必須条件だと書く（S01、B・要旨） |
| 前回の来場者に見せない一斉の公開 | Gap は新ロゴを取りやめたとき、進め方に誤りがあったと述べた（S24、B）。公開前に聞く手順を置く |

## 構成

```text
+----------------------------------------------+
|  ■ ■ ■     瀬戸内ブックフェア                  |
|  ■   ■     2027                               |
|  ■ ■ ■                                        |
+----------------------------------------------+
   マーク      ワードマーク（名称）+ 年号
```

図は 2027 年版。四隅の 4 マスが固定で、上・左・右・下の 4 マスが今年の可変。中央は空ける。

| 区分 | 項目 | 内容 |
|---|---|---|
| 固定 | 名称の字面 | ワードマーク「瀬戸内ブックフェア」 |
| 固定 | 骨格 | 3×3 の格子の位置と、四隅の 4 マス（主色） |
| 固定 | 主色 | 紺 1 色 |
| 固定 | 配置 | マークが左、名称が右、年号は名称の下 |
| 可変 | 塗るマス | 四隅以外の 5 マスのうち 3〜4 マスを副色で塗る |
| 可変 | 副色 | 表の 4 色から 1 色。前年と別の色 |
| 可変 | テーマ語 | マークの外（告知の文）に置く |

MIT Media Lab のアイデンティティは、7×7 のグリッドに基づくロゴを起点に、23 の研究グループへ拡張し、固定のアイデンティティと活動の多様性を両立させたと Pentagram が述べる（S13）。本例の 3×3 の格子と四隅の固定は、共通の骨格を置くという型を借りた本 skill の設計で、S13 の寸法や図形を借りたものではない。

規則は次の 5 行に収める（本 skill の目安）。冊子全体で守る 10 項目（`brand-guidelines-booklet.md`）のうちマークに関わる部分に、塗るマスの数と公開前の聞き取りを足したものである（本 skill の整理）。

1. 四隅の 4 マス・主色・配置・名称は動かさない
2. 可変の 5 マスのうち 3〜4 マスを副色で塗る
3. 副色は表の 4 色から、前年と別の色を選ぶ
4. 1 色では副色のマスも主色で、反転では白で塗る
5. 公開前に、過去の来場者へ 3 年分を並べて見せる

運用は、引き継ぎ担当 1 名がマスターの SVG と上の 5 行を持つ。強く関与する指導層がいればプログラムは根づく、と Olins は書く（S31、B・要旨）。引き継ぎ担当という責任者を、規則より先に決めるのは本 skill の整理である。

## 仕様

| 項目 | 値 | 根拠 |
|---|---|---|
| 格子 | 3×3。1 マス 32、隙間 8（viewBox 120） | 本 skill の目安（出典なし） |
| 塗るマス数 | 可変の 5 マスのうち 3〜4 | 本 skill の目安（出典なし） |
| マーク単体の最小サイズ | 24 px | 本 skill の目安（出典なし）。16 px でも 3 年分を 1 色で区別できたが、隙間は約 1 px になる |
| 余白 | マークの 1 マスの幅を単位とする | 本 skill の目安（出典なし）。余白の値は組織・ロゴごとに決まり、他のロゴへ流用しない（S07、S14 は組織の規定） |
| 色 | 主色 1 色 + 副色 1 色。色は通常・1 色・反転の 3 通り（`brand-guidelines-booklet.md` と同じ） | 1 色と全黒・全白の型は S07、S19。具体色は本 skill の目安 |
| 文言の書体 | 1 系統。外部のフォントを配信しない | 本 skill の目安 |

過去 2 年分は本例の仮のデータ。

| 年 | 塗るマス（左上を 1、右下を 9 として行ごとに数える） | 副色 |
|---|---|---|
| 2025 | 2・5・8（縦の 1 列） | A |
| 2026 | 4・5・6（横の 1 行） | B |
| 2027 | 2・4・6・8（中央を空けた輪） | C |

コントラスト比（WCAG の相対輝度式で計算。文字は 4.5:1 以上。S33）。

| 色 | 値 | 白の上 | 生成り #f7f3ea の上 | 主色の上 |
|---|---|---|---|---|
| 主色（紺） | #1b2f5b | 13.09 | 11.82 | - |
| 白（反転用） | #ffffff | - | - | 13.09 |
| 副色 A（橙茶） | #b4441c | 5.55 | 5.01 | 2.36 |
| 副色 B（緑） | #1f7a5c | 5.25 | 4.74 | 2.49 |
| 副色 C（紫） | #8a2f6b | 7.78 | 7.02 | 1.68 |
| 副色 D（青） | #0b6e99 | 5.67 | 5.12 | 2.31 |

- 年号などの文字に使う副色は、白か生成りの上に限る（いずれも 4.5:1 以上）。主色の上に副色の文字を置かない
- 反転では副色のマスも白にする。主色と副色の比は 1.68〜2.49 で、色だけで固定と可変を分けられない。固定と可変の違いは色ではなく位置で決める
- 文字でないマーク（図形）に 4.5:1 が適用されるかは未照合。本例の副色はすべて白の上で 4.5:1 以上なので、どちらの読みでも満たす

## 文言

| 場所 | 文言 | 理由 |
|---|---|---|
| 告知の名称・年号 | 瀬戸内ブックフェア 2027 | 名称は固定。年号だけが毎年変わる |
| テーマ語（架空） | 今年のテーマ「港で読む」 | 毎年変わる文は、マークの外に置く |
| 聞き取りの案内 | 2027 年の見た目の案です。毎年変わるのは四隅以外のマスと色だけで、四隅と名前は変わりません。気づいたことを教えてください | 何が変わり何が変わらないかを一言で伝え、反応を聞く窓口を置く（S12、S24 の教訓。文面は目安） |
| 引き継ぎ表紙 | 毎年、マークについてはこの 5 行だけを守る | 規則を少数に絞る（本 skill の整理）。複雑な規則が守られなくなるという指摘は S30（C。意見） |

## コード断片

固定は `ev-core`、可変は `ev-flex` のクラスで分け、色は変数で差し替える。外部のフォント・スクリプト・CDN は使わない。

```svg
<svg xmlns="http://www.w3.org/2000/svg" class="edition" data-year="2027" viewBox="0 0 420 120" role="img" aria-labelledby="ev-t">
  <title id="ev-t">瀬戸内ブックフェア 2027</title>
  <style>
    .ev-core { fill: var(--core, #1b2f5b); }   /* 固定: 主色 */
    .ev-flex { fill: var(--flex, #8a2f6b); }   /* 可変: その年の副色（2027 は C） */
  </style>
  <!-- 固定: 四隅の 4 マス（3×3 の格子。1 マス 32、隙間 8） -->
  <g class="ev-core">
    <rect x="4" y="4" width="32" height="32"/><rect x="84" y="4" width="32" height="32"/>
    <rect x="4" y="84" width="32" height="32"/><rect x="84" y="84" width="32" height="32"/>
  </g>
  <!-- 可変: 2027 は上・左・右・下の 4 マス（2025 は上・中・下、2026 は左・中・右） -->
  <g class="ev-flex">
    <rect x="44" y="4" width="32" height="32"/><rect x="4" y="44" width="32" height="32"/>
    <rect x="84" y="44" width="32" height="32"/><rect x="44" y="84" width="32" height="32"/>
  </g>
  <!-- ワードマークは文字（図形ではない）。配布前にアウトライン化するか、書体のライセンスを確認する -->
  <text class="ev-core" x="140" y="62" font-size="30" font-weight="700"
        font-family="'Hiragino Sans','Yu Gothic','Noto Sans CJK JP',sans-serif">瀬戸内ブックフェア</text>
  <text class="ev-flex" x="140" y="102" font-size="30" font-weight="700"
        font-family="'Hiragino Sans','Yu Gothic','Noto Sans CJK JP',sans-serif">2027</text>
</svg>
```

```css
/* 塗るマスは年ごとの SVG に書く。CSS が差し替えるのは色だけ。1 色と反転は変数の代入で作る */
.edition { --core: #1b2f5b; --flex: #8a2f6b; }
.edition[data-year="2026"] { --flex: #1f7a5c; }
.edition[data-year="2025"] { --flex: #b4441c; }
.edition.mono { --flex: var(--core); }                                   /* 1 色: 副色のマスも主色 */
.edition.reverse { --core: #ffffff; --flex: #ffffff; background: #1b2f5b; }   /* 反転: すべて白 */
```

## 初見検証

説明なしで、告知（ポスターか Web のヘッダー）を初めて見る人に見せる。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか | 「瀬戸内の本のイベントで、今年は 2027 年」 | ワードマークと年号 |
| 何を操作できるか | 日時・場所・申込先を探せる | 告知の主情報（マークは操作対象ではない） |
| どう操作するか | 申込先まで 1 手で行ける | QR か URL の位置 |

マークに固有の確認として、過去の来場者 5 人程度（本 skill の目安）に 2025〜2027 を並べて見せ、次の 2 つを聞く。

- 「同じイベントか」: はいと答えられるか
- 「今年のどこが変わったか」: 色か、中のマスかを言えるか

答えられない場合は説明を足さず、固定の核（四隅・名称・配置）の見え方を見直す。

## 点検

- 同一性: 2025〜2027 を並べて、四隅・主色・名称・配置で同じイベントと分かる。1 色にして 16 px へ縮めても 3 年分の違いが残る（目視。確認した環境は 1 つで、他の環境では未確認）
- 同一性の外れ: 副色だけでなく、塗るマスの位置も変えたとき、前回の来場者が同じと読むかは、聞き取りで確かめる（実測データは無い）
- 差別化: 正方形の格子はありふれた形で、没個性化の批判（S28、C）に当たりうる。拡縮・可読という機能面の理由は認めたうえで、他の催しの告知と並べて見分けがつくかは未確認。名称と四隅の固定を、見分ける手がかりとして使う
- 発表と受け止め: London 2012 のエンブレムは、発表直後に専門家と一般から批判を受けた（S26、S27。報道の地の文・R）。原因は出典から断定できず、Wolff Olins 自身の説明は未取得。本例は、公開前に持ち主へ見せる手順を置く理由として挙げる（本 skill の整理）。Bierut は、後から変えるのは人々の持ち物を取り上げるようなものだとたとえる（S12）。本例は毎年変わることを先に宣言し、変わる範囲を限る
- 運用: 規則 5 行を引き継ぎ担当が持つ。規則が複雑なほど守られなくなるという指摘がある（S30、C。意見）。強く関与する指導層がいればプログラムは根づく（S31、B・要旨）。引き継ぎ担当を置くのは本 skill の整理
- 商標: 名称「瀬戸内ブックフェア」と図形（格子）について、名称・図形・指定商品・役務の確認項目を洗い出し、専門家（弁理士・弁護士）へ渡す。日本の公的案内は、J-PlatPat の機能は基本的なものに限られ、高度な調査は民間サービスを勧めるとする（S32）。米国の案内は、調査は登録可否の確実な答えにならないとする（S15、S16。米国の制度）。類否・登録可否・侵害の有無は判断しない。実在の書籍イベントとの名称の近さは未調査
- 実在の模倣: 実在のイベント・ロゴの図形と配色を写していない。差別化の確認は上のとおり未確認
- 推測の明示: 来場者の反応・申込数への効果はこの例からは分からない。実測データが要る判断は、最終的に相談者が行う
