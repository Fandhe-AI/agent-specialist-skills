# 例: スタートアップのロゴとワードマーク

創業 1 年の会社のロゴを、「流行の見た目」からでなく「何を識別させるか」から組み直す例。新規のロゴを作るとき、単色・極小で成立するかを確かめるとき、没個性化（blanding）を避けたいときに開く。題材は架空の会社で、実在の企業・製品・ロゴの模倣は含まない。

## 依頼

- 会社: 工場の設備に取り付ける温度・振動センサーを作る「ミナト計測」（架空。創業 1 年の少人数の会社）
- 依頼文: 「流行の感じで、他社と並んでも新しく見えるロゴにしたい」
- 見る人: 工場の設備担当者（センサー本体の刻印・納品書・見積書で見る）、展示会の来場者（名札・ブース）、求職者（採用ページのファビコン・SNS アイコン）
- 使う最小の場面: センサー筐体のレーザー刻印（単色）、名刺、ファビコン、白黒コピーの納品書
- 置いた前提（確認が取れていない）: 既存のロゴは無く文字の仮表記だけ。同業他社のロゴは未確認。商標の調査は未実施。書体は未購入。英字表記は MINATO

## 目的の一文

工場の設備担当者が、センサー本体の刻印・納品書・展示会の名札のどれで見ても「ミナト計測」と分かり、小さく単色にしても同じものと識別できる。

「新しく見える」は目的ではなく結果である。ロゴは直接は売らず識別する、意味は象徴する中身の質から来る、と Rand は書く（S01、B・要旨）。良い製品が売る、という Rand の発言もある（S03、B・要旨）。ロゴに受注を増やす役を負わせない。

## 削るもの

| 削るもの | 理由 |
|---|---|
| グラデーション・影・立体 | 単色・極小で再現できることが必須条件と Rand は書く（S01、B・要旨）。刻印と白黒コピーで消える |
| 頭文字 M を抽象化した記号 | 同業と見分けがつきにくい（本 skill の整理）。形は社名の「港」から取る |
| 記号幅の 1/50 以下の細い線 | 計算上、記号の幅を 16 px にすると線は 1 画素未満になる（本 skill の整理。実測はしていない） |
| タグライン一体のロゴ | 極小で読めない。別の要素として必要なときだけ置く（本 skill の整理） |
| 3 色以上 | 単色・反転・グレーの版が増える。ロゴは 1 色にする |
| 「未来的」「シャープ」を足す装飾 | 形で新しさを演出しない。理由は上の目的の一文 |

## 構成

```text
標準版（印刷・画面の主表示）    記号（半円 + 下から入る切り欠き）+ 文字 MINATO を横に並べる
簡略版（刻印・ファビコン）      記号のみ。切り欠きを広く・浅くする
```

- 形の核は 1 つ: 半円（港の水面と計器の文字盤）に、下から入る切り欠き（港の入口）。差別化の要素を 1 つに絞る
- 文字は直線と円だけで描き起こした自作のパスで、既存書体のファイルから取っていない。日本語の「ミナト計測」は別の組版で、ロゴの図形には含めない
- 版は 2 つ。標準版は記号と文字、簡略版は記号のみで切り欠きを広くする。版ごとに最小サイズを決める型は S14 の記述に倣う（値は紋章に対するもので流用しない。後述）
- ロゴの色は 1 色を基本とし、全黒・全白でも使えるようにする型は S19 に倣う（S19 は "full color option or all-black or all-white" と定める）
- 没個性化への対処: サンセリフが多様な媒体で拡縮・可読になる機能面の理由は、批判側の S28（C・要旨）も認める。ここでは文字の幾何学的な構成は機能の理由で選び、差別化は記号の切り欠きに置く。ただし、デザイナーは差別化と独自性を過大評価しがち、人は目立つより溶け込みたい、という指摘もある（S12、A）。工場の購買担当に必要なのは「目立つ」より「見分けられる」と推測する（本 skill の整理）。見分けがつくかは同業と並べて確かめる（初見検証）

## 仕様

出典のある値と、本 skill の目安（出典なし）を分ける。

| 項目 | 値 | 根拠 |
|---|---|---|
| 記号の形 | 半円（半径 24 単位）。標準版の切り欠きは幅 4・高さ 16 | 本 skill の目安（出典なし） |
| 簡略版の記号 | 半円は同じ。切り欠きは幅 8・高さ 14（記号幅の 1/6） | 本 skill の目安。16 px の実測は下表 |
| 文字 | 字高 20・線幅 4・字間 6（単位。M は 20、I は 4、N・A・T・O は 20 の幅） | 本 skill の目安 |
| 最小サイズ（仮置き） | 標準版は横幅 30 mm または 120 px、簡略版は記号の幅 6 mm（切り欠き 1 mm）または 16 px | 本 skill の目安。刻印機の最小線幅と実機の画面で確定する。S14 の 20 mm・5 mm・60 px は英国政府の紋章に対する規定で、ここへ流用しない（S14 は、最大・最小のサイズは紋章の幅または高さを指し、アイデンティティ全体を指さないと述べる） |
| 余白 | 半円の半径 1 つ分（R）を仮置き。ロゴの高さと一致する。最小サイズの下限が効くときも、下限を掛けた高さと一致させる | 本 skill の目安。S14 は紋章の幅 1 つ分を除外領域とし、可能なら広く取るが、紋章の規定 |
| 色 | 主色 1 色（ink）。反転は白。グレー版は #595959 | 本 skill の目安。単色・全黒・全白の型は S19 |
| 禁止 | 形を変えない・引き伸ばさない・輪郭だけの文字にしない | S19（変更、本来の比率を崩す拡縮・引き伸ばしの禁止）、S07（ロゴタイプを歪めない・輪郭だけの文字で示さない） |

「輪郭だけの文字」は文字の中を抜いた袋文字の禁止で、文字を図形（パス）に変換する「アウトライン化」とは別の話である。

実寸確認（macOS のサムネイル描画で 16・24 px に縮めた、1 つの描画系での実測。記号の色は灰度 47、背景は 255）:

| 表示幅 | 標準版の切り欠き（幅 4/48） | 簡略版の切り欠き（幅 8/48） |
|---|---|---|
| 16 px | 2 画素が灰度 185（薄い） | 2 画素が 255、両脇が 116 |
| 24 px | 2 画素が 255 | 4 画素が 255 |

16 px では標準版の切り欠きが弱く、簡略版へ切り替える根拠になる。ブラウザや刻印機では結果が違いうるため、実機での確認は残る（要確認）。

コントラスト比（WCAG の相対輝度式で計算。基準は文字と背景の組で 4.5:1。S33）:

| 前景 / 背景 | 比 | 用途 |
|---|---|---|
| ink #0F3A47 / white #FFFFFF | 12.23 | ロゴ 1 色（白地） |
| ink / paper #F4F7F6 | 11.35 | ロゴ 1 色（紙色の地） |
| white / ink | 12.23 | 反転 |
| grey #595959 / white | 7.00 | グレー版 |
| water #0E7C86 / white | 4.95 | 画面の強調（リンク・見出し） |
| water / paper | 4.59 | 同上。基準を 0.09 上回るだけで、色を動かしたら再計算する |
| water / ink | 2.47 | 使わない（4.5 未満） |

ロゴの文字の扱いは S33 の引用の範囲外である。例外に頼らず、使う組をすべて 4.5:1 以上にそろえた。図形・UI 部品の 3:1 は未照合で、判定に使っていない。

## 文言

| 場所 | before | after | 理由 |
|---|---|---|---|
| 会社の説明 | 革新的なセンシングで製造業の未来をつくる | 工場の設備の状態を、小さなセンサーで測る。 | 誇張語を避け、何の会社かを言う（本 skill の整理） |
| ガイドの冒頭 | 当社のブランドアイデンティティを体現する | このロゴは、ミナト計測を見分けるための印である。 | 識別が仕事であるという目的に合わせる（S01、B・要旨） |
| 禁止の書き方 | ロゴの取り扱いには十分ご注意ください | 形を変えない。引き伸ばさない。輪郭だけの文字にしない。 | 禁止は具体的に短く（S19、S07 の型） |
| 画像の代替テキスト | ロゴ | ミナト計測 | 画像が伝える名前を書く |

## コード断片

外部 URL・フォント・スクリプトは使わない。色は `currentColor` で受け、1 色・反転・グレーを CSS で切り替える。

標準版（記号と文字。文字はすべてパス）:

簡略版（記号のみ。切り欠きを広げ、枠は記号に合わせて切る）:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 12 48 24" role="img" aria-labelledby="minato-m">
  <title id="minato-m">ミナト計測</title>
  <path fill="currentColor" fill-rule="evenodd" d="M0 36A24 24 0 0 1 48 36Z M20 22H28V36H20Z"/>

```

ファビコン・SNS アイコンの正方形に置くときは viewBox を `0 0 48 48` にする（上の実寸確認はこの形で測った）。

色と余白（表の値と一致させる）:

```css
:root {
  --minato-ink: #0F3A47;  --minato-water: #0E7C86;
  --minato-paper: #F4F7F6; --minato-white: #FFFFFF; --minato-grey: #595959;
}
.logo-slot { --logo-h: 2rem; --logo-min: 0px; --logo-size: max(var(--logo-h), var(--logo-min)); padding: var(--logo-size); }   /* 余白 = 記号の半径 1 つ分 = ロゴの高さ。下限が効いても高さと同じ値 */
.logo-slot svg { display: block; height: var(--logo-size); width: auto; }
.logo      { color: var(--minato-ink); }     /* 1 色 */
.logo--rev { color: var(--minato-white); }   /* 反転。背景は ink */
.logo--grey { color: var(--minato-grey); }   /* グレー */
/* 最小サイズ（仮置き）は、slot 側の変数 --logo-min で高さの下限として表し、高さと余白の両方に掛ける。高さを決めると幅は縦横比で決まるため、min-width は効かない */
.logo-slot:has(svg.logo--full) { --logo-min: 14.6px; }   /* 幅 120 px ÷ (198 / 24) = 14.55 px */
.logo-slot:has(svg.logo--mark) { --logo-min: 8px; }      /* 幅 16 px ÷ (48 / 24) = 8 px（viewBox 0 12 48 24 の場合） */
/* :has() 非対応の環境では下限が効かない。その場合は slot に版を示すクラス（例 .logo-slot--full）を付けて --logo-min を指定する */
```

文字（パス）は既存書体のファイルから取っていない。日本語の「ミナト計測」を既存書体で組む場合は、書体のライセンス（埋め込み・パス化の可否）を別途確認する。

## 初見検証

説明なしで見せ、3 つの問いに答えられるかを見る。無関係な 3 人程度に聞く（Rand の非公式な 3 人の試し〔S02、B〕に着想を得た、本 skill の整理。検証手法として Rand が主張したものではない）。

| 問い | 期待する答え | 確認する場所 |
|---|---|---|
| 何に注意するか（何と読むか） | 2 秒ほど見せて「MINATO、ミナト」と読める | 標準版の文字 |
| 何を操作できるか（どこで使えるか） | 刻印・名刺・ファビコンに使える。小さい場所では記号だけの版になる | 簡略版を 16 px に縮めた見え方 |
| どう操作するか（どう使うか） | 形を変えない・引き伸ばさない・輪郭だけの文字にしない、の 3 行を読んで誤用を当てられる | 文言の禁止 3 行 |
| 並べて見分けがつくか | 社名を隠し、同業 5 社（相談者が用意）と同じ大きさで並べて、形だけで区別できる | 記号の切り欠き |

3 人が読めない・見分けられない場合は、装飾を足さず、記号の切り欠きと文字の字間・字高を見直す。

## 点検

- 識別: 目的の一文を言い直せる。意味・構造・実用の 3 面（Semantic・Syntactic・Pragmatic。S06）のどれが弱いかを点検した。3 面は議論の整理用で、合否の採点には使わない
- 成立: 1 色・反転・グレー・極小で成立することを実寸で見た。最小サイズの下限が効くとき（`--logo-h` を下限より小さくした場合）も、余白が高さと一致することを確かめた。刻印機・実機の画面での確認は未実施（要確認）
- 差別化: 同業 5 社と並べた結果は未取得。没個性化の批判（S28、C。意見で実証は無い）と、差別化の過大評価の指摘（S12、A）の両方を踏まえ、差別化を記号 1 つに絞った
- コントラスト: 使う組をすべて計算し、4.5:1 以上にそろえた（S33）。基準を 0.09 しか上回らない組（water / paper）は色を動かしたら再計算する
- 商標: 名称「ミナト計測」・図形（半円と切り欠き）・指定商品または役務（センサー・計測機器など）の確認項目を洗い出し、弁理士・弁護士へ渡す。類否・登録可否・侵害の有無は判断しない。J-PlatPat で見つからなかったことは、使ってよい根拠にならない（S15・S16 は米国、S32 は日本の案内で、互いの制度に当てはまらない）
- 模倣: 実在の企業・製品のロゴ、配色の組み合わせを写していない。借りたのは考え方（識別・単色・極小）である
- 効果: ロゴで受注が増えるとは言えない。ブランド施策の効果は測りにくい、と当事者が述べる例がある（S10。原は広告がどう役に立っているか自分でもよく分からないと述べる。広告の話で、ロゴの制作論ではない）
- 推測の明示: 同業との見分け・工場現場での実際の読み取りは、この例からは分からない。実測が要る判断は最終的に相談者が行う
